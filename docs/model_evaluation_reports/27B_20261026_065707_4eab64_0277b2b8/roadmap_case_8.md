# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선·단기 집중: 권한표 문서화 중심 실습

가용 시간(1주, 총 3시간)과 예산(0원)을 우선 반영해 목표 범위를 '가상 서비스의 읽기·쓰기 권한표 작성 및 과도 권한 3건 식별·문서화'로 축소했습니다. 실제 계정 접속·외부 API 호출은 수행하지 않으며, 모든 활동은 로컬 문서·시뮬레이션으로 완료합니다. 시간 제약으로 인해 심층 자동화·테스트는 포함하지 않습니다.

### 1. 권한표 작성 및 과도 권한 식별

- 목표: 가상 서비스별 최소 권한(읽기/쓰기)을 정리하고, 현실적 시나리오에서 과도한 권한 3건을 찾아 근거와 위험을 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 서비스 목록 정의(예: 스토리지, 컴퓨팅, 네트워킹, 로깅) — 30분
- 활동: 각 서비스에 대해 읽기·쓰기·관리 권한을 표로 정리(권한 이름·설명·권한 범위) — 60분
- 활동: 과도한 권한 3건 선정(예: 전체 쓰기 권한, 관리 권한의 불필요한 부여, 광범위한 읽기 권한) 및 각 항목의 위험·완화 방안 기술 — 60분
- 활동: 결과 요약(1페이지) 및 향후 검토 권고사항 작성 — 30분
- 산출물: 서비스별 읽기·쓰기 권한표(CSV 또는 마크다운 표)
- 산출물: 과도한 권한 3건 목록과 각 항목의 위험·완화 방안 문서(최대 1페이지)
- 산출물: 간단한 검토 체크리스트(향후 권한 재검토 시 사용)
- 완료 기준: 권한표와 과도 권한 3건 문서가 작성되어 로컬 파일로 저장되고, 각 항목에 대해 근거(왜 과도한지)와 최소권한 권고가 명시되어 있을 것. 총 소요시간 3시간 이내.
- 추천 자료 KMOOC_18100: 제공 근거에서 확인되지 않음
