# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실무형 RDBMS 모델링 집중 로드맵

가용 시간(총 6시간)에 맞춰 목표 범위를 축소하여 관계형 DB 모델링의 핵심 설계·구현·검증을 완료합니다. GIS 서버 구축은 제외하고, 지역-지점 관계 모델, 지역별 지점 수 집계 쿼리, 중복 ID 거절(제약조건) 테스트를 수행합니다. 시간 제약으로 인해 성능 튜닝·대규모 데이터 적재는 수행하지 않습니다.

### 1. 요구·모델 설계

- 목표: 핵심 엔티티와 관계 정의, 중복 ID를 방지할 제약조건 설계
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 요구(지역별 지점 수 조회, 중복 ID 거부)를 3개 항목으로 정리
- 활동: 엔티티(지역, 지점)와 최소 속성 목록 작성
- 활동: ER 다이어그램(간단한 표기) 작성 및 정규화 수준(최소 3NF) 검토
- 활동: 중복 ID를 막을 제약조건(예: UNIQUE 또는 PK) 설계
- 산출물: 요구사항 3개 항목 문서(간단한 텍스트)
- 산출물: ER 다이어그램(이미지 또는 텍스트 표기)
- 산출물: 제약조건 목록(중복 ID 방지 규칙 포함)
- 완료 기준: ER 다이어그램과 제약조건 목록이 작성되어 지역별 지점 수 질의와 중복 ID 거절 요구를 충족하는 모델이 도출되어야 함.
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. 구현·검증

- 목표: 테이블 생성, 샘플 데이터 적재, 지역별 지점 수 쿼리 실행 및 중복 ID 거절 테스트
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 선택한 RDBMS(예: SQLite/PostgreSQL/MySQL 중 사용 가능한 환경)에서 DDL 작성 및 테이블 생성
- 활동: 샘플 데이터(지역 3개, 지점 8개 등) 삽입
- 활동: 지역별 지점 수를 반환하는 SQL(예: GROUP BY) 작성 및 결과 확인
- 활동: 중복 지점 ID 삽입 시 제약조건으로 거부되는지 테스트(예외 발생 확인)
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: 지역별 지점 수 쿼리 및 실행 결과 스냅샷
- 산출물: 중복 ID 삽입 시도와 실패 로그(또는 제약조건 위반 메시지)
- 완료 기준: 지역별 지점 수 쿼리가 예상 결과(샘플 데이터 기준)를 반환하고, 중복 ID 삽입 시 DB가 제약조건 위반으로 거부해야 함.
