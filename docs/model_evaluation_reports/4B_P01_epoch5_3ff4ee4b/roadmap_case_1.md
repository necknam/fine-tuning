# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선 최소 RAG 시제품: 2주(총 6시간) — 가상 규정 기반 근거 표시·거부 기능

주당 3시간, 총 2주(총 6시간) 안에 가상 규정 3건과 질문 5건을 사용해 검색 인덱싱, 쿼리·정합성 검사, 간단한 RAG 파이프라인(검색→응답)과 근거 표시/거부 기능을 구현하고 검증합니다. 예산 20,000원은 선택적 유료 자료 구매 여지를 남깁니다(현재 추천 목록에는 유료 항목이 없음).

### 1. 사전점검·환경·데이터 준비

- 목표: 가상 규정 3건의 메타데이터(문서ID, 페이지/절, 요약)와 5개 질문 정의 및 로컬 검색 인덱스 준비
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건의 구조(문서ID, 본문, 메타데이터)를 간단히 작성(각 문서 1~2페이지 분량 요약)
- 활동: 5개 질문(정답이 있는 근거 포함)을 정의하고 정답-문서 매핑을 작성
- 활동: 로컬 파일 기반 검색(예: FAISS 또는 간단한 inverted index)으로 인덱스 생성
- 산출물: 가상 규정 3건의 메타데이터 파일(CSV/JSON)
- 산출물: 5개 질문과 정답-문서 매핑 파일
- 산출물: 로컬 검색 인덱스 파일
- 완료 기준: 미확인

### 2. 검색·정합성 검증 및 RAG 프로토타입

- 목표: 검색 결과의 정합성(정확한 문서ID 반환)을 검증하고, 검색 결과를 생성 모델에 주입해 답변 생성 후 근거 표시/거부 로직을 구현
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 쿼리 5건 실행하여 검색 성공/실패/정합성 실패를 기록
- 활동: 간단한 RAG 파이프라인 구현(검색 → 컨텍스트 주입 → LLM 호출 → 근거 추출/표시/거부)
- 활동: 정답-문서 매핑과 실제 반환 문서ID를 비교하여 정합성 지표(정확도, 누락률) 계산
- 산출물: 검색 결과 로그(쿼리별 반환 문서ID 및 정합성 결과)
- 산출물: RAG 프로토타입 코드(검색·LLM 호출·근거 처리 포함)
- 산출물: 정합성 검증 결과(정확도·누락률 표)
- 완료 기준: 미확인

### 3. 검증·비교·문서화

- 목표: 검색 성공/누락/정합성 실패 사례를 정리하고, RAG 응답의 근거 표시·거부 동작을 문서화하여 재현 가능한 체크리스트로 정리
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 성공·근거 누락·답변 불가 사례를 분류하고 각 사례에 대한 원인·대응을 기록
- 활동: 간단한 테스트 케이스(5개 질문)로 근거 표시·거부 동작을 재현
- 활동: 최종 결과와 한계(데이터 규모·모델 한계·운영 전 추가 작업)를 문서화
- 산출물: 검증 보고서(검색 정합성 지표, 사례별 분석)
- 산출물: 재현 가능한 테스트 케이스와 실행 방법
- 산출물: 최종 요약(다음 단계 권장사항 포함)
- 완료 기준: 미확인
