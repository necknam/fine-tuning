## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

2주 시간 우선 RAG 시제품: 검색 근거 연결과 질문-답변 책임성 검증

총 2주(주당 3시간, 총 6시간) 동안 가상 규정 3건과 질문 5건을 사용해 검색 기반 근거 연결과 RAG 기반 답변 책임성 검증을 수행합니다. 단계별로 환경 준비·검색·정제·응답 검증·회고를 진행하며 각 단계의 산출물과 완료 기준을 명확히 합니다. 예산은 소규모 유료 자료 구매나 유료 툴 사용을 위한 여유금으로 남깁니다(사용자 확인 필요).

### 1. 환경 준비 및 데이터 준비

- 목표: 가상 규정 3건의 텍스트를 정리하고 검색 인덱스에 적재
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건의 구조(문서/절/문단)를 정의하고 샘플 1건씩 추출
- 활동: 간단한 검색 인덱스(예: 로컬 FAISS 또는 SQLite+인벤토리) 생성 및 문서 적재
- 활동: 검색 쿼리 샘플 5건 작성(각 규정별 1~2건 포함)
- 산출물: 정제된 규정 문서 3건(텍스트 파일 또는 JSON)
- 산출물: 검색 인덱스 파일(로컬) 및 적재 로그
- 산출물: 쿼리 샘플 5건 목록
- 완료 기준: 미확인

### 2. 검색·정제·응답 검증

- 목표: 질문 5건에 대해 검색 결과를 연결하고 근거 표시·거부 규칙을 적용해 응답을 검증
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 문서 ID로 연결하는 간단한 매핑 규칙 구현
- 활동: 응답에 근거 문서를 표시하는 출력 포맷(예: [evidence_id]) 정의
- 활동: 검색 실패·중복·잘못된 문서 연결 사례를 3개 이상 생성하고 원인 분류
- 산출물: 검색-응답 매핑 스크립트(간단한 Python 스크립트)
- 산출물: 5건의 질문-응답 예시(각에 근거 문서 ID 표시 또는 '거부' 표기)
- 산출물: 검색 실패 사례 목록 및 원인 분류
- 완료 기준: 미확인

### 3. 회고 및 개선 계획

- 목표: 검색 실패·누락 사례를 정리하고 다음 실험 우선순위를 결정
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 실패·누락·잘못된 연결 사례의 원인별 우선순위화
- 활동: 다음 2주 내 실험(예: RAG 통합, 프롬프트 전략 개선) 제안서 작성
- 활동: 프로젝트 산출물 정리(코드·데이터·결과 요약)
- 산출물: 실패 원인 분석 보고서(간단한 표와 권장 조치 포함)
- 산출물: 다음 실험 우선순위 목록(최대 3개)
- 산출물: 프로젝트 산출물 압축(코드·데이터·요약)
- 완료 기준: 미확인
