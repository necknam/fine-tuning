# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

기존 검색 코드 기반 근거 누락 검출·회귀 시험 추가(업무 적용 우선)

1주(총 4시간) 동안 기존 검색 코드의 입력·출력 계약을 고정하고, 근거 없는 주장 발생 조건을 분리한 테스트 케이스를 추가합니다. 새 기능은 기존 코드에 최소 변경으로 통합하며 단위 테스트와 회귀 실행으로 검증합니다. 추가 시간·예산을 임의로 확정하지 않습니다.

### 1. 계약 고정 및 실패 조건 정의

- 목표: 입력 문서·질문·기대 답변·출력 메타데이터(원문 인용)를 고정하고 근거 없는 주장 판정 기준을 문서화
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 코드의 입력/출력 샘플 5개 수집(이미 작성된 코드 기반)
- 활동: 출력에 원문 인용 또는 근거 미발견 플래그가 포함되어야 함을 계약으로 명시
- 활동: 근거 없는 주장 판정 규칙(예: 근거 미발견일 때 확신도 낮음·원문 인용 누락)을 1페이지로 정리
- 산출물: 입력/출력 계약 문서(간단한 JSON 스키마 포함)
- 산출물: 근거 없는 주장 판정 규칙 문서
- 완료 기준: 미확인

### 2. 검출 로직 최소 구현 및 테스트 작성

- 목표: 기존 코드에 최소 변경으로 근거 누락/잘못된 인용을 탐지하는 함수를 추가하고 단위 테스트를 작성해 로컬에서 통과
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 파이프라인에 인용 검증 단계(문서 매칭 확인·원문 추출) 최소 구현
- 활동: 정확히 실패하는 케이스 3개와 정상 케이스 2개를 포함한 단위 테스트 작성
- 활동: 로컬에서 테스트 실행 및 실패 시 원인 로그 수집
- 산출물: 코드 패치(검출 함수 및 테스트)
- 산출물: 테스트 실행 결과(통과/실패 로그)
- 완료 기준: 미확인
