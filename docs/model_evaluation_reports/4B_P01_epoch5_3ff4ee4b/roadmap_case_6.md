# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선 소규모 RAG 시제품: 최소 구현으로 근거 확인 흐름 검증

주어진 제약(총 2주, 주 3시간, 예산 10,000원)을 우선 반영하여 범위를 작은 검색 시제품(문서 인덱싱 + 쿼리·정답 확인)으로 축소합니다. 외부 유료 서비스나 추가 인력을 전제로 하지 않고, 오픈소스 도구와 로컬 환경으로 구현·검증을 완료하도록 설계합니다. 지원금 가능성은 미확정하므로 예산에서 차감하지 않습니다.

### 1. 환경 준비 및 데이터 준비

- 목표: 로컬 개발 환경과 소규모 문서셋(예: 10~50문장) 준비
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 개발 환경(파이썬, 가상환경, 필요한 라이브러리) 설치 및 간단 실행 확인
- 활동: 테스트용 문서 10~50문장 수집(공개 데이터 또는 합성) 및 메타데이터(문서ID, 출처) 추가
- 활동: 간단한 데이터 전처리(텍스트 정규화, 토큰화) 스크립트 작성
- 산출물: 환경 설치 체크리스트(설치한 패키지 목록 포함)
- 산출물: 테스트 문서셋(파일)과 전처리 스크립트
- 완료 기준: 미확인

### 2. 간단한 RAG 파이프라인 구현

- 목표: 문서 인덱싱과 검색(벡터 유사도) 구현 및 생성 모델에 근거 삽입
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 문서 벡터화(로컬 임베딩 모델 또는 경량 오픈소스 임베딩 사용) 및 인덱스 생성
- 활동: 검색(벡터 유사도 기반) 구현 및 상위 k 문서 반환 로직 작성
- 활동: 생성 모델(로컬 또는 무료 API)에 검색 결과를 근거로 삽입하여 응답 생성
- 활동: 간단한 로그·메트릭(검색된 문서ID, 응답에 포함된 근거 문장) 기록
- 산출물: 인덱스 생성 스크립트 및 샘플 쿼리 실행 결과
- 산출물: 생성 응답 예시(각 응답에 근거 문장 ID 표시)
- 완료 기준: 미확인
- 추천 자료: Microsoft Foundry를 사용하여 생성 AI 모델 성능 최적화 · ID MS_df219eb945ff · DB 비용 0.00원 · 이용 상태 미확인
- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi

### 3. 검증·문서화 및 비용·한계 정리

- 목표: 정합성 테스트 실행, 결과 문서화, 향후 확장·비용 고려사항 정리
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 정합성 테스트(예: 10개 쿼리) 실행하여 검색 결과와 생성 응답의 근거 일치 여부 확인
- 활동: 간단한 평가 지표(정확도, 근거 포함 여부 등) 계산 및 결과 기록
- 활동: 프로젝트 요약 문서 작성(사용한 도구, 비용 추정, 한계 및 다음 단계 제안)
- 산출물: 정합성 테스트 결과표(쿼리별 검색 결과·응답·정합성 여부)
- 산출물: 프로젝트 요약 문서(최소 1페이지)
- 완료 기준: 미확인
