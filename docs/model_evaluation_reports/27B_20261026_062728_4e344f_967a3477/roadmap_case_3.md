- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실무형 RDBMS 모델링·검증 로드맵

주어진 2주(총 6시간) 동안 실무 적용을 우선해 관계형 DB 모델링과 핵심 검증(지역별 지점 수 쿼리, 중복 ID 거절)을 완료한다. 시간 제약이 있으므로 설계·구현·검증을 최소한의 범위로 압축하고, 산출물은 ER 다이어그램, DDL, 검증 쿼리 및 테스트 결과로 한정한다.

### 1. 데이터 모델링 및 스키마 구현

- 목표: 가상 지점과 지역의 관계형 데이터 모델을 설계하고 DDL로 구현하여 샘플 데이터를 로드한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 요구사항(지역-지점 관계, 필수 속성, 제약조건) 정리
- 활동: ER 다이어그램 작성(엔티티, 관계, PK/FK 정의)
- 활동: DDL 작성(테이블 생성, 인덱스, 제약조건 포함)
- 활동: 샘플 데이터 생성 및 로드
- 산출물: ER 다이어그램(엔티티·관계·PK/FK 명시)
- 산출물: DDL 스크립트(테이블 생성, 인덱스 포함)
- 산출물: 샘플 데이터(지역 5개, 지점 20개 등) 로드 스크립트
- 산출물: 간단한 검증 쿼리(지역별 지점 수, 중복 ID 삽입 시도 및 실패 로그)
- 완료 기준: 미확인

### 2. 쿼리 작성·검증 및 성능 확인

- 목표: 지역별 지점 수를 반환하는 SQL을 작성하고, 중복 ID 삽입 시 제약조건이 올바르게 작동하는지 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 지역별 지점 수를 반환하는 SQL 작성 및 실행
- 활동: 중복 ID 삽입 시 FK/PK 제약으로 거부되는지 테스트
- 활동: 간단한 성능 측정(쿼리 실행 시간 비교) 및 인덱스 효과 확인
- 활동: 테스트 케이스 문서화 및 결과 요약
- 산출물: 검증 쿼리 목록(지역별 지점 수, 중복 ID 삽입 시도 결과)
- 산출물: 간단한 성능 측정 결과(쿼리 실행 시간 비교)
- 산출물: 테스트 케이스와 기대 결과 문서
- 산출물: 최종 요약 보고서(문제점·개선안 포함)
- 완료 기준: 미확인
