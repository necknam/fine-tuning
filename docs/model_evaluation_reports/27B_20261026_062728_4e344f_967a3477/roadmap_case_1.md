# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선 — 로컬 재현 중심의 실습 로드맵

사용자 제공 제약(총 2주, 주 3시간, 예산 0원)을 반영해 로컬 환경에서 최소한의 코드와 실험으로 동시성 문제를 재현하고 잠금 적용 전후의 로그를 비교하는 실습 중심 로드맵을 제시합니다. 외부 유료 서비스나 추가 인건비는 사용하지 않습니다. 제공된 K-MOOC 강좌는 참고 자료로 연결하되, 비용·시간이 확인되지 않은 자료는 확정 비용으로 간주하지 않습니다.

### 1. 재현 및 베이스라인 수집

- 목표: 로컬에서 스레드 두 개가 공유 카운터를 증가시키는 간단한 프로그램을 작성하고, 잠금 미적용 상태에서 카운터 불일치(경합)를 재현하여 로그를 수집한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발환경 준비(컴파일러/인터프리터, 빌드 도구 확인)
- 활동: 간단한 공유 카운터 프로그램 작성(스레드 2개, 반복 증가)
- 활동: 잠금 미적용 상태에서 여러 번 실행하여 로그 수집
- 활동: 재현 결과(예: 최종 카운터 값이 기대값과 다른 경우)를 기록
- 산출물: 간단한 재현 코드(예: C 또는 Python) — 스레드 두 개가 공유 카운터를 증가시키는 프로그램
- 산출물: 잠금 미적용 실행 로그(예: 10회 반복 실행 결과)
- 산출물: 잠금 적용(뮤텍스/세마포어) 후 실행 로그(동일 반복 횟수)
- 산출물: 간단한 비교 표(잠금 전후의 최종 카운터 값 분포)
- 완료 기준: 미확인

### 2. 잠금 적용 및 비교 분석

- 목표: 잠금(뮤텍스/세마포어/원자 연산)을 적용하여 경합을 제거하고, 잠금 적용 전후의 로그를 비교해 차이를 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 잠금 적용(뮤텍스 또는 세마포어 또는 원자 연산 중 하나 선택)
- 활동: 잠금 적용 후 동일 조건으로 반복 실행하여 로그 수집
- 활동: 잠금 전후 로그 비교(최종 카운터 값, 실행 시간 등)
- 활동: 간단한 분석 노트 작성(문제 원인, 해결 방식, 한계)
- 산출물: 잠금 적용된 코드(뮤텍스/세마포어/원자 연산 중 하나 사용)
- 산출물: 잠금 적용 전후의 로그 비교 파일
- 산출물: 간단한 분석 노트(왜 잠금이 문제를 해결하는지, 성능 영향에 대한 관찰)
- 완료 기준: 미확인
