# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선 — 문서 기반 권한 점검(1주, 3시간)

주어진 1주(총 3시간) 동안 가상 서비스의 읽기·쓰기 권한표를 작성하고, 그 표를 근거로 과도한 권한 3가지를 식별·문서화한다. 비용 우선 관점에서 유료 서비스·외부 API 호출은 사용하지 않으며, 산출물은 권한표와 과도 권한 목록 및 간단한 개선 권고로 제한한다.

### 1. 권한표 작성 및 과도 권한 식별

- 목표: 가상 서비스의 읽기·쓰기 권한을 표로 정리하고, 그 표를 근거로 과도한 권한 3가지를 식별·문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 서비스(예: Compute, Storage, Network, IAM) 목록을 정의하고 각 서비스의 핵심 읽기·쓰기 권한 항목을 표로 작성
- 활동: 권한표에서 권한 범위(전역/리소스 수준), 주체(관리자/운영자/읽기 전용 등)를 비교하여 과도한 권한 후보 3개를 선정
- 활동: 각 과도한 권한에 대해 위험(예: 데이터 유출, 권한 상승)과 간단한 완화 권고를 문서화
- 활동: 결과를 1페이지 분량의 요약 문서로 정리
- 산출물: 가상 서비스 목록(예: Compute, Storage, Network, IAM)과 각 서비스별 읽기·쓰기 권한 항목을 정리한 권한표(간단한 표 형식)
- 산출물: 권한표에 근거한 과도한 권한 3개 항목과 그 위험 설명(각 항목별 1~2문장)
- 산출물: 간단한 개선 권고(권한 축소 또는 분리 방안) 3개
- 완료 기준: 미확인
