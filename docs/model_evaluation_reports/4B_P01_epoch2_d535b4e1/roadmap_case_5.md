# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 우선의 소규모 회귀·누락 검출 추가

1주(총 4시간) 동안 기존 검색 코드의 검증 부재를 확인하고, 최소한의 회귀 테스트와 누락 검출 체크리스트를 추가하여 재현 가능한 테스트 케이스를 확보합니다. 비용은 0원이며 추가 자료는 필요시 확인합니다.

### 1. 검증 부재 확인 및 최소 회귀·누락 추가

- 목표: 기존 검색 코드의 핵심 동작을 재현하고, 근거 누락·출처 미포함 사례를 탐지하는 최소 테스트를 추가
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 코드(문서 분할·검색)의 핵심 입력·출력·예상 결과를 문서화(간단한 체크리스트)
- 활동: 핵심 기능(예: 문서 검색 결과의 출처 포함 여부)에 대해 최소 3개의 회귀 테스트 케이스 작성
- 활동: 테스트 케이스에 근거 누락(문서 ID·출처 미포함)을 의도적으로 포함하여 탐지 여부 확인
- 활동: 간단한 자동화 스크립트(예: pytest 또는 간단한 shell 스크립트)로 테스트 실행 및 결과 기록
- 산출물: 핵심 동작 문서(간단한 체크리스트, 입력/출력 예시)
- 산출물: 3개 이상의 회귀 테스트 케이스(테스트 코드 또는 스크립트)
- 산출물: 테스트 실행 결과(로그 또는 간단한 결과 파일)
- 완료 기준: 작성한 회귀 테스트가 로컬에서 실행되어 기대 결과(출처 포함 여부 등)를 재현하거나, 누락 사례가 탐지되는 것을 확인하면 완료로 간주. 테스트가 실패하거나 재현 불가하면 원인(환경·의존성)을 기록하고 추가 확인 항목을 남김.
