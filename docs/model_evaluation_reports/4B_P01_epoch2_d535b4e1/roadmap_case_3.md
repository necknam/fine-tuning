## 계획

2주 실무형 RAG 시제품: 가상 규정 기반 근거 표시·거부 시제품

사용자의 제약(기간 2주, 주당 3시간, 예산 20,000원)을 반영하여 최소 기능의 RAG 시제품을 구현합니다. 목표는 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 것. 각 단계는 실제 작업·산출물·완료 기준을 포함하며, 단계 시간 합계는 사용자 가용 시간(총 6시간) 내에 맞춥니다. 추가 유료 자료·승인·운영은 사용자가 별도로 확인해야 합니다.

### 1. 환경·데이터 준비 및 검색 파이프라인 구성

- 목표: 가상 규정 3건(문서)을 로컬 인덱스로 준비하고, 간단한 검색(벡터 또는 키워드) 파이프라인을 구성하여 문서 검색을 수행할 수 있게 함
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건의 텍스트를 준비(각 문서 1~2페이지 분량으로 요약)
- 활동: 로컬 벡터 인덱스(예: FAISS 또는 유사한 오픈소스) 또는 키워드 인덱스 구성
- 활동: 검색 쿼리(5개 질문)를 작성하고 검색 결과 반환을 확인
- 산출물: 가상 규정 3건의 텍스트 파일(또는 JSON)
- 산출물: 검색 인덱스 파일 및 검색 쿼리 목록(5개 질문)
- 산출물: 검색 결과 샘플(각 질문에 대해 반환된 문서 ID 또는 스니펫)
- 완료 기준: 5개 질문 중 최소 3개에 대해 검색이 문서 스니펫을 반환하고, 반환된 스니펫이 질문과 관련이 있는지 수동으로 확인 가능해야 함

### 2. RAG 연결·응답 검증 및 문서화

- 목표: 검색 결과를 생성형 AI(로컬/오픈소스)에 연결해 답변을 생성하고, 답변에 근거 문서를 표시하거나 근거가 없을 때 '근거 없음'을 반환하도록 검증
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 생성형 AI 입력에 연결(검색 문맥 주입)
- 활동: 간단한 프롬프트 템플릿으로 답변 생성 및 근거 표시(문서 ID 또는 스니펫 포함) 구현
- 활동: 5개 질문을 대상으로 답변·근거 표시·근거 없음 판정을 검증하고 결과 기록
- 산출물: RAG 연결 코드(검색→LLM 입력 연결)와 실행 스크립트
- 산출물: 5개 질문의 답변·근거 표시 결과(각 답변에 근거 문서 ID 또는 스니펫 포함)
- 산출물: 간단한 검증 보고서(정답/오답·근거 유무 표기)
- 완료 기준: 5개 질문 중 최소 3개에 대해 답변이 생성되고, 답변에 근거 문서 ID 또는 스니펫이 표시되거나 '근거 없음'이 명시되어야 함
