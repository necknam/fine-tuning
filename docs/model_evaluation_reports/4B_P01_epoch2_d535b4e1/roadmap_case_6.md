- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원

- 활동: 최소 구현 범위(예: 문서 인덱싱 10건, 검색·정렬·응답 10건)와 필요한 기술(예: 로컬 벡터 인덱스, 간단한 프롬프트 템플릿)을 정의
- 활동: 비용·시간 제약 내 산출물 목록(간단한 README, 샘플 데이터, 테스트 케이스) 작성
- 산출물: 요구·검증 1페이지(사용 목적·입력·출력·검증 기준)
- 산출물: 최소 구현 범위 문서(필요 기술·예상 시간·예상 비용)
- 산출물: 샘플 데이터(10건)와 테스트 케이스(10건)
- 완료 기준: 요구·검증 1페이지와 최소 구현 범위 문서가 작성되어, 10건 샘플 데이터와 테스트 케이스가 준비되어 있으면 완료로 간주
