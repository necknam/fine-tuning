# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선 2주 실습: 가상 문서 검색 실패 재현 및 원인 기록

사용자의 제한된 시간(총 4시간)과 예산(0원)을 반영하여, 이미 준비된 Python 환경과 가상 문서만으로 RAG 검색 실패를 재현하고 원인을 문서화하는 실습 로드맵입니다. 외부 유료 자료·추가 설치 없이 완료 가능한 범위로 설계했습니다.

### 1. 환경 점검 및 실패 재현

- 목표: 가상 문서 3건에 대해 검색 실패를 재현하고 실패 유형을 분류
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건 준비(이미 준비된 문서 사용)
- 활동: 간단한 검색/인덱스 스크립트 실행(이미 준비된 Python 환경 사용)
- 활동: 실패 케이스 3건 수집 및 실패 유형(예: 문서 미인덱스, 토큰 길이 초과, 쿼리 불일치) 분류
- 산출물: 실패 재현 로그(각 문서별 실패 사례 3건)
- 산출물: 실패 유형 분류표(간단한 CSV 또는 텍스트)
- 완료 기준: 각 문서에 대해 실패를 재현하고 실패 유형을 분류하여 문서화. 성공/실패 기준(재현 가능성 확인)을 기록.

### 2. 원인 분석 및 개선 기록

- 목표: 실패 원인을 분류하고 개선 포인트를 문서화하여 성공/실패 기준을 정리
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 실패 유형별 원인 가설 작성(예: 인덱스 누락, 토큰 제한, 쿼리 정규화 문제)
- 활동: 간단한 수정(예: 인덱스 재빌드, 토큰 길이 조정, 쿼리 전처리) 적용 및 재실행
- 활동: 수정 전후 결과를 비교하여 성공/실패 기준을 정리
- 산출물: 원인 분석 문서(각 실패 유형별 원인·가설·수정 방법)
- 산출물: 수정 전후 비교 결과(간단한 로그 또는 표)
- 산출물: 최종 성공/실패 기준 문서
- 완료 기준: 각 실패 유형에 대해 원인 가설과 최소한의 수정 방법을 제시하고, 수정 전후 결과를 비교하여 성공/실패 기준을 문서화.
