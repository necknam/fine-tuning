## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선 최소 RAG 시제품(2주, 6시간)

2주(총 6시간) 동안 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품을 만듭니다. 단계별 산출물과 완료 기준을 명시하며, 추가 비용·기간이 확인되지 않으면 유료 자료·확장 일정을 확정하지 않습니다.

### 1. 환경·데이터 준비

- 목표: 가상 규정 3건과 5개 질문을 정리하고 검색용 인덱스(간단한 텍스트 인덱스)를 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서 텍스트)과 5개 질문을 문서화(각 문서에 메타데이터: 문서ID, 페이지/절 포함)
- 활동: 간단한 텍스트 인덱스 생성(예: Python의 FAISS 또는 간단한 inverted index) 및 검색 테스트
- 활동: 검색 결과와 질문의 매핑을 표로 정리
- 산출물: 문서 목록(3건)과 각 문서의 메타데이터 파일
- 산출물: 5개 질문과 예상 답변(간단한 정답) 목록
- 산출물: 검색 인덱스 파일 및 검색 테스트 로그(검색 결과 스냅샷)
- 완료 기준: 검색 인덱스에서 5개 질문 중 최소 3건에 대해 관련 문서를 찾아내고, 검색 결과와 질문 매핑 표가 완성되어 있어야 함

### 2. 최소 RAG 구현·검증

- 목표: 검색 결과를 생성형 모델에 연결해 답변을 생성하고, 근거 표시·근거 없는 질문 판별을 검증
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 생성형 모델(로컬 또는 무료 API)에 입력해 답변 생성 파이프라인 구성
- 활동: 답변에 근거 문서를 표시하는 포맷(예: [source: 문서ID])을 적용하고 샘플로 검증
- 활동: 근거 없는 질문(검색 결과 없음)과 검색 성공·누락 사례를 분류해 표로 정리
- 산출물: 최소 동작하는 RAG 시제품 코드(검색→생성→근거 표시)
- 산출물: 검증 보고서(5개 질문별 검색 결과, 생성 답변, 근거 표시 여부, 판정 근거)
- 산출물: 간단한 사용법(README) 및 실행 스크립트
- 완료 기준: 시제품이 5개 질문 중 최소 3건에 대해 검색 결과를 근거로 답변을 생성하고, 근거 표시와 '근거 없음' 판정을 문서화하여 검증 보고서가 완성되어야 함
