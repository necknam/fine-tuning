# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선의 RAG·생성형 에이전트 실습 로드맵 (2주)

사용자의 제약(기간 2주, 주당 3시간, 예산 0원)을 반영하여 외부 유료 자료·확정된 승인 없이도 수행 가능한 실습 중심 로드맵을 제안합니다. 각 단계는 실제 산출물(코드·노트북·검증 리포트)을 목표로 하며, 제공된 무료 강좌 ID만 권장 자료로 연결합니다. 규정·지원금 승인 여부는 확인이 필요하므로 규정 인용은 하지 않습니다.

### 1. 환경 준비 및 기초 실습

- 목표: 로컬/가상환경에서 RAG 파이프라인의 핵심 흐름을 구현하고 검색 결과와 문서 근거를 대조하는 최소 시제품 완성
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 개발 환경(가상환경, Python 패키지) 설정 및 샘플 문서(가상 PDF/텍스트) 준비
- 활동: 간단한 검색(벡터 또는 키워드) + LLM 응답 파이프라인 구현(로컬 또는 무료 API 사용 가능 범위 내)
- 활동: 검색 결과와 원문 근거를 매핑하는 스크립트 작성 및 샘플 쿼리 10건 실행
- 산출물: 환경 설정 가이드(README)와 실행 스크립트
- 산출물: 최소 동작하는 RAG 시제품 코드(노트북 또는 스크립트)
- 산출물: 검색 결과-원문 근거 매핑 표(샘플 10건)
- 완료 기준: 시제품이 로컬에서 실행되어 10건 샘플 쿼리에 대해 검색 결과와 원문 근거를 매핑한 표가 생성되어야 완료로 인정
- 추천 자료: Microsoft Foundry를 사용하여 생성 AI 모델 성능 최적화 · ID MS_df219eb945ff · DB 비용 0.00원 · 이용 상태 미확인
- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi

### 2. 프롬프트·추적·검증 개선

- 목표: 프롬프트 전략과 추적 정보를 활용해 검색 결과의 신뢰성·정합성을 검증하고 개선 가능한 지점을 문서화
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 동적 컨텍스트 주입·프롬프트 변형 실험(샘플 쿼리 5건)
- 활동: 추적(로그/메타데이터)을 수집해 검색 단계와 응답 단계의 불일치를 확인
- 활동: 검증 리포트 작성(검색 결과-원문 일치 여부, 오류 유형, 개선 권고)
- 산출물: 프롬프트 변형 실험 노트(실험 설정과 결과)
- 산출물: 추적 로그와 분석 요약(불일치 사례 포함)
- 산출물: 최종 검증 리포트(개선 권고 포함)
- 완료 기준: 프롬프트 변형과 추적 로그를 통해 최소 3건의 불일치 사례를 식별하고 개선 권고를 포함한 검증 리포트가 작성되어야 완료로 인정
