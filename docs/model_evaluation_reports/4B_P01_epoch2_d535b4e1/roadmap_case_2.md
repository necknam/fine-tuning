## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

시간 우선 최소 RAG 시제품: 2주(총 6시간) — 가상 규정 기반 근거 표시·분류

사용자의 제한된 시간(2주, 주 3시간)과 예산(20,000원)을 반영하여, 가상 규정 3건과 질문 5건을 대상으로 최소 기능의 RAG 시제품을 구현합니다. 목표는 검색 성공·근거 누락·답변 불가 사례를 구분하고, 각 답변에 근거 출처를 표시하는 것입니다. 추가 비용·유료 자료는 사용자의 확인 없이 임의로 도입하지 않습니다.

### 1. 환경 준비 및 데이터 준비

- 목표: 가상 규정 3건과 질문 5건을 정리하고, 검색용 인덱스(간단한 텍스트 인덱스)를 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서)과 질문 5건 목록 작성
- 활동: 문서 전처리(간단한 토큰화/정제) 및 로컬 인덱스 생성(예: FAISS 또는 간단한 SQLite 기반 검색)
- 활동: 검색 정확도 체크용 샘플 쿼리 5건 준비
- 산출물: 문서 목록(3건)과 질문 목록(5건) 파일
- 산출물: 로컬 인덱스 파일 및 검색 테스트 결과(간단한 로그)
- 완료 기준: 문서 3건이 로컬 인덱스에 인덱싱되어, 준비한 5개 샘플 쿼리 중 최소 3건에 대해 검색 결과가 반환되는 것을 확인

### 2. 최소 RAG 구현 및 검증

- 목표: 검색 결과를 기반으로 답변을 생성하고, 각 답변에 근거 출처를 표시·검증
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 가져와 간단한 템플릿 기반 응답 생성(검색 문맥 + 시스템 메시지 포함)
- 활동: 답변에 근거 출처(문서 ID 또는 문장 위치)를 표시하도록 구현
- 활동: 검증: 각 질문 5건에 대해 검색 성공/누락/답변 불가 분류 및 근거 표시 여부 확인
- 산출물: 최소 RAG 시제품 코드(검색→응답 파이프라인)
- 산출물: 검증 리포트(5개 질문별 검색 결과·출처 표시 여부·분류)
- 완료 기준: 5개 질문 중 최소 3건에 대해 검색 결과가 반환되고, 각 답변에 근거 출처가 표시되어 있어 '근거 없는 질문'을 구분할 수 있음
