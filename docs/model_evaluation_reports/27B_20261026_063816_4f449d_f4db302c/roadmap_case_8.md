- 목표: 가상 서비스(예: 가상 스토리지, 가상 VM, 가상 DB)에 대해 읽기·쓰기 권한을 표로 정리하고, 과도한 권한 3가지를 선정·설명한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 서비스 목록(3개)과 각 서비스의 핵심 리소스(예: 객체, 인스턴스, 테이블)를 정의한다.
- 활동: 각 리소스에 대해 읽기·쓰기 권한을 행/열로 배치한 권한 매트릭스(간단한 표)를 작성한다.
- 활동: 매트릭스를 바탕으로 과도한 권한(예: 불필요한 쓰기 권한, 광범위한 관리자 권한, 불필요한 삭제 권한) 3가지를 선정하고 각각의 위험과 완화 방안을 1~2문장으로 기술한다.
- 활동: 결과를 1페이지 분량의 문서(권한 매트릭스 표 + 과도 권한 목록 및 완화 제안)로 정리한다.
- 산출물: 권한 매트릭스 표(가상 서비스 3개, 각 리소스에 대한 읽기·쓰기 권한 표시)
- 산출물: 과도한 권한 3건 목록 및 각 항목에 대한 위험 설명과 간단한 완화 제안(각 1~2문장)
- 산출물: 최종 1페이지 요약 문서(권한 매트릭스 스냅샷 포함)
