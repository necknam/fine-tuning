## 계획

2주 실습형: 스레드 동시성 오류 재현 및 잠금 적용 비교

주어진 2주(총 6시간) 동안 로컬 환경에서 스레드 두 개가 공유 카운터를 동시에 증가시키는 간단한 프로그램을 작성해 동시성 오류(경합)를 재현하고, mutex 적용 전후의 로그를 비교해 차이를 문서화한다. 비용 우선 관점에서 유료 서비스나 추가 장비는 사용하지 않으며, 로컬 개발환경(컴파일러, 텍스트 에디터, 터미널)만 사용한다.

### 1. 환경 준비 및 재현 코드 작성

- 목표: 로컬에서 컴파일·실행 가능한 최소 재현 코드(스레드 2개, 공유 카운터)를 작성하고 동시성 오류를 관찰할 수 있도록 한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발환경 확인(컴파일러, 텍스트 에디터, 터미널) — 0.5시간
- 활동: 간단한 C 또는 C++ 스레드 프로그램 작성: 두 스레드가 공유 카운터를 N회 증가시키는 코드 — 1시간
- 활동: 동시성 오류 재현: 여러 번 실행해 카운터 값이 기대치와 다른 경우를 기록(로그 캡처) — 0.5시간
- 활동: 재현 결과(로그 스냅샷)와 재현 절차(명령어, 실행 횟수)를 README에 정리 — 0.5시간
- 산출물: 재현 코드(소스 파일) — 스레드 2개, 공유 카운터
- 산출물: 재현 실행 로그(잠금 미적용 상태) — 최소 3회 실행 결과
- 산출물: README: 재현 절차와 관찰된 오류 요약
- 완료 기준: 미확인

### 2. 잠금 적용 및 비교 분석

- 목표: mutex(또는 동등한 동기화 기법)를 적용해 재현 코드를 수정하고, 잠금 적용 전후의 로그를 비교해 차이를 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 잠금 적용: mutex 또는 동등한 동기화 기법으로 공유 카운터 접근을 보호 — 1시간
- 활동: 잠금 적용 후 동일 조건으로 여러 번 실행해 로그 수집 — 0.5시간
- 활동: 잠금 적용 전후 로그 비교(예: 카운터 값 분포, 실패 빈도) 및 간단한 분석 작성 — 0.5시간
- 활동: 결과 요약(문제 원인, 적용 방법, 한계)을 README에 추가 — 0.5시간
- 산출물: 잠금 적용된 코드(소스 파일)
- 산출물: 잠금 적용 후 실행 로그(최소 3회 실행 결과)
- 산출물: 비교 분석 문서: 잠금 적용 전후의 로그 차이와 간단한 해석
- 완료 기준: 미확인
