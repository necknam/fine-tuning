- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

1주 집중 실습: SQLite 기반 재고 데이터 모델링 및 JOIN 검증

주어진 제약(총 1주, 주당 4시간, 예산 0원)을 반영해 로컬 SQLite 환경에서 재고 품목·입출고 테이블을 설계하고 외래키·JOIN 결과를 검증하는 실습 중심 로드맵을 제시합니다. 시간 우선 관점에서 핵심 산출물(DDL, 샘플 데이터, 검증 쿼리, 결과 스크린샷)을 4시간 내에 완성하도록 단계별로 분배합니다.

### 1. 환경 준비 및 요구사항 정리

- 목표: 로컬 SQLite 사용 준비(예: sqlite3 CLI 또는 Python sqlite3 모듈)와 실습 범위 확정
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬에 sqlite3 설치 또는 Python sqlite3 모듈 확인
- 활동: 실습에서 사용할 샘플 데이터 항목(예: 5개 품목, 10건 입출고) 정의
- 활동: 검증 기준(예: JOIN 결과 행 수, NULL 처리, 외래키 위반 시 동작) 문서화
- 산출물: 환경 준비 체크리스트(사용한 도구·버전)
- 산출물: 실습 범위 및 검증 기준 문서(간단한 텍스트)
- 완료 기준: 로컬에서 sqlite3로 빈 DB를 생성하고 샘플 데이터 항목 목록을 문서화함

### 2. 테이블 설계 및 DDL 작성

- 목표: 품목(items)과 입출고(transactions) 테이블의 스키마 설계 및 외래키 정의
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: items 테이블 DDL 작성(id, name, category, price 등)
- 활동: transactions 테이블 DDL 작성(id, item_id, type(IN/OUT), quantity, timestamp 등)
- 활동: 외래키 제약(FOREIGN KEY)과 기본 제약(예: NOT NULL, PRIMARY KEY) 적용
- 활동: 간단한 인덱스(예: item_id) 추가
- 산출물: DDL 스크립트(.sql 파일)
- 산출물: 테이블 관계 다이어그램(간단한 텍스트 또는 이미지)
- 완료 기준: DDL을 실행해 테이블이 생성되고 외래키 제약이 적용되는지 확인함

### 3. 샘플 데이터 삽입 및 JOIN 검증

- 목표: 샘플 데이터로 JOIN 쿼리 실행 및 결과 검증(외래키 무결성 포함)
- 기간: 1.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: items에 샘플 데이터 삽입(예: 5개 품목)
- 활동: transactions에 샘플 데이터 삽입(예: 10건 입출고)
- 활동: JOIN 쿼리 작성(예: SELECT i.name, t.type, t.quantity FROM transactions t JOIN items i ON t.item_id = i.id)
- 활동: 외래키 위반 시 동작(예: INSERT 실패) 테스트
- 활동: NULL 처리 및 집계(예: 품목별 총 입고/출고) 쿼리 실행
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: JOIN 쿼리 및 실행 결과(스크린샷 또는 텍스트 출력)
- 산출물: 외래키 위반 테스트 결과
- 완료 기준: JOIN 쿼리가 의도한 결과를 반환하고 외래키 위반 시 기대 동작이 확인됨

### 4. 결과 정리 및 산출물 제출

- 목표: 산출물 정리(DDL, 쿼리, 결과 스크린샷) 및 간단한 검증 보고서 작성
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 모든 SQL 스크립트와 실행 결과를 한 폴더에 정리
- 활동: 간단한 검증 보고서(목표, 수행한 쿼리, 결과 요약, 발견된 이슈) 작성
- 활동: 향후 개선 포인트(예: 인덱스 추가, 트랜잭션 처리) 1~2개 제안
- 산출물: 최종 산출물 폴더(DDL, INSERT, JOIN 쿼리, 결과 스크린샷)
- 산출물: 검증 보고서(최대 1페이지)
- 완료 기준: 산출물이 제출 가능한 형태로 정리되어 있고 검증 보고서에 핵심 결과와 개선 제안이 포함됨
