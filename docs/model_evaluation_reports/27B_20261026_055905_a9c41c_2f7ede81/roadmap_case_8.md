# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선: 최소 구현으로 실패 재현→원인 가설화→수정 실험

2주(총 4시간) 동안 외부 유료 자료 없이 Python 환경과 가상 문서만으로 RAG 검색 실패를 재현하고 원인을 기록하는 실습 중심 로드맵입니다. 목표는 '성공 2건과 실패 1건을 구분하는 완료 기준'을 충족하는 것입니다. 각 단계는 1주(주당 2시간)로 구성되며, 산출물은 실행 가능한 스크립트와 실패 원인 기록입니다.

### 1. 환경 준비 및 실패 재현

- 목표: 가상 문서 3건(정상 2건, 실패 1건)을 생성하고 간단한 인덱싱·검색 파이프라인을 구현하여 검색 실패를 재현한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건(텍스트, 메타데이터 포함)을 JSON 파일로 생성
- 활동: 간단한 인덱싱(예: TF-IDF 또는 키워드 기반 인덱스) 구현
- 활동: 검색 함수 구현 및 3건에 대해 검색 실행
- 활동: 성공/실패 케이스를 구분하여 로그로 기록
- 산출물: 실행 가능한 Python 스크립트(가상 문서 생성·인덱싱·검색 함수 포함)
- 산출물: 검색 실패 재현 로그(입력 쿼리, 기대 결과, 실제 결과, 실패 원인 가설)
- 완료 기준: 미확인

### 2. 원인 분석 및 수정 실험

- 목표: 재현된 실패의 원인을 가설화하고, 최소한의 수정(예: 토큰화·정규화·메타데이터 매칭 규칙 변경)을 적용해 수정 전후를 비교한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 실패 케이스별 원인 가설 작성(예: 토큰화 불일치, 메타데이터 누락, 인덱스 불일치)
- 활동: 가설별 최소 수정안 적용(코드 변경 또는 데이터 정제)
- 활동: 수정 전후 검색 결과 비교 및 로그 기록
- 활동: 결과를 바탕으로 실패 원인 우선순위와 한계 기술
- 산출물: 원인 분석 보고서(각 실패 케이스별 원인 가설과 검증 방법)
- 산출물: 수정 전후 비교 로그(수정 적용 전·후 검색 결과)
- 완료 기준: 미확인
