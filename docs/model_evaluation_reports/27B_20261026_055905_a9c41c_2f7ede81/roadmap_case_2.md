# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

시간 우선: 1주(총 4시간)로 핵심 산출물 확보

주어진 1주(총 4시간) 내에 로컬 SQLite 기반의 간단한 재고 데이터 모델(품목·입출고)을 설계하고, 외래키와 JOIN 결과를 검증하는 SQL 산출물을 만든다. 시간 우선 관점에서 범위를 최소화하여 설계→DDL→샘플 데이터→JOIN 검증까지 완료한다.

### 1. 데이터 모델 설계 및 DDL 작성

- 목표: 재고 품목과 입출고의 관계(1:N 또는 N:M)를 정의하고 SQLite DDL로 구현한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 요구사항(필드·관계)을 1페이지로 정리
- 활동: ER 다이어그램 작성(간단한 도식)
- 활동: SQLite DDL 작성(테이블, PK, FK, 인덱스 포함)
- 활동: 샘플 데이터(각 테이블 5~10행) 삽입 스크립트 작성
- 산출물: ER 다이어그램(간단한 텍스트 또는 이미지)
- 산출물: DDL 스크립트(.sql) — CREATE TABLE, FOREIGN KEY 포함
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 완료 기준: 미확인

### 2. JOIN 쿼리 작성 및 결과 검증

- 목표: 외래키 무결성과 JOIN 결과를 검증하는 쿼리를 작성하고 결과를 확인한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기본 JOIN(내부/외부) 쿼리 작성
- 활동: 외래키 제약 위반 시나리오(삭제/수정) 테스트
- 활동: 쿼리 결과와 기대값 비교(간단한 검증 체크리스트 작성)
- 활동: 결과를 문서화(스크린샷 또는 CSV)
- 산출물: JOIN 쿼리 모음(.sql)
- 산출물: 쿼리 결과 스냅샷(스크린샷 또는 CSV)
- 산출물: 간단한 검증 체크리스트(예: FK 무결성 확인, NULL 처리 확인)
- 완료 기준: 미확인
