## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선: 최소 구현으로 RAG 핵심 흐름 검증

주어진 2주(총 6시간)와 예산 20,000원 내에서 '검색→근거 표시→근거 없는 답변 구분'을 검증하는 최소 RAG 시제품을 구현합니다. 이미 알려진 Python 기초는 반복하지 않고, 검색·정렬·간단한 생성(또는 규칙 기반 답변)·평가에 집중합니다. 비용 관점: 유료 API·유료 데이터베이스 사용은 피하고, 로컬 인덱스(FAISS 등)와 오픈소스 벡터 모델 또는 간단한 TF-IDF/키워드 인덱스를 우선 검토합니다. 시간 관점: 각 단계는 1~2시간 이내로 설계하여 총 6시간 안에 완료 가능하도록 합니다. 업무 적용 관점: 산출물은 사내 규정 문서 3건과 5개 질문을 대상으로 한 검색 로그·근거 매핑·간단한 평가 리포트로, 향후 팀 내 PoC로 확장 가능한 형태로 남깅니다.

### 1. 데이터 준비 및 검색 인덱스 구성

- 목표: 3건의 가상 규정 문서(각 1~2페이지 분량)를 준비하고, 검색을 위한 인덱스(로컬)를 구성하여 5개 질문을 검색해보기
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(예: 인사규정·데이터관리규정·보안규정)을 텍스트로 정리(각 300~600자)
- 활동: 5개 질문(근거가 있는 3건, 근거가 없는 2건)을 정의
- 활동: 로컬 인덱스 구성: 선택지 A) FAISS + 오픈소스 임베딩(예: sentence-transformers) — 설치·실행 시간 고려, 선택지 B) TF-IDF + BM25(간단한 파이썬 라이브러리) — 설치·실행 시간 짧음
- 활동: 검색 실행: 각 질문에 대해 상위 3개 문서·문장(또는 문단)을 검색하고 결과 로그를 저장
- 산출물: 가상 규정 텍스트 파일(3개)
- 산출물: 질문 목록(5개) 및 기대 근거 매핑(어떤 문서·절차가 근거인지 표기)
- 산출물: 검색 로그(각 질문에 대한 상위 3개 결과와 점수)
- 완료 기준: 미확인

### 2. 간단한 RAG 파이프라인 구현 및 평가

- 목표: 검색 결과를 기반으로 답변을 생성하거나(또는 규칙 기반 답변을 생성) 각 답변에 근거(문서·절차·문장)를 표시하고, 근거 없는 질문은 '근거 없음'으로 분류하는 로직을 구현하여 5개 질문을 평가
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과와 질문을 결합해 간단 답변 생성(옵션 A: 로컬 소형 LLM 호출, 옵션 B: 규칙 기반 템플릿으로 답변 생성)
- 활동: 각 답변에 대해 근거(문서 ID·절차·문장)를 자동 매핑하고, 근거가 없으면 '근거 없음'으로 표시
- 활동: 간단한 평가 스크립트 작성: 검색 정확도(정답 문서 포함 여부), 근거 표시 정확도(정답 근거 포함 여부), 근거 없음 판정 정확도
- 활동: 결과를 표로 정리하고, 실패 사례(검색 실패·근거 누락)를 분석
- 산출물: RAG 파이프라인 코드(검색→응답 생성→근거 매핑)
- 산출물: 평가 리포트(5개 질문에 대한 검색 결과·응답·근거 표시·평가 지표)
- 산출물: 실패 사례 분석 및 개선 포인트(예: 토큰화·임베딩 품질·문서 분할 전략)
- 완료 기준: 미확인
