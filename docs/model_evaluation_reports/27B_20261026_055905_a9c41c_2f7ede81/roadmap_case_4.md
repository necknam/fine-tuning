## 계획

비용 우선: 2주(총 6시간)로 단일 서버 vs 이중화 구조 비교·장애 대응표 작성

사용자 가용 시간(2주, 주 3시간)과 예산(0원)을 우선 반영해, 유료 리소스 생성 없이 문서·다이어그램·시뮬레이션(종이/로컬)으로 단일 서버와 이중화 구조의 차이와 장애 대응 절차를 정리합니다. 목표는 실무에서 바로 참고 가능한 아키텍처 다이어그램과 장애 대응표(체크리스트)를 산출하는 것입니다. 추가 기간이나 유료 자원이 필요하면 확장안을 제시합니다.

- 활동: 간단한 사례(예: 웹서버 단일 인스턴스 vs 2대 로드밸런서+백업) 선정

- 완료 기준: 비교 항목과 선정 사례가 문서로 정리되어 다음 단계에서 다이어그램을 그릴 준비가 되었음을 확인.
