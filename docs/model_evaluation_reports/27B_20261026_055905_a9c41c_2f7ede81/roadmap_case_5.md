# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

2주 집중 실습: 지점-지역 관계 모델링 및 검증

주당 3시간, 총 2주(총 6시간) 동안 관계형 DB로 지점과 지역의 관계를 모델링하고, 지역별 지점 수 집계 쿼리와 중복 ID 거절(제약)을 구현·검증한다. GIS 서버 구축은 제외하고, 로컬 SQLite 또는 PostgreSQL(로컬 인스턴스)을 사용해 실습한다. 예산 0원(유료 서비스 없음)을 반영하여 무료 도구와 공개 자료만 사용한다.

### 1. 요구·모델 설계 및 DDL 구현

- 목표: 간단한 ER 다이어그램(지역 1:N 지점) 설계, 테이블 DDL 작성 및 샘플 데이터 적재
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 요구(지역별 지점 수 조회, 중복 ID 방지)를 1페이지로 정리
- 활동: ER 다이어그램 작성(지역: id, name; 지점: id, name, region_id)
- 활동: DDL 작성(지역 테이블, 지점 테이블, region_id에 FOREIGN KEY, 지점.id에 PRIMARY KEY)
- 활동: 샘플 데이터(지역 3개, 지점 10개)를 CSV로 준비하고 DB에 적재
- 산출물: 요구 1페이지(검증 기준 포함)
- 산출물: ER 다이어그램(이미지 또는 텍스트)
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 CSV 및 적재 스크립트
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. 집계 쿼리·제약 검증 및 결과 문서화

- 목표: 지역별 지점 수 집계 쿼리 작성, 중복 ID 입력 시 제약으로 거절되는지 자동화된 테스트로 증명
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 지역별 지점 수를 반환하는 SQL(예: SELECT r.name, COUNT(b.id) FROM regions r LEFT JOIN branches b ON r.id=b.region_id GROUP BY r.name) 작성
- 활동: 중복 ID 입력 시 PRIMARY KEY/UNIQUE 제약으로 실패하는지 확인하는 테스트 케이스 작성
- 활동: 간단한 자동화(스크립트 또는 SQL 테스트)로 중복 입력 시 에러 발생을 검증
- 활동: 결과(쿼리 출력, 에러 메시지)를 캡처하고 검증 보고서 작성
- 산출물: 집계 쿼리 스크립트(.sql)
- 산출물: 중복 입력 테스트 스크립트 및 실행 로그
- 산출물: 검증 보고서(요구 대비 결과, 한계 및 다음 단계 제안)
- 완료 기준: 미확인
