# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

1주 집중: SQLite 기반 최소 데이터모델 설계·검증

주당 4시간, 총 1주(총 4시간)를 사용해 로컬 SQLite에서 가상 재고 품목과 입출고 테이블을 설계하고 외래키 제약과 JOIN 쿼리로 데이터 무결성을 검증하는 산출물을 만든다. 시간 우선 관점에서 범위를 최소화해 설계·구현·검증까지 완료한다.

### 1. 요구·모델 설계 및 구현

- 목표: 테이블 스키마(컬럼·데이터타입·PK·FK)와 검증 기준 정의, SQLite 스크립트 작성
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항(품목: id, name, unit; 입출고: id, item_id, type(in/out), qty, occurred_at) 문서화(30분)
- 활동: ER 다이어그램(간단한 텍스트 표기) 및 무결성 규칙(외래키, 제약) 정의(45분)
- 활동: SQLite용 DDL 스크립트 작성: CREATE TABLE items(...), CREATE TABLE transactions(..., FOREIGN KEY(item_id) REFERENCES items(id))(60분)
- 산출물: 요구사항 1페이지(텍스트)
- 산출물: ER 텍스트 다이어그램(간단 표기)
- 산출물: SQLite DDL 스크립트(.sql)
- 완료 기준: 미확인

### 2. 데이터 적재·JOIN 검증 및 결과 정리

- 목표: 샘플 데이터로 쿼리 실행해 외래키 무결성과 JOIN 결과(입출고 합계, 현재 재고)를 검증하고 산출물 정리
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 데이터(품목 3개, 입출고 8건)를 CSV 또는 INSERT 문으로 준비(30분)
- 활동: SQLite에 DDL 적용 후 데이터 적재(30분)
- 활동: JOIN 쿼리 작성 및 실행: 품목별 입고 합계, 출고 합계, 현재 재고 계산(60분)
- 활동: 결과 스냅샷(쿼리 출력)과 간단한 검증 체크리스트(예: 외래키 위반 시 동작 확인) 작성(30분)
- 산출물: 샘플 데이터 파일(.csv 또는 INSERT .sql)
- 산출물: JOIN 쿼리 스크립트(.sql)
- 산출물: 쿼리 실행 결과 스냅샷(텍스트 또는 스크린샷)
- 산출물: 검증 체크리스트(간단한 통과/실패 표기)
- 완료 기준: 미확인
