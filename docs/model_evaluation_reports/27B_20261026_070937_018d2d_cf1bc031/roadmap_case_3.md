# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실습형 RDBMS 데이터 모델링 집중 로드맵

주당 3시간, 총 2주(총 6시간)를 투입하여 가상 지점-지역 관계를 관계형 DB로 모델링하고, 지역별 지점 수를 반환하는 SQL 질의와 중복 ID를 거부하는 제약(UNIQUE) 검증까지 완료합니다. GIS 서버 구축은 제외하고, 설계·DDL·테스트 케이스·검증 결과 문서화를 목표로 합니다. 시간 제약 때문에 심층 성능 튜닝은 포함하지 않습니다.

### 1. 요구·모델 설계 및 DDL 작성

- 목표: 핵심 엔티티(지점, 지역)와 관계(지역-지점)를 정의하고, 중복 ID를 방지할 UNIQUE 제약이 포함된 DDL을 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 시나리오(지역별 지점 집계, 중복 ID 거절)를 3개 이하의 요구 항목으로 정리
- 활동: 간단한 ERD(엔티티·PK·FK·유니크 제약)를 다이어그램으로 작성(종이 또는 도구 사용)
- 활동: 관계형 DDL(SQL) 초안 작성: 지역 테이블, 지점 테이블, FK 및 UNIQUE 제약 포함
- 활동: 설계 검토: 중복 ID가 발생 가능한 경로와 제약으로 막을 수 있는지 확인
- 산출물: 요구사항 1페이지 요약(지역별 집계·중복 ID 거절 포함)
- 산출물: ERD 이미지(PNG) 또는 다이어그램 파일
- 산출물: DDL 초안(.sql) — CREATE TABLE 문과 UNIQUE/FK 제약 포함
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. 테스트 데이터·질의 구현 및 검증

- 목표: 샘플 데이터로 지역별 지점 수를 계산하는 SQL을 실행하고, 중복 ID 삽입 시 제약으로 거부되는지 자동화된 테스트로 증명한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 데이터(지역 3개, 지점 8~12개)를 CSV 또는 INSERT 스크립트로 준비
- 활동: 지역별 지점 수를 반환하는 SQL(SELECT ... GROUP BY) 작성 및 실행
- 활동: 중복 ID 삽입 시나리오를 포함한 테스트 스크립트 작성(성공/실패 케이스 포함)
- 활동: 테스트 실행 및 결과 캡처(쿼리 결과 스냅샷, 제약 위반 에러 메시지)
- 산출물: 샘플 데이터 파일(.csv) 또는 INSERT 스크립트(.sql)
- 산출물: 지역별 집계 SQL 스크립트 및 실행 결과 스냅샷
- 산출물: 중복 ID 삽입 테스트 스크립트와 실패(거부) 로그
- 산출물: 간단한 검증 보고서(설계 의도 vs 실제 동작 비교, 1페이지)
- 완료 기준: 미확인
