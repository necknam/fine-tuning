## 계획

비용 우선: 로컬 실험 중심의 재현·원인 분석 로드맵

주어진 10주(총 20시간) 동안 외부 유료 자료 없이 로컬 Python 환경과 가상 문서만으로 RAG 검색 실패를 재현하고 원인을 기록하는 실습 중심 로드맵입니다. 목표는 '성공 2건과 실패 1건을 구분하는 완료 기준'을 충족하는 재현 가능한 실험과 원인 분석 산출물을 만드는 것입니다. 각 단계는 2~3주 단위로 나누어 총 10주(주당 2시간) 내에 완료되도록 설계했습니다.

### 1. 1단계 · 환경·데이터 준비 및 실패 재현

- 목표: 가상 문서 3건(정상 2건, 실패 1건)을 생성하고 간단한 인덱싱·검색 파이프라인을 구현하여 검색 실패를 재현한다.
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 가상 문서 3건(텍스트, 메타데이터 포함)을 JSON 형태로 정의
- 활동: 간단한 인덱싱(예: TF-IDF 또는 키워드 기반)과 검색 함수 구현
- 활동: 정상 검색 2건과 실패 1건을 재현하는 테스트 케이스 작성 및 실행
- 활동: 실패 케이스의 입력·출력·로그를 캡처
- 산출물: 실행 가능한 Python 스크립트(가상 문서 생성·인덱싱·검색 함수 포함)
- 산출물: 검색 실패 재현 로그(입력 쿼리, 기대 결과, 실제 결과, 실패 원인 가설)
- 완료 기준: 실행 가능한 Python 스크립트(가상 문서 생성·인덱싱·검색 함수 포함) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · 원인 분석 및 가설 수립

- 목표: 재현된 실패의 원인을 가설화하고 로그·데이터를 근거로 원인 가설을 검증한다.
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 실패 케이스별 입력·인덱스·검색 결과 비교
- 활동: 토큰화·정규화·메타데이터 불일치·인덱싱 누락 등 원인 가설 수립
- 활동: 각 가설에 대해 간단한 실험(예: 토큰화 변경, 메타데이터 보정)으로 검증
- 활동: 원인별 영향도와 재현 가능성을 정리
- 산출물: 원인 분석 보고서(각 실패에 대한 원인 가설과 근거 로그 포함)
- 산출물: 우선순위화된 개선 항목 목록(우선순위·예상 영향·실시 난이도 표기)
- 완료 기준: 원인 분석 보고서(각 실패에 대한 원인 가설과 근거 로그 포함) 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · 수정 적용 및 비교 실험

- 목표: 원인 가설에 따라 최소한의 수정(예: 토큰화·정규화·메타데이터 보정)을 적용하고 개선 효과를 측정한다.
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 우선순위가 높은 원인 1~2개에 대해 수정안 설계
- 활동: 수정 적용 후 동일 테스트 케이스로 재실행
- 활동: 수정 전·후의 검색 결과와 로그를 비교하여 개선 여부 기록
- 활동: 개선 한계와 추가 실험 필요성 기술
- 산출물: 개선 적용 스크립트(변경 전/후 비교 포함)
- 산출물: 비교 결과 요약(정확도·재현성·한계 기술)
- 완료 기준: 개선 적용 스크립트(변경 전/후 비교 포함) 작성 완료 및 요구 기준 충족 검증

### 4. 4단계 · 문서화 및 재현성 확보

- 목표: 재현 방법·원인·수정·결과를 정리하여 재현 가능한 산출물을 남긴다.
- 기간: 1 · 시간: 2시간 · 비용: 0원
- 활동: 재현 절차(환경·명령·입력)를 단계별로 문서화
