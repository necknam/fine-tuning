# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: AI 업무 개선
- 관점: 비용 우선
- 기간: 12주 · 주당 2시간 · 예산 0원

## 계획

비용 우선의 실습 중심 RAG·에이전트 프로토타입 로드맵

주당 2시간, 총 12주(총 24시간)의 제한된 시간과 예산(0원)을 고려해 로컬 환경에서 실행 가능한 RAG 기반 생성형 AI 에이전트 프로토타입을 단계적으로 구현합니다. 목표는 실무에서 바로 적용 가능한 검색-생성 파이프라인과 간단한 에이전트(도구 호출)를 만들어 검증하는 것입니다. 비용 우선 관점에서 유료 서비스·유료 자격증·유료 강좌를 사용하지 않고 오픈소스 도구와 로컬 실행 가능한 경량 모델을 우선 사용합니다. 자료(강좌·도서·자격증)는 검색된 추천 목록이 비어 있어 추천하지 않으며, 필요한 경우 추가 자료를 별도로 확인해야 합니다.

### 1. 1단계 · 환경·데이터 준비

- 목표: 로컬에서 실행 가능한 RAG 기본 파이프라인(문서 전처리→임베딩→벡터 DB→검색)을 구성하고, 검색 품질을 측정할 수 있는 기준을 마련한다.
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 개발 환경 구성: Python, 가상환경, Jupyter/VSCode, Docker(선택)
- 활동: 샘플 문서 수집 및 전처리(텍스트 분할, 정제) 스크립트 작성
- 활동: 임베딩 모델 선택(오픈소스 경량 모델) 및 벡터 DB(FAISS/Chroma 등)로 인덱싱
- 활동: 검색 정확도(정밀도/재현율)를 측정할 수 있는 간단한 평가 스크립트 작성
- 산출물: 환경 구성 체크리스트(로컬/컨테이너)
- 산출물: 샘플 데이터셋(문서 20~50건) 및 전처리 스크립트
- 산출물: 간단한 검색(키워드/벡터) 비교 결과
- 완료 기준: 환경 구성 체크리스트(로컬/컨테이너) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · RAG 프로토타입 구현

- 목표: 검색 결과를 생성형 모델에 연결해 질의응답을 생성하는 RAG 프로토타입을 만들고, 검색 품질과 생성 품질을 비교·측정한다.
- 기간: 4 · 시간: 8시간 · 비용: 0원
- 활동: 검색 결과를 프롬프트로 조합하는 템플릿 설계
- 활동: 오픈소스 LLM(로컬 실행 가능한 경량 모델) 또는 API(비용 고려)로 응답 생성
- 활동: 응답 품질을 정성·정량적으로 평가(정확성, 관련성, 일관성)
- 활동: 실험을 통해 검색-생성 조합의 한계와 개선 포인트 도출
- 산출물: RAG 프로토타입 코드(검색→프롬프트→응답)
- 산출물: 간단한 평가 리포트(정확도·응답 품질 비교)
- 산출물: 실험 로그(모델·프롬프트별 결과)
- 완료 기준: RAG 프로토타입 코드(검색→프롬프트→응답) 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · 에이전트 설계·실험

- 목표: 검색·생성 기능을 도구로 호출하는 간단한 에이전트(도구 호출, 의사결정 루프)를 구현해 실무 시나리오에서 유용성을 검증한다.
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 에이전트 설계: 입력 파싱→도구(검색/계산/DB 조회) 호출→응답 생성 흐름 정의
- 활동: 도구 호출 인터페이스 구현(간단한 함수형 API)
- 활동: 시나리오별 테스트(예: 문서 요약, 질의응답, 데이터 조회) 및 실패 사례 수집
- 활동: 에이전트 동작의 안정성·응답 시간 측정
- 산출물: 에이전트 프로토타입(도구 호출·의사결정 흐름)
- 산출물: 작업별 시나리오별 테스트 결과
- 산출물: 에이전트 동작 로그 및 실패 사례 분석
- 완료 기준: 에이전트 프로토타입(도구 호출·의사결정 흐름) 작성 완료 및 요구 기준 충족 검증

### 4. 4단계 · 검증·문서화·데모

- 목표: 프로토타입을 정리해 데모 가능한 형태로 만들고, 운영·확장 시 고려사항(비용·성능·보안)을 문서화한다.
- 기간: 2 · 시간: 4시간 · 비용: 0원
- 활동: 프로토타입 코드 정리 및 실행 가이드 작성
- 활동: 데모 시나리오 준비(실무 예제 2~3개)
- 활동: 성능·비용·보안 관점의 간단한 리스크 분석 작성
- 활동: 향후 개선 우선순위 및 다음 단계 제안
- 산출물: 최종 데모(스크린캐스트 또는 슬라이드)
- 산출물: 간단한 배포/실행 가이드
- 산출물: 향후 개선 계획 및 비용·리스크 분석
- 완료 기준: 최종 데모(스크린캐스트 또는 슬라이드) 작성 완료 및 요구 기준 충족 검증
