## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선: 최소 RAG 시제품(6주, 3시간/주)

6주(총 18시간) 동안 가상 규정 3건과 질문 5건을 사용해 검색·정제·응답 흐름을 구현하고, 근거 유무·정확성·응답 불능을 구분하는 최소 시제품을 만든다. 예산 20,000원은 필요 시 유료 자료 구매에 사용 가능하나, 현재 추천 자료는 무료 Microsoft Learn 모듈로 구성한다. 규정·지원금 승인 자료는 확인 필요로 남긴다.

### 1. 요구·데이터 준비

- 목표: 가상 규정 3건과 질문 5건 정의 및 검색용 텍스트 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서 텍스트) 작성
- 활동: 질문 5건 작성(정확한 근거 포함/거부/불명확 포함)
- 활동: 검색용 텍스트 인덱스(간단한 텍스트 파일 또는 JSON) 준비
- 산출물: 규정 3건 텍스트 파일
- 산출물: 질문 5건 목록(정답/거부/불명확 표기)
- 산출물: 검색용 텍스트 인덱스 파일
- 완료 기준: 규정 3건과 질문 5건이 준비되어 검색 인덱스에 적재 가능함

### 2. 검색·정제·응답 파이프라인 구현

- 목표: 검색→정제→응답 흐름을 구현하고 근거 표시·거부 로직을 추가
- 기간: 3 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 검색(문서 매칭) 구현(예: Python + 간단한 검색 함수)
- 활동: 정제 단계: 관련 문서 필터링 및 근거 추출
- 활동: 응답 생성: 근거를 표시하거나 근거가 없으면 '거부' 또는 '불명확'으로 응답
- 활동: 간단한 평가 스크립트로 5건에 대해 결과 비교
- 산출물: 검색·정제·응답 코드(예: Python 스크립트)
- 산출물: 5건의 평가 결과(정답/거부/불명확 표기)
- 산출물: 간단한 실행 가이드
- 완료 기준: 5건 중 각 질문에 대해 검색 결과와 정제된 근거를 표시하거나 거부를 수행할 수 있음
