# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선의 실습 중심 RAG 검증 로드맵

9주(주 3시간, 총 27시간) 동안 비용 0원으로 '검색 결과와 실제 근거를 대조하는 학습 시제품'을 구현합니다. 목표는 RAG 파이프라인의 핵심 검증(검색 정확성·근거 일치성)을 소규모 테스트셋으로 반복 실험해 한계와 개선 포인트를 도출하는 것입니다. 시작점(사전 지식)을 고려해 이미 아는 Python·데이터 처리는 반복 학습하지 않고, LLM·RAG 관련 기본 개념과 실습에 집중합니다. 예산이 0원이므로 유료 서비스·유료 데이터는 사용하지 않고 로컬 도구와 공개 학습 자료(제공된 Microsoft Learn 모듈)를 활용합니다.

### 1. 1단계 · 준비 및 기준 수립

- 목표: 학습 범위와 검증 기준을 확정하고, 테스트용 문서·질문 세트를 준비한다.
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 목표·검증 기준(정확도·재현성·한계) 정의
- 활동: 테스트 문서 10건(각 문서에 2~3개의 사실성 질문 포함) 작성
- 활동: 간단한 검색·매칭 스크립트(검색 결과와 문서 원문 대조용) 설계
- 산출물: 학습 목표·검증 기준 문서(간단한 체크리스트)
- 산출물: 테스트 문서 10건(각 문서에 2~3개의 사실성 질문 포함)
- 산출물: 간단한 검색·매칭 스크립트(검색 결과와 문서 원문 대조용)
- 완료 기준: 학습 목표·검증 기준 문서(간단한 체크리스트) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · 핵심 기능 구현(검색-증거 매칭)

- 목표: 검색 결과와 문서 원문을 자동으로 대조하는 간단한 파이프라인을 구현하고, 샘플 10건에 대해 검증한다.
- 기간: 3 · 시간: 9시간 · 비용: 0원
- 활동: 로컬 검색(문서 인덱싱) 및 검색 결과 수집 스크립트 구현
- 활동: 검색 결과와 문서 원문 간 일치·불일치 판정 로직 구현(간단한 문자열/토큰 매칭 또는 임베딩 유사도)
- 활동: 샘플 10건에 대해 자동 대조 실행 및 결과 수집
- 산출물: 검색·증거 매칭 파이프라인(로컬 실행 스크립트)
- 산출물: 샘플 10건에 대한 매칭 결과(정답/오답 표기)
- 산출물: 기본 성능 지표(정확도, 재현성) 및 실패 사례 목록
- 완료 기준: 검색·증거 매칭 파이프라인(로컬 실행 스크립트) 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · 증거 기반 응답 생성 및 검증

- 목표: 검색된 근거를 바탕으로 생성형 응답을 만들고, 응답이 근거와 일치하는지 검증한다.
- 기간: 3 · 시간: 9시간 · 비용: 0원
- 활동: 검색 결과를 입력으로 받아 응답을 생성하는 간단한 에이전트(프롬프트 기반) 구현
- 활동: 응답과 근거 간 일치성(근거 인용·문장 매칭)을 자동·수동으로 평가
- 활동: 불일치 사례를 수집해 원인(검색 실패, 프롬프트 문제, 모델 한계) 분류
- 산출물: 증거 기반 응답 생성 모듈(샘플 10건에 대한 출력)
- 산출물: 응답과 근거의 일치성 평가표(정확도·근거 연결성)
- 산출물: 문제 사례 5건과 원인 분석
- 완료 기준: 증거 기반 응답 생성 모듈(샘플 10건에 대한 출력) 작성 완료 및 요구 기준 충족 검증

### 4. 4단계 · 평가·문서화·한계 분석

- 목표: 샘플에 대한 정량적·정성적 평가를 수행하고, 결과와 한계를 문서화한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 정확도(정답 일치율), 재현성(동일 입력에 대한 출력 일관성) 측정
- 활동: 실패 사례 분석 및 개선 포인트 도출
- 활동: 최종 리포트 작성 및 시제품 코드 정리
- 산출물: 최종 검증 리포트(정확도·재현성·한계 포함)
- 산출물: 실행 가능한 시제품 코드(README 포함)
- 산출물: 향후 개선 우선순위 목록
- 완료 기준: 최종 검증 리포트(정확도·재현성·한계 포함) 작성 완료 및 요구 기준 충족 검증
