# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 중심의 실전 개선 로드맵

기존 검색 코드에 대해 검증(근거 누락 검출)과 회귀 시험을 추가하는 5주 실전 계획입니다. 주당 4시간, 총 20시간을 사용하며 비용은 0원입니다. 이미 문서 분할·검색 코드를 작성한 경험이 있으므로 기초 학습은 배제하고 검증·테스트·개선 권고에 집중합니다.

### 1. 1단계 · 검증 계획 및 데이터 준비

- 목표: 검증 범위와 성공 기준을 확정하고 검증용 샘플 데이터 준비
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 기존 검색 파이프라인의 입력·출력 스펙 확인(분할 단위, 메타데이터, 검색 쿼리)
- 활동: 검증 항목 정의: 근거 누락 유형(문단 누락, 메타데이터 누락, 토큰화 오류 등)과 우선순위 결정
- 활동: 검증용 샘플 문서 10건 선정(다양한 길이·포맷 포함) 및 분할 결과 수집
- 산출물: 검증 계획서(검증 항목·데이터·성공 기준 포함)
- 산출물: 검증용 샘플 문서 10건(원문·분할 결과 포함)
- 완료 기준: 검증 계획서(검증 항목·데이터·성공 기준 포함) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · 검증 스크립트 구현

- 목표: 자동화된 검증 스크립트로 근거 누락을 탐지하고 결과를 수집
- 기간: 2 · 시간: 8시간 · 비용: 0원
- 활동: 검증 스크립트 작성: 입력 문서→분할→검색→출력 비교(원문과 검색 결과의 토큰/문장 일치도 측정)
- 활동: 누락 탐지 로직 구현: 분할 경계에서 문장·의미 단위가 잘리는지, 메타데이터가 누락되는지 검사
- 활동: 샘플 10건에 대해 스크립트 실행 및 결과 수집
- 산출물: 검증 스크립트(샘플 입력→분할→검색→검증 결과 출력)
- 산출물: 검증 결과 리포트(누락 유형별 빈도·예시 포함)
- 완료 기준: 검증 스크립트(샘플 입력→분할→검색→검증 결과 출력) 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · 회귀 테스트 추가

- 목표: 검증 결과를 기반으로 회귀 테스트를 추가하여 재발 방지
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 검증에서 발견된 누락 유형을 테스트 케이스로 변환(각 유형별 최소 1개 케이스)
- 활동: 테스트 자동화: 로컬에서 실행 가능한 스크립트 또는 CI용 간단한 스크립트 작성
- 활동: 테스트 실패 시 알림(간단한 로그/이메일 템플릿) 추가
- 산출물: 회귀 테스트 스위트(자동 실행 가능한 테스트 케이스 10개)
- 산출물: 테스트 실행 스크립트 및 실패 시 알림(간단한 로그/이메일 템플릿)
- 완료 기준: 회귀 테스트 스위트(자동 실행 가능한 테스트 케이스 10개) 작성 완료 및 요구 기준 충족 검증

### 4. 4단계 · 결과 분석 및 개선 권고

- 목표: 검증 결과를 정리하고 개선 우선순위 및 적용 방안을 제시
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 검증 결과 요약: 누락 유형별 빈도, 심각도, 재현 방법 정리
- 활동: 개선 권고안 작성(분할 전략 수정, 메타데이터 보강, 토크나이저 변경 등)
- 활동: 테스트 스위트 실행 결과와 함께 최종 리포트 제출
- 산출물: 최종 검증 리포트(문제 요약·우선순위·권고안 포함)
- 산출물: 테스트 실행 결과 스냅샷(성공/실패 케이스 포함)
- 완료 기준: 최종 검증 리포트(문제 요약·우선순위·권고안 포함) 작성 완료 및 요구 기준 충족 검증
