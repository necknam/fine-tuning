# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

4주 실무형 RAG 시제품 — 근거 표시·거부 기준 구현

주당 3시간, 총 4주(총 12시간)를 사용해 가상 규정 3건과 질문 5건에 대해 검색·정제·응답을 수행하는 최소 RAG 시제품을 완성합니다. 각 단계는 업무 적용 관점에서 구현·검증·기록을 포함하며, 예산·시간 제약 내에서 구현 가능한 범위로 설계했습니다. 규정·지원금 승인 여부는 확인 필요로 두고 추가 비용·승인 전제 없이 시제품을 완료합니다.

### 1. 요구·데이터 준비

- 목표: 가상 규정 3건과 질문 5건의 텍스트를 정리하고 검색·응답 기준을 정의
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서 텍스트)과 질문 5건 작성
- 활동: 검색용 인덱스(간단한 텍스트 인덱스) 생성 계획 수립
- 활동: 응답 품질 기준(근거 표시·거부 기준) 정의
- 산출물: 규정 3건 텍스트 파일(또는 CSV)
- 산출물: 질문 5건 목록
- 산출물: 검색·응답 품질 기준 문서(간단한 체크리스트)
- 완료 기준: 규정 3건과 질문 5건이 준비되어 있고, 검색·응답 품질 기준이 문서화되어 있어 다음 단계에서 검색·정제 작업을 수행할 수 있음

### 2. 검색·정제·응답 구현

- 목표: 검색 결과를 정제하고, 답변 근거를 표시하거나 근거가 없는 질문은 '답변 불가'로 표시하는 간단한 RAG 파이프라인 구현
- 기간: 2 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 텍스트 인덱스(예: Python + FAISS 또는 유사 라이브러리) 생성
- 활동: 검색 쿼리(5건) 실행 및 상위 k개 문서 반환
- 활동: 정제(중복·불완전 문서 제거) 및 답변 생성(검색 결과 기반 요약)
- 활동: 응답에 근거 문서를 표시하거나 근거가 없는 질문은 '답변 불가'로 표시
- 산출물: 검색·응답 코드(간단한 스크립트 또는 노트북)
- 산출물: 5건의 검색 결과와 정제된 답변(각 답변에 근거 문서 표시 포함)
- 산출물: 실행 가이드(실행 방법과 입력 파일 위치)
- 완료 기준: 5건에 대해 검색 결과를 반환하고, 각 답변에 근거 문서를 표시하거나 근거가 없는 질문은 '답변 불가'로 표시하는 동작이 재현 가능함

### 3. 검증·기록·회고

- 목표: 5건에 대해 검색·정제·응답 결과를 비교하고, 근거 표시·거부 기준을 문서화
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 각 질문의 검색 결과와 최종 답변을 비교(정확성·근거 표시 여부 확인)
- 활동: 실패 사례(검색 누락·잘못된 정제) 기록
- 활동: 간단한 회고 문서 작성(다음 개선 포인트)
- 산출물: 검증 리포트(각 질문별 검색 결과·정제·응답 비교)
- 산출물: 실패 사례 목록 및 개선 제안
- 산출물: 최종 구현 코드와 실행 가이드
- 완료 기준: 5건에 대한 검증 리포트가 작성되어 있고, 근거 표시·거부 기준이 문서화되어 있으며, 실패 사례와 개선 포인트가 정리되어 있음
