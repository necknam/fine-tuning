# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선: 최소 기능 RAG 검색 시제품 구현

사용자의 가용 시간(총 6시간)과 예산(10,000원)을 고려해, 2주 동안 최소 기능의 검색 증강(RAG) 시제품을 구현하고 검증하는 실습 중심 로드맵입니다. 유료 서비스나 대규모 인프라를 사용하지 않고 로컬 환경과 무료 도구로 구현합니다. 지원금 미확정으로 인해 추가 비용은 계획하지 않습니다.

### 1. 검색 시제품 구현

- 목표: 작동하는 최소 RAG 검색 시제품 구현
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 문서 5개(텍스트) 준비 및 전처리(토큰화·정규화)
- 활동: 간단한 벡터화(예: scikit-learn TF-IDF 또는 무료 API 사용) 및 인덱싱
- 활동: 검색 쿼리 입력 시 상위 3개 문서 반환하는 스크립트 작성
- 활동: 검색 결과에 대해 근거 문장(원문 스니펫)을 표시하도록 출력 포맷 설계
- 산출물: 작동하는 검색 시제품 코드(로컬 실행 스크립트)
- 산출물: 샘플 문서 5개와 검색 결과 비교 로그
- 산출물: 간단한 실행 가이드(README)
- 완료 기준: 미확인

### 2. 검증·분석

- 목표: 검색 품질 검증 및 결과 해석
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 테스트 쿼리 10개 작성(간단한 사실 확인형)
- 활동: 검색 결과의 상위 3개 문서와 근거 문장 매칭 여부 확인
- 활동: 간단한 정밀도·재현율(수동 평가) 기록
- 활동: 결과 해석: 어떤 쿼리에 실패했는지 원인 분석(문서 분할·토큰화·벡터화 한계 등)
- 산출물: 최종 검색 시제품(코드 + 실행 스크립트)
- 산출물: 테스트 쿼리 10개와 기대 결과·실제 결과 비교표
- 산출물: 한계·향후 개선 항목 정리 문서
- 완료 기준: 미확인
