- 활동: 문서 분할(문단 단위) 및 임베딩 생성(로컬 모델 또는 API 사용) — Python 스크립트로 자동화
- 활동: 벡터 저장소(로컬 FAISS 또는 ChromaDB)에 임베딩 저장 및 검색 함수 구현
- 활동: 검색 결과와 원문 위치(문단·문장)를 반환하는 검색 함수 작성
- 산출물: 가상 규정 3건(각 200자 내외)과 질문 5건(근거 있음 3건, 근거 없음 2건)의 데이터셋
- 산출물: 문서 분할·임베딩·벡터 저장소(로컬 FAISS 또는 ChromaDB) 구성 코드
- 산출물: 검색 결과와 원문 위치(문단·문장)를 반환하는 검색 함수

### 2. RAG 파이프라인 구현 및 평가

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 컨텍스트로 주입하여 LLM에 질문을 전달하는 파이프라인 구현
- 활동: 응답에 인용된 원문 위치(문단·문장)를 표시하도록 포맷팅
- 활동: 각 질문에 대해 성공(근거 표시), 근거 누락(검색 실패), 답변 불가(규정 없음) 사례를 구분하는 간단한 평가 스크립트 작성
- 활동: 간단한 테스트(5개 질문) 실행 및 결과 정리
- 산출물: RAG 시제품 코드(검색→컨텍스트 주입→LLM 호출→응답 생성)
- 산출물: 각 질문에 대한 응답과 함께 인용된 원문 위치(문단·문장) 표시
- 산출물: 성공·근거 누락·답변 불가 사례를 구분한 평가 리포트(간단한 표)
