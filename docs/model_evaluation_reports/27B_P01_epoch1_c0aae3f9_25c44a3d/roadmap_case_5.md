# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 중심의 최소 변경 로드맵

사용자 요청(검증 부분부터)과 가용 시간(총 1주, 주 4시간)을 반영해 검증 설계와 회귀 테스트 추가에 집중합니다. 기존에 작성한 문서 분할·검색 코드를 수정·확장하여 누락 검출과 회귀 시험을 구현합니다. 단계별 산출물과 완료 기준을 명확히 하여 1주 안에 검증 가능한 결과를 도출합니다.

### 1. 검증 설계 및 테스트 데이터 준비

- 목표: 검증 항목과 테스트 케이스를 정의하고, 검증 자동화 스크립트를 작성해 누락 검출을 실행할 수 있게 한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 코드의 입력·출력 계약과 실패 사례를 문서화
- 활동: 검출 대상(예: 문서 분할 누락, 메타데이터 불일치, 검색 결과 순서 오류) 목록 작성
- 활동: 테스트 케이스 설계(정상 케이스, 경계 케이스, 오류 케이스) 및 테스트 데이터 준비
- 활동: 검증 자동화 스크립트 작성(테스트 실행, 결과 수집, 실패 항목 보고)
- 산출물: 검증 계획서(검출 항목·테스트 케이스 목록)
- 산출물: 검증용 테스트 데이터(정상·경계·오류 케이스 포함)
- 산출물: 검증 자동화 스크립트(테스트 실행 및 결과 수집)
- 완료 기준: 미확인

### 2. 회귀 테스트 추가 및 검출 로직 구현

- 목표: 회귀 테스트를 추가하고, 누락 검출 로직을 코드에 반영해 회귀 실행 시 누락이 자동 감지되도록 한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 회귀 테스트 케이스를 자동화(테스트 프레임워크 또는 스크립트)하여 반복 실행 가능하게 구성
- 활동: 검출 로직(예: 분할 결과와 원문 비교, 메타데이터 검증)을 기존 코드에 통합
- 활동: 회귀 실행을 통해 누락 검출의 정확성·성능을 측정하고 결과 리포트 작성
- 활동: 검출 실패 시 재현 절차와 수정 가이드를 문서화
- 산출물: 회귀 테스트 스위트(자동 실행 가능)
- 산출물: 회귀 실행 결과 리포트(성공/실패 케이스 및 재현 절차)
- 산출물: 코드 변경(검출 로직 추가) 및 변경 로그
- 완료 기준: 미확인
