- 관점: 시간 우선

## 계획

시간 우선: 최소 기능 중심의 RAG 시제품 구현

2주(총 6시간) 동안 최소 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문을 구분하는 것을 목표로 한다. 이미 익힌 Python 기초는 반복하지 않고, 검색·응답 파이프라인과 근거 표시 로직에 집중한다. 각 단계의 활동·산출물·완료 기준과 소요 시간을 구체적으로 제시하며, 단계 시간 합계는 사용자 가용 시간(2주 × 3시간/주 = 6시간) 안에 들어간다.

### 1. 데이터·기준 설계

- 목표: 가상 규정 3건과 질문 5건을 정의하고, 검색 성공·근거 누락·답변 불가 사례를 구분하는 기준을 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 200자 내외)과 질문 5건(근거 있음 3건, 근거 없음 2건)을 작성
- 활동: 검색 성공·근거 누락·답변 불가 판정 기준(예: 토큰 일치, 문장 포함, 유사도 임계값) 정의
- 활동: 간단한 검색·응답 파이프라인(예: Python 스크립트)으로 검색 결과와 근거 표시를 구현
- 산출물: 가상 규정 3건(각 200자 내외)과 질문 5건(근거 있음 3건, 근거 없음 2건)의 데이터 파일
- 산출물: 간단한 검색·응답 파이프라인 코드(예: Python 스크립트)와 실행 결과 로그
- 산출물: 각 질문에 대한 기대 근거와 실제 출력 비교표
- 완료 기준: 미확인

### 2. 시제품 구현·검증

- 목표: 최소 RAG 시제품을 구현하고, 검색 성공·근거 누락·답변 불가 사례를 구분해 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 RAG 파이프라인 구현(문서 분할 → 인덱싱 → 검색 → 응답 생성)
- 활동: 각 질문에 대해 검색 결과와 근거 표시를 확인하고, 근거 없는 질문에 대해 '근거 없음'을 반환하도록 로직 추가
- 활동: 테스트 케이스(5건)에 대해 실행하고 결과 비교·분석
- 산출물: 최종 시제품 코드와 실행 스크립트
- 산출물: 테스트 결과(각 질문에 대한 출력과 근거 표시)와 한계·개선점 문서
- 산출물: 간단한 데모(스크립트 실행 결과 캡처)
- 완료 기준: 미확인
