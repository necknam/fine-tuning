# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선의 작은 검색 시제품(7주, 3시간/주)

7주(총 21시간) 동안 사전 자기점검을 바탕으로 RAG·생성형 AI 에이전트의 핵심 개념을 빠르게 학습하고, 소규모 검색 시제품을 구현하여 근거 문장 확인 기능을 검증합니다. 예산은 10,000원이며 지원금(30,000원)은 미확정이라 별도 차감하지 않습니다. 각 단계는 실제 목표와 시간 제약을 반영하여 산출물을 명확히 합니다.

### 1. 사전 진단 및 요구·환경 정리

- 목표: 학습 시작점(사전 자기점검)과 실습 환경(로컬/클라우드) 결정, 우선순위 정의
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 사전 자기점검 결과(이해도·개발 경험)를 정리
- 활동: 실습 환경(로컬 Python 환경 또는 무료 클라우드) 선택
- 활동: 시제품의 핵심 기능(검색→문서 추출→생성 응답)과 검증 기준 정의
- 산출물: 사전 진단 요약(1페이지)
- 산출물: 실습 환경 선택 기록(환경 설치 명령 포함)
- 산출물: 시제품 요구사항 목록(핵심 기능·검증 기준)
- 완료 기준: 사전 진단 요약과 실습 환경 선택 기록이 작성되어 시제품 요구사항이 정의되어 있으면 완료

### 2. 핵심 개념 학습(간단한 RAG·프롬프트 전략)

- 목표: RAG의 기본 흐름과 생성형 에이전트의 프롬프트 설계 원리를 이해하여 시제품 설계에 적용
- 기간: 2 · 시간: 미확인시간 · 비용: 미확인원
- 활동: RAG의 검색→추출→응답 흐름을 간단히 정리
- 활동: 프롬프트 엔지니어링 기본(시스템 메시지, 컨텍스트 주입) 학습
- 활동: 시제품 설계(문서셋, 검색어, 응답 형식) 초안 작성
- 산출물: RAG 흐름 정리 노트(간단 다이어그램 포함)
- 산출물: 프롬프트 설계 초안(예: 시스템 메시지·컨텍스트 예시)
- 산출물: 시제품 설계 문서(핵심 기능·검증 기준 포함)
- 완료 기준: RAG 흐름과 프롬프트 설계 초안이 문서화되어 시제품 구현 계획이 수립되면 완료

### 3. 시제품 구현(검색→문서 추출→간단 생성 응답)

- 목표: 작은 문서셋과 검색·추출·생성 파이프라인을 구현하여 근거 문장 확인 기능을 검증
- 기간: 3 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 문서셋(예: 10~20개 문단) 준비 및 인덱싱(로컬 검색 엔진 사용)
- 활동: 검색 결과에서 관련 문단 추출 및 프롬프트로 생성형 응답 생성
- 활동: 응답에 근거 문장(출처)을 표시하는 간단한 검증 로직 구현
- 산출물: 시제품 코드(검색·추출·생성 모듈 포함)
- 산출물: 시제품 실행 가이드(설치·실행 명령 포함)
- 산출물: 검증 결과(예: 10개 질의에 대한 근거 표시 결과)
- 완료 기준: 시제품이 로컬에서 실행되어 질의에 대해 근거 문장을 표시하는 응답을 생성하면 완료
