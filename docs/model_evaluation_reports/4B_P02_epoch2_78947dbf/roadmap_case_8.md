## 계획

비용 우선의 RAG·생성형 AI 에이전트 실습 로드맵

사용자의 제약(기간 9주, 주당 3시간, 예산 0원)을 반영하여 최소한의 실습으로 RAG 검색 결과와 생성형 AI 응답의 일관성을 검증하는 시제품을 만드는 로드맵입니다. 각 단계는 실제 산출물(간단한 코드·실행 로그·비교표)을 목표로 하며, 추가 비용이나 승인 없이 완료 가능한 범위로 설계했습니다. 필요 시 추가 자료·승인 확인 항목을 명시합니다.

### 1. 환경 준비 및 데이터 준비

- 목표: 로컬에서 실행 가능한 개발 환경과 샘플 문서(가상 문서) 준비
- 기간: 2 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 개발 환경(파이썬, 가상환경, 필요한 패키지) 설치 및 확인
- 활동: 샘플 문서 3~5개(가상 문서) 준비 및 메타데이터(문서 ID, 출처) 추가
- 활동: 간단한 문서 전처리 스크립트 작성(토큰화, 분절)
- 산출물: 환경 설치 체크리스트(사용한 패키지 버전 포함)
- 산출물: 샘플 문서 파일과 메타데이터 CSV
- 산출물: 문서 전처리 스크립트(실행 가능한 코드)
- 완료 기준: 샘플 문서로 전처리 스크립트를 실행해 분절 파일이 생성되고, 로컬에서 실행 가능한 상태

### 2. 간단 RAG 파이프라인 구현

- 목표: 문서 인덱싱·검색·응답 생성의 최소 동작 파이프라인 구현
- 기간: 3 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 문서 분절과 벡터 인덱스(간단한 임베딩 + 인덱스) 구현
- 활동: 검색 쿼리 작성 및 상위 k개 문서 반환 구현
- 활동: 생성형 AI 호출(로컬 또는 공개 API)과 프롬프트 템플릿 작성
- 활동: 검색 결과와 생성 응답을 연결하는 간단한 파이프라인 코드 작성
- 산출물: RAG 파이프라인 코드(인덱싱·검색·생성 연결)
- 산출물: 샘플 쿼리 10개와 반환된 문서 목록
- 산출물: 간단한 실행 가이드(README)
- 완료 기준: 샘플 쿼리 10개에 대해 검색 결과와 생성 응답을 얻고, 파이프라인이 재현 가능하게 실행됨

### 3. 평가·비교 및 개선

- 목표: 검색 결과와 생성 응답의 일관성·정확성 평가 및 개선 포인트 도출
- 기간: 3 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과와 생성 응답을 비교하는 간단한 평가 스크립트 작성(정합성 체크, 출처 일치 여부)
- 활동: 실패 사례 5개 이상 수집 및 원인 분석
- 활동: 프롬프트·인덱싱·검색 파라미터를 소규모로 조정해 개선 시도
- 산출물: 평가 리포트(비교표, 실패 사례 및 원인 분석)
- 산출물: 개선 전후의 간단한 비교 결과(예: 정합성 비율)
- 산출물: 다음 개선 항목 목록
- 완료 기준: 평가 리포트와 개선 항목이 작성되어, 최소 1개 이상의 개선 시도가 문서화됨
