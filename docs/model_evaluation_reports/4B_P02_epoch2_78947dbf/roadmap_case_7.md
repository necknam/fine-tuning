## 계획

비용 우선·시간 제약 내 RAG·에이전트 실무 개선 로드맵

사용자의 제약(총 12주, 주당 2시간, 예산 0원)을 우선으로 하여 RAG·생성형 AI 에이전트의 실무 적용을 목표로 단계별로 학습·실험·검증을 수행합니다. 각 단계는 실제 산출물(문서·코드·평가 리포트)을 목표로 하며, 비용이 확인되지 않은 유료 자료는 추천하지 않습니다. 규정·지원금 관련 승인 자료는 확인 필요로 표기합니다.

### 1. 1단계 · 현황 진단 및 요구 정의

- 목표: 업무에서 RAG·에이전트가 해결할 수 있는 문제 1~2개 선정 및 성공 기준 정의
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 담당 업무와 관련 문서(FAQ, 운영 매뉴얼, 내부 지식 베이스) 수집
- 활동: 사용자(동료) 1~2명 인터뷰로 요구·사용 패턴 수집
- 활동: 우선순위 문제 1~2개 선정 및 성공 기준(정확도·응답 일관성 등) 정의
- 산출물: 문제 정의 문서(우선순위 문제 1~2개 포함)
- 산출물: 성공 기준 정의서(측정 지표 포함)
- 완료 기준: 산출물 작성 및 검증 기준 충족 확인

### 2. 2단계 · 기초 RAG·에이전트 구현(실험용)

- 목표: 작은 규모로 RAG 파이프라인과 에이전트 동작을 구현해 기본 기능 검증
- 기간: 4 · 시간: 8시간 · 비용: 0원
- 활동: 간단한 문서 인덱싱(예: PDF/텍스트) 및 검색 구현
- 활동: 생성형 모델(로컬 또는 공개 API)을 사용해 RAG 응답 생성
- 활동: 에이전트(질문→검색→생성→응답) 흐름 구현 및 간단한 테스트 케이스 작성
- 산출물: 실험용 코드 저장소(README 포함)
- 산출물: 기본 동작 테스트 케이스 및 실행 방법
- 완료 기준: 산출물 작성 및 검증 기준 충족 확인

### 3. 3단계 · 평가·비교·개선

- 목표: 정량·정성 평가를 통해 개선 효과를 측정하고 한계와 개선안 도출
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 테스트 케이스로 정확도·응답 일관성 평가(간단한 평가 스크립트 작성)
- 활동: 기초 모델 vs 개선(예: 검색 질의 개선, 토큰 프롬프트 조정) 비교
- 활동: 결과 요약 및 개선 우선순위 도출
- 산출물: 평가 리포트(정량 지표와 개선 권고 포함)
- 산출물: 개선 적용 가이드(간단한 체크리스트)
