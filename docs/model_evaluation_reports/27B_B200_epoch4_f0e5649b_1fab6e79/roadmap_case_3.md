## 계획

2주 집중: 최소 RAG 시제품으로 근거 표시·분류 구현

주당 3시간, 총 2주(총 6시간) 내에 Python 기반 최소 RAG 시제품을 구현합니다. 목표는 가상 규정 3건에서 질문 5건에 대해 근거(문장/섹션)를 표시하고, 근거가 없는 질문은 '근거 없음'으로 분류하는 것입니다. 기존 Python·데이터 처리 경험은 활용하되 기초 반복은 배제합니다. 비용은 20,000원 이내로 제한하며, 외부 유료 서비스는 사용하지 않습니다. 산출물은 코드(검색·매칭·응답 포맷), 테스트 케이스(5문항), 결과 보고서(성공/실패 분류)입니다.

### 1. 데이터 준비 및 검색 파이프라인 설계

- 목표: 가상 규정 3건을 구조화하고, 검색(문서 분할·키워드 인덱스)과 매칭 로직을 설계한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 200~500자)을 JSON/텍스트로 준비하고 메타데이터(섹션, 조항)를 추가
- 활동: 문서 분할 전략(섹션 단위 또는 문장 단위)을 결정하고 샘플 분할 수행
- 활동: 간단한 검색 파이프라인 설계: 토큰화→키워드 인덱스(예: inverted index) 또는 TF-IDF 기반 유사도 계산
- 활동: 검색 결과에 대한 근거 표시 규칙 정의(예: 매칭 문장 + 출처 섹션 표기)
- 산출물: 가상 규정 3건의 구조화된 데이터 파일(JSON)
- 산출물: 문서 분할 샘플(각 문서에서 3~5개 분할 예시)
- 산출물: 검색 파이프라인 설계 문서(간단한 흐름도 또는 단계 설명)
- 산출물: 근거 표시 규칙 문서(예: {answer, evidence: [{text, source_section}]})
- 완료 기준: 미확인

### 2. 최소 RAG 구현·테스트·보고서 작성

- 목표: 검색 결과를 기반으로 근거를 표시하는 응답 포맷을 구현하고, 5개 질문으로 성공/실패를 분류해 보고서를 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: Python으로 검색 파이프라인 구현(간단한 함수/스크립트, 외부 DB 불필요)
- 활동: 응답 포맷 구현: 각 질문에 대해 {answer, evidence[], confidence} 구조로 출력
- 활동: 테스트 질문 5건(근거 있음 3건, 근거 없음 2건)을 실행하고 결과 수집
- 활동: 결과 분석: 검색 성공(근거 표시), 근거 누락(부분 매칭), 답변 불가(근거 없음)로 분류
- 활동: 간단한 성능 지표(정확히 근거를 표시한 비율, 근거 누락 비율) 계산 및 한계 기술
- 산출물: 실행 가능한 Python 스크립트(검색 + 응답 포맷)
- 산출물: 테스트 케이스 5건과 실행 결과(원시 출력)
- 산출물: 결과 보고서(성공/실패 분류, 간단한 지표, 개선 아이디어)
- 산출물: 간단한 사용법 README(실행 방법, 입력/출력 예시)
