# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 우선 실무 적용 로드맵 (1주, 총 4시간)

주어진 1주(총 4시간) 동안 기존 검색 코드의 검증(근거 누락 검출)과 회귀 시험 추가에 집중한다. 시작점 3 이전의 기초 학습은 배정하지 않으며, 이미 작성한 분할·검색 코드를 전제로 검증·테스트 구현과 실행에 시간을 할당한다. 예산은 0원으로 가정하여 무료 도구·로컬 실행 중심으로 진행한다.

### 1. 검증 파이프라인 설계 및 샘플 데이터 준비

- 목표: 기존 검색 결과에서 근거 누락(문서 분할·매칭 실패)을 자동으로 판정하는 검증 파이프라인을 구현하고, 누락 사례를 재현 가능한 테스트셋으로 확보한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 분할·검색 코드에서 입력 문서와 기대 근거(정답 매핑)를 정의하는 샘플 데이터셋을 10~30건 준비
- 활동: 검색 결과와 기대 근거를 비교하는 검증 스크립트 작성(정확도·재현율 기반 누락 판정 로직 포함)
- 활동: 누락 사례를 재현하는 단위 테스트 케이스 5개 이상 작성 및 실행
- 산출물: 검증용 샘플 데이터셋(문서 원본, 분할 결과, 기대 근거 매핑)
- 산출물: 검증 스크립트(누락 판정 로직 포함)
- 산출물: 검증 실행 결과(누락 사례 목록 및 재현 절차)
- 완료 기준: 미확인

### 2. 회귀 테스트 추가 및 자동화

- 목표: 문서 분할·검색 변경 시 근거 누락이 재발하지 않도록 자동화된 회귀 테스트를 추가하고, 테스트 실패 시 원인 추적 절차를 마련한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검증 스크립트를 기반으로 회귀 테스트 케이스를 자동화(예: pytest 또는 기존 테스트 프레임워크 사용)
- 활동: 테스트 실패 시 재현 로그와 입력 샘플을 저장하도록 테스트에 로그·아티팩트 수집 추가
- 활동: 테스트를 CI에 간단히 통합하거나 로컬에서 반복 실행 가능한 스크립트 제공
- 산출물: 회귀 테스트 스위트(자동 실행 가능한 테스트 케이스)
- 산출물: 테스트 실행 결과 리포트(성공/실패 케이스 및 로그)
- 산출물: 간단한 CI 실행 스크립트(로컬 또는 기존 CI에 통합 가능한 형태)
- 완료 기준: 미확인
