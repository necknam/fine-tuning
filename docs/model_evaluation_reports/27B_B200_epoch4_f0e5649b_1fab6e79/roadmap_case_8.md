# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선의 2주 실습형 RAG 검증 로드맵

주어진 2주(총 6시간) 동안 비용 우선 원칙을 반영하여, 기존 Python·데이터 처리 경험을 활용해 문서 검색 결과와 실제 근거를 대조하는 최소 기능 시제품을 구현하고 검증하는 실습 중심 로드맵입니다. 외부 유료 서비스는 사용하지 않으며, 제공된 무료 강좌 ID만 추천합니다. 시간 제약(총 6시간)을 고려해 각 단계는 1주(3시간)로 분배되어 있습니다.

### 1. 기초 준비 및 검색 파이프라인 시제품

- 목표: 문서 인덱싱과 검색 결과의 신뢰성 검증을 위한 최소 기능 시제품 구현
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 문서(가상 문서 10~20개)를 준비하고 메타데이터(문서ID, 출처, 요약)를 정의
- 활동: 간단한 검색 파이프라인 구현(키워드 기반 또는 임베딩 기반 중 선택) 및 검색 결과 반환
- 활동: 검색 결과와 실제 근거(원문 또는 요약)를 비교하는 검증 스크립트 작성(정확도/정밀도/재현율 계산)
- 활동: 작은 연습 문제 설계: 주어진 질의 5개에 대해 검색 결과와 근거를 대조하고 결과표 작성
- 산출물: 간단한 문서 인덱스(예: JSON/CSV)와 검색 함수(검색 쿼리 → 상위 N 문서 반환)
- 산출물: 검색 결과와 가상 문서(또는 제공된 샘플)를 비교하는 간단한 스크립트(정확도/정밀도 계산 포함)
- 산출물: 작은 연습 문제(예: 5개 질의에 대해 검색 결과와 근거를 대조하고 결과표 작성)
- 완료 기준: 미확인

### 2. RAG 통합 및 검증

- 목표: 검색 결과를 생성형 모델에 안전하게 주입하고, 응답의 근거 연결성을 검증하는 시제품 완성
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 프롬프트에 안전하게 주입하는 방식 설계(출처 표기, 신뢰도 필터링)
- 활동: 간단한 LLM 호출(예: API 또는 로컬 모델)을 통해 질의응답 시제품 구현
- 활동: 응답과 근거 문서의 연결성(참조 일치 여부)을 자동/수동으로 평가하는 절차 수립
- 활동: 비용·시간 제약 고려: 외부 유료 서비스 사용 대신 로컬/무료 API 또는 모의 응답으로 테스트
- 산출물: RAG 기반 질의응답 시제품(검색 → 프롬프트 생성 → LLM 호출 → 응답 반환)
- 산출물: 응답 품질 평가표(정확성, 근거 연결성, 실패 사례 목록)
- 산출물: 간단한 개선 권고(프롬프트 변경, 검색 필터링, 추가 검증 단계)
- 완료 기준: 미확인
