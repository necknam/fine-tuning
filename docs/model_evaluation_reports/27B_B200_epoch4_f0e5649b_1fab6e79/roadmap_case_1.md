## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선 2주 최소 RAG 시제품 로드맵

주당 3시간, 총 6시간(2주) 안에 최소 동작 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건의 근거 표시와 근거 없는 질문 구분까지 완료합니다. 예산 20,000원 내에서 외부 유료 서비스 없이 로컬/무료 도구로 구현하고, Microsoft Learn의 관련 모듈을 학습 자료로 병행합니다. 시간·비용 제약이 있으므로 기능은 '최소 검증 가능한 시제품' 수준으로 범위를 좁힙니다.

### 1. 데이터 준비 및 기준 정의

- 목표: 가상 규정 3건과 질문 5건을 확정하고, 각 질문에 대해 기대되는 근거(문서·구간)와 '근거 없음' 판정 기준을 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 1~2페이지 분량)을 작성·정리(텍스트 파일로 저장).
- 활동: 질문 5건을 작성(근거가 있는 3건, 근거가 없는 2건 권장)하고 각 질문에 대해 기대 근거를 표로 정리.
- 활동: 간단한 평가 기준 정의: (a) 근거 문서 ID·구간 표시 여부, (b) 근거 없음 판정 여부, (c) 오탐/미탐 사례 기록 방식.
- 산출물: 가상 규정 3건의 텍스트 파일(예: regulation_1.txt 등)
- 산출물: 질문 5건 목록과 기대 근거 매핑표(CSV 또는 마크다운)
- 산출물: 간단한 평가 기준 문서(1페이지)
- 완료 기준: 규정 3건과 질문 5건이 파일로 준비되고, 각 질문에 대한 기대 근거 매핑표가 작성되어 평가 기준이 문서화되어 있으면 완료.

### 2. 최소 RAG 구현 및 검증

- 목표: 로컬 환경에서 임베딩·검색·생성(또는 검색 기반 응답)을 연결해 5개 질문에 대해 근거 표시와 근거 없음 판정을 수행하고 결과를 비교·기록한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발 환경 준비: Python, 가상환경, 필요한 라이브러리(예: FAISS 또는 단순 검색 라이브러리, 임베딩 라이브러리) 설치.
- 활동: 간단한 임베딩 생성(로컬 모델 또는 무료 API 사용) 및 문서 인덱싱(3건).
- 활동: 검색(임베딩 유사도)으로 상위 근거 후보를 찾고, 후보를 기반으로 간단한 응답 생성(템플릿 기반 또는 LLM 호출) 구현.
- 활동: 5개 질문에 대해 실행하고, 각 질문에 대해 근거 문서·구간을 표시하거나 '근거 없음'으로 분류한 결과표를 작성.
- 활동: 간단한 성능 비교: 기대 근거 매핑표와 실제 출력 비교, 오탐·미탐 사례 기록.
- 산출물: 실행 가능한 코드(예: notebook 또는 스크립트) — 임베딩 생성·인덱싱·검색·응답 생성 포함
- 산출물: 실행 결과표(질문별 출력, 표시된 근거 문서·구간, 근거 없음 여부)
- 산출물: 간단한 검증 리포트(오탐·미탐 사례와 개선 아이디어 1페이지)
- 완료 기준: 코드 실행으로 5개 질문에 대해 근거 표시 또는 '근거 없음' 판정이 수행되고, 결과표와 검증 리포트가 작성되어 기대 매핑과 비교가 완료되면 완료.
