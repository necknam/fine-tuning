## 계획

2주 집중: 최소 RAG 시제품으로 근거 표시·분류 구현

주당 3시간, 총 2주(총 6시간) 내에 Python 기반 최소 RAG 시제품을 구현합니다. 목표는 가상 규정 3건과 질문 5건에 대해 검색 근거를 표시하고, 근거가 없는 질문은 '근거 없음'으로 분류하는 것입니다. 시간 우선 관점에서 핵심 기능(문서 인덱싱, 검색, 간단한 생성/응답 포맷, 근거 표시·분류 로직)만 구현하고, 성능 최적화·배포는 제외합니다. 예산(20,000원)은 선택적 유료 리소스(예: 소규모 벡터 DB 요금·추가 자료 구매)에 사용할 수 있으나, 본 계획은 무료 도구·로컬 실행을 기본으로 합니다.

### 1. 데이터 준비 및 검색 파이프라인 설계

- 목표: 가상 규정 3건을 구조화하고, 질문 5건을 정의하여 검색·매칭 기준을 정한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 200~500자)을 작성하고 JSON/텍스트로 정리
- 활동: 질문 5건(근거 있음 3건, 근거 없음 2건)을 설계
- 활동: 간단한 인덱싱 방식 결정(예: TF-IDF + cosine 유사도 또는 키워드 매칭)
- 활동: 검색 결과에 대한 근거 표시 규칙 정의(문장/섹션 ID 포함)
- 산출물: 가상 규정 3건(파일 또는 JSON)
- 산출물: 질문 5건 목록(근거 유무 라벨 포함)
- 산출물: 검색 파이프라인 설계 문서(간단한 알고리즘·매칭 규칙)
- 산출물: 테스트 케이스(질문→기대 근거 매핑)
- 완료 기준: 미확인

### 2. 최소 RAG 구현 및 검증

- 목표: 검색 결과를 기반으로 간단한 생성/응답 포맷을 만들어 근거를 표시하고, 근거가 없는 질문을 분류한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 Python 스크립트로 인덱싱 및 검색 구현(예: scikit-learn의 TfidfVectorizer + cosine similarity)
- 활동: 검색 결과 상위 N개를 응답에 포함하고 각 근거에 출처(문서 ID·섹션)를 표시
- 활동: 응답 포맷에 '근거 없음' 판정 로직 추가(유사도 임계값 또는 매칭 실패 기준)
- 활동: 테스트 케이스 5건으로 동작 검증 및 결과 기록
- 산출물: 실행 가능한 Python 스크립트(인덱싱·검색·응답 포맷 포함)
- 산출물: 테스트 실행 결과(각 질문에 대한 응답과 표시된 근거 또는 '근거 없음' 표기)
- 산출물: 간단한 검증 리포트(성공/실패 사례와 원인 분석)
