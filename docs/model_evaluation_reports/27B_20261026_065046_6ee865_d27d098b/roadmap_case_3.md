# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실무형 RDBMS 데이터 모델링 실습 로드맵

주당 3시간, 총 2주(총 6시간) 내에 관계형 DB로 가상 지점-지역 모델을 설계하고, 지역별 지점 수 집계 쿼리와 중복 ID 거절(제약) 검증을 완료한다. GIS 서버 구축은 범위에서 제외하며, 산출물은 ERD, DDL, 검증 쿼리 및 테스트 케이스다. 비용은 0원(무료 도구 사용)으로 가정하고, 외부 유료 서비스나 추가 기간은 권장하지 않는다.

### 1. 요구 정의 및 ERD 설계

- 목표: 핵심 엔티티(지점, 지역)와 관계(지점-지역 다대일)를 정의하고 ERD를 작성한다. 중복 ID 거절 요구를 반영한 제약(UNIQUE/PK)을 설계한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 핵심 엔티티 식별: 지점(예: branch_id, name, region_id), 지역(region_id, region_name)
- 활동: 관계 정의: 지점.region_id → 지역.region_id (다대일)
- 활동: 제약 설계: branch_id UNIQUE 또는 PRIMARY KEY, region_id NOT NULL 등
- 활동: 간단한 ERD(도구: draw.io, dbdiagram.io 등 무료 도구) 작성
- 활동: 검증 기준 정의: 지역별 지점 수 쿼리 예시, 중복 ID 삽입 시 에러 발생 여부
- 산출물: ERD 이미지 또는 dbdiagram.io 링크(텍스트 설명 포함)
- 산출물: 요구사항 요약(간단한 텍스트): 엔티티·속성·제약 목록
- 산출물: 검증 기준 문서(지역별 지점 수 쿼리 예시, 중복 ID 테스트 케이스)
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. DDL 작성·테스트 데이터 적재 및 검증

- 목표: ERD를 기반으로 DDL을 작성하고, 테스트 데이터를 적재하여 지역별 지점 수 집계 쿼리와 중복 ID 거절 시나리오를 실행해 결과를 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: DDL 작성: CREATE TABLE 지역, CREATE TABLE 지점(제약 포함)
- 활동: 샘플 데이터 적재(지역 3개, 지점 10개 등 소규모)
- 활동: 집계 쿼리 작성 및 실행: SELECT region_id, COUNT(*) FROM 지점 GROUP BY region_id
- 활동: 중복 ID 테스트: 동일 branch_id 삽입 시도 → 제약에 의해 실패하는지 확인
- 활동: 결과 문서화: 쿼리 결과 스냅샷, 에러 메시지 캡처
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 적재 스크립트(.sql)
- 산출물: 집계 쿼리 결과 스냅샷(스크린샷 또는 텍스트)
- 산출물: 중복 ID 삽입 실패 로그(에러 메시지 포함)
- 완료 기준: 미확인
