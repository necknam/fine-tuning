### 1. 환경 준비 및 재현 코드 작성

- 목표: 로컬에서 재현 가능한 최소 코드(예: C 또는 Python)를 작성해 스레드 두 개가 공유 카운터를 동시에 증가시키는 상황을 만들고, 잠금 미적용 상태에서 오류(예: 최종 카운터 값이 기대값보다 작음)를 재현한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발 환경(컴파일러/인터프리터, 빌드 도구) 확인 및 설치(필요 시)
- 활동: 간단한 스레드 프로그램 작성(예: C의 pthreads 또는 Python의 threading)
- 활동: 공유 카운터 변수를 스레드 두 개가 동시에 증가시키는 루프 구현
- 활동: 잠금 미적용 상태에서 여러 번 실행해 로그(예: 최종 카운터 값, 실행 횟수) 수집
- 산출물: 재현 코드(소스 파일)와 실행 방법(README)
- 산출물: 잠금 미적용 상태의 실행 로그(최소 10회 이상 반복 결과)
- 산출물: 간단한 실행 스크립트(반복 실행용)
