- 관점: 시간 우선

## 계획

1주 집중 실습: SQLite 재고 모델 설계·외래키·JOIN 검증

주어진 1주(총 4시간) 내에 로컬 SQLite 환경에서 재고 품목과 입출고 테이블을 설계하고, 외래키 제약과 JOIN 결과를 검증하는 작은 산출물을 완성합니다. 시간 우선 관점에서 범위를 최소한의 핵심 활동(설계·DDL·샘플 데이터·검증 쿼리)으로 좁혀 완료 기준을 명확히 합니다.

### 1. 요구·스키마 설계

- 목표: 핵심 엔티티(품목, 입출고)와 관계(외래키)를 정의하고 DDL을 작성한다.
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 핵심 엔티티와 속성 목록 작성(품목: id, name, unit, initial_qty; 입출고: id, item_id, type(IN/OUT), qty, occurred_at)
- 활동: 관계 정의: transactions.item_id → items.id (외래키)
- 활동: SQLite DDL 작성(테이블 생성, PRIMARY KEY, FOREIGN KEY 제약 포함)
- 활동: 간단한 ER 다이어그램(텍스트 또는 이미지) 작성
- 산출물: items.sql, transactions.sql (DDL)
- 산출물: 간단한 ER 다이어그램(텍스트 또는 이미지)
- 산출물: 설계 노트(속성·제약 설명)
- 완료 기준: DDL 파일이 존재하고, SQLite에서 테이블 생성이 오류 없이 실행되며 외래키 제약이 정의되어 있어야 함.

### 2. 샘플 데이터 적재 및 검증

- 목표: 샘플 데이터를 적재하고 외래키 제약이 동작함을 확인하며 JOIN으로 재고 잔량을 계산하는 쿼리를 실행해 결과를 검증한다.
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 데이터(예: 5개 품목, 10건 입출고)를 INSERT로 적재
- 활동: 외래키 위반 시 에러 발생 여부 확인(의도적 위반 테스트 포함)
- 활동: JOIN 쿼리 작성: items LEFT JOIN transactions로 품목별 현재 재고 잔량 계산
- 활동: 결과를 스크린샷 또는 CSV로 저장하고 간단한 검증 노트 작성
- 산출물: sample_data.sql (INSERT 스크립트)
- 산출물: validation_queries.sql (JOIN 및 잔량 계산 쿼리)
- 산출물: 검증 결과(스크린샷 또는 CSV) 및 검증 노트
- 완료 기준: 샘플 데이터 적재 후 JOIN 쿼리가 실행되어 품목별 잔량이 계산되고, 외래키 위반 시 SQLite가 에러를 반환함을 확인한 문서가 존재해야 함.
