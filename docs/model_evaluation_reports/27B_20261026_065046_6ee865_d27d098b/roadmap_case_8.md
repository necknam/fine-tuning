### 2. 과도한 권한 식별 및 문서화

- 목표: 작성한 권한표를 근거로 과도한 권한 3가지를 식별하고, 각 항목에 대해 위험·영향·권고안을 문서화한다.

- 완료 기준: 권한표에서 과도한 권한 3개가 식별되어 각 항목에 대해 위험·영향·권고안이 문서화되어야 한다. 권고안은 최소 권한 원칙을 반영해야 하며, 실제 계정·외부 API 호출 없이 문서로 검증 가능해야 한다.
