# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

초단기 비용 우선 RAG 실패 재현 로드맵

가용 시간(총 4시간)과 예산 제약을 우선 반영하여, 이미 있는 Python 환경과 가상 문서만 사용해 RAG 검색 실패를 재현하고 실패 원인을 문서화하는 2주(총 4시간) 계획입니다. 외부 유료 자료·추가 인프라는 사용하지 않으며, 성공/실패 판정 기준을 명확히 하여 최소 작업으로 완료합니다.

### 1. 환경 점검 및 실패 재현

- 목표: 가상 문서 3건과 검색 파이프라인을 준비해 3건 중 최소 1건 이상 실패를 재현
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건 준비(텍스트 파일 또는 로컬 DB)
- 활동: 간단한 검색 파이프라인(인덱스 생성·쿼리 실행) 구성
- 활동: 각 문서에 대해 동일 쿼리로 검색 실행하여 실패 사례 수집
- 산출물: 재현용 문서 3건(파일 또는 DB)
- 산출물: 실패 재현 로그(각 문서별 쿼리·응답 포함)
- 완료 기준: 3건 중 최소 1건에 대해 검색이 실패하거나 기대 결과와 다른 응답을 반환하는 로그를 확보

### 2. 원인 분석 및 개선 실험(간단)

- 목표: 실패 원인을 분류하고, 최소한의 수정(문서 전처리·쿼리 수정·인덱스 재구성)으로 재현 시도
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 실패 로그를 바탕으로 원인 후보(문서 전처리, 토큰화, 인덱스 설정, 쿼리 매칭) 분류
- 활동: 각 후보에 대해 소규모 수정(예: 전처리 스크립트 변경, 쿼리 리라이팅) 적용
- 활동: 수정 후 동일 쿼리로 검색 재실행하여 결과 비교
- 산출물: 원인 분석 요약(각 실패별 원인 후보 및 우선순위)
- 산출물: 수정 적용 전/후 비교 로그 및 간단한 개선 권고
- 완료 기준: 각 실패에 대해 원인 후보를 문서화하고, 최소 1건의 수정으로 검색 결과가 개선되었거나 개선 불가 원인을 명확히 기술
