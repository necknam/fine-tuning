# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 우선: 기존 검색 코드의 근거 누락·회귀 검출 추가(업무 적용 중심)

1주(총 4시간) 동안 기존 검색 코드의 실패 사례를 우선 수집하고, 최소한의 근거 누락 검출 로직과 회귀 테스트를 추가해 재현 가능한 검증 산출물을 만든 뒤 한계와 다음 검증 범위를 정리합니다. 시작점(이미 작성된 검색 코드)을 전제로 하며, 추가 학습은 검증 활동에 통합합니다. 예산·외부 승인 확인이 필요하면 범위를 축소하거나 기간을 연장합니다.

### 1. 검증 범위 확정 및 실패 사례 수집

- 목표: 검증 대상 문서·질문·기대 결과 목록 확보 및 실패 사례 5건 이상 수집
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 코드와 관련 입력(문서, 쿼리) 목록 정리
- 활동: 검증에 사용할 샘플 문서 10건 선정
- 활동: 기대 결과(정답 문서 ID 또는 불일치 여부)를 명시
- 활동: 실패 사례 5건 이상을 문서화(입력·출력·기대값 포함)
- 산출물: 검증 대상 문서 목록(샘플 포함)
- 산출물: 실패 사례 5건 이상(질문·기대 결과·현재 출력 포함)
- 완료 기준: 검증 대상 문서 목록과 5건 이상의 실패 사례가 문서화되어 재현 절차가 작성되어야 완료로 본다.

### 2. 근거 누락 검출 로직 구현 및 회귀 테스트 작성

- 목표: 검색 결과와 문서 출처 불일치 여부를 자동으로 판별하는 최소 로직 구현 및 회귀 테스트 작성
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검증 대상 문서의 메타데이터(출처, 페이지 등)를 표준화
- 활동: 검색 결과와 문서 출처 불일치 판별 로직(간단한 규칙 기반) 구현
- 활동: 회귀 테스트 스크립트 작성(수집한 실패 사례 포함)
- 활동: 테스트 실행 및 결과 기록
- 산출물: 근거 누락 검출 코드(주석 포함)
- 산출물: 회귀 테스트 스크립트 및 실행 결과(성공/실패 표)
- 산출물: 간단한 사용법 문서(1페이지)
- 완료 기준: 회귀 테스트를 실행해 수집한 실패 사례 중 최소 3건이 검출 로직으로 식별되어야 완료로 본다. 코드와 테스트는 재현 가능해야 한다.
