- 목표: 로컬 개발 환경과 소규모 근거 문서(예: 20~50문장)를 확보하여 인덱싱 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발 환경(예: Python 가상환경, 필요한 라이브러리 설치) 확인
- 활동: 소규모 근거 문서(텍스트 파일 또는 CSV)를 수집·정리
- 활동: 문서 전처리(텍스트 정규화, 토큰화) 스크립트 작성
- 산출물: 로컬 개발 환경(예: Python 가상환경, 필요한 라이브러리 설치) 확인 기록
- 산출물: 인덱싱에 사용할 근거 문서 목록(파일 또는 텍스트)
- 완료 기준: 로컬에서 문서 로드 및 인덱스 초기화가 실행되는지 확인 가능한 상태

### 2. 간단한 RAG 파이프라인 구현 및 검증

- 목표: 문서 인덱싱과 쿼리 응답을 연결하는 최소 동작 파이프라인을 구현하고, 근거 문장 매핑을 확인
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 문서 인덱싱(벡터 인덱스 또는 간단한 키워드 인덱스) 구현
- 활동: 쿼리 전처리 및 검색(벡터 검색 또는 키워드 매칭) 구현
- 활동: 검색 결과에 대해 간단한 에이전트 흐름(예: 문서 출처 표시, 정답 매핑) 추가
- 활동: 정답 매핑 테스트 케이스(쿼리-정답 문서 쌍)와 실행 결과 기록
- 산출물: 실행 가능한 RAG 시제품(코드)과 간단한 사용법 문서
- 산출물: 정답 매핑 테스트 케이스(쿼리-정답 문서 쌍)와 실행 결과
