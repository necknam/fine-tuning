- 목표: 실행 가능한 로컬 환경과 평가 기준 정의

- 활동: 로컬 개발 환경(파이썬, 가상환경, 필요한 라이브러리) 설치 및 확인
- 활동: 샘플 문서(가상 문서) 10건 준비 및 메타데이터 정의
- 활동: 평가 기준(정확도, 정합성, 응답 형식) 문서화
- 산출물: 실행 환경 체크리스트(필요 패키지·데이터 샘플 포함)
- 산출물: 평가 기준 문서(정확도·정합성·응답 형식)
- 완료 기준: 로컬에서 샘플 쿼리 실행이 재현 가능하고 평가 기준 문서가 작성되어 있어야 완료로 본다.

- 목표: 검색 결과와 모델 응답을 연결해 근거 추적 가능한 시제품을 만든다
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색(벡터 또는 키워드) 파이프라인 구현 및 샘플 문서 인덱싱
- 활동: 간단한 LLM 호출(로컬 또는 공개 API 사용 가능 시)로 응답 생성
- 활동: 검색 결과와 모델 응답을 연결해 근거 추적 표 작성 및 검증 리포트 작성
