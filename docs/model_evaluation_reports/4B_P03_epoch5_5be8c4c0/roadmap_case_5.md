## 계획

검증 우선: 기존 검색 코드에 근거 누락 검출과 회귀 테스트 추가

5주(총 20시간) 동안 기존 검색 코드의 근거 누락(검색 결과와 문서 ID 불일치)을 자동으로 탐지하고, 회귀 테스트를 추가하여 재현 가능한 검출 파이프라인을 만든다. 업무 적용 관점에서 최소한의 코드 변경과 테스트를 통해 검출·보고·재현까지 완료한다. 추가 비용·유료 자료는 예산·승인 확인이 필요하며 이 계획에는 포함하지 않는다.

### 1. 1단계 · 검증 범위 정의 및 기준선 수집

- 목표: 검출 대상(문서 ID 불일치, 근거 누락)과 우선순위 케이스 정의, 기존 코드 실행 결과 수집
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 기존 검색 코드와 샘플 쿼리·문서 목록 확인
- 활동: 검출할 오류 유형(문서 ID 불일치, 근거 누락) 목록 작성
- 활동: 기준선: 현재 코드가 반환하는 문서 ID와 실제 문서 매핑을 비교하는 간단한 스크립트 작성
- 산출물: 검출 대상 목록(우선순위 포함)
- 산출물: 기준선 스크립트(문서 ID 불일치 비교 결과)
- 완료 기준: 검출 대상 목록과 기준선 스크립트가 작성되어 기존 코드의 문서 ID 불일치 사례를 식별할 수 있을 때 완료

### 2. 2단계 · 검출 로직 구현 및 단위 테스트

- 목표: 문서 ID 불일치와 근거 누락을 탐지하는 최소 기능 구현과 단위 테스트 작성
- 기간: 2 · 시간: 8시간 · 비용: 0원
- 활동: 문서 ID 불일치 탐지 로직 구현(문서 매핑 비교)
- 활동: 근거 누락 탐지 로직 구현(검색 결과에 문서 ID가 없는 경우 식별)
- 활동: 단위 테스트 작성(정상·오류 케이스 포함)
- 산출물: 검출 로직 코드(핵심 함수)
- 산출물: 단위 테스트 코드 및 실행 결과
- 완료 기준: 단위 테스트가 통과하고, 샘플 케이스에서 문서 ID 불일치·근거 누락이 탐지될 때 완료

### 3. 3단계 · 회귀 테스트 추가 및 통합 검증

- 목표: 기존 기능에 회귀 테스트를 추가하고, 통합 테스트로 검출 파이프라인이 정상 동작함을 확인
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 기존 검색 쿼리·문서에 대해 회귀 테스트 케이스 추가
- 활동: 통합 테스트 실행(검출 파이프라인과 기존 검색 결과 비교)
- 활동: 테스트 실패 시 원인 추적 및 수정
- 산출물: 회귀 테스트 케이스 목록 및 실행 결과
- 산출물: 통합 테스트 실행 로그
- 완료 기준: 회귀 테스트가 통과하고, 통합 테스트에서 기존 검색 결과와 검출 파이프라인이 일관되게 동작할 때 완료

### 4. 4단계 · 결과 정리·업무 적용 가이드 작성

- 목표: 검출 결과를 운영에 적용할 수 있는 간단한 가이드와 체크리스트 작성
- 기간: 1 · 시간: 4시간 · 비용: 0원
- 활동: 검출 결과의 의미와 우선순위(우선 수정 항목) 정리
- 활동: 운영 적용 체크리스트(테스트·모니터링·알림) 작성
- 활동: 간단한 README로 재현 방법과 유지보수 절차 문서화
- 산출물: 검출 결과 요약 보고서
- 산출물: 운영 적용 체크리스트 및 README
- 완료 기준: 검출 결과 요약과 운영 적용 체크리스트가 작성되어 다른 개발자가 재현·적용할 수 있을 때 완료
