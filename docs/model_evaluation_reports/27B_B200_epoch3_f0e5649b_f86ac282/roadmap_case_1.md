## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선: 최소 기능 RAG 시제품(2주, 총 6시간)

주어진 2주(총 6시간)와 예산 20,000원 내에서 '가상 규정 3건'을 인덱싱하고, 5개 질문(근거 있는 3건, 근거 없는 2건)에 대해 근거를 표시하거나 '근거 없음'으로 구분하는 최소 RAG 시제품을 구현합니다. 비용 우선 관점에서 무료 도구·로컬 실행·소규모 데이터로 범위를 좁혀 결과(검색 성공·근거 누락·답변 불가)를 명확히 구분하는 데 집중합니다.

### 1. 데이터 준비 및 기준 정의

- 목표: 가상 규정 3건(각 1~2문단)과 질문 5건(근거 있는 3건, 근거 없는 2건)을 확정하고 평가 기준(검색 성공/근거 누락/답변 불가)을 정의
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(예: 인사규정·데이터관리규정·예산규정)을 1~2문단씩 작성(총 약 300~600자)
- 활동: 각 규정에서 근거가 될 문장(증거 문장)을 1~2개씩 표시
- 활동: 질문 5건 작성: 근거 있는 질문 3건(각각 특정 규정 문장에 대응), 근거 없는 질문 2건(규정 어디에도 근거 없음)
- 활동: 평가 기준 문서화: 검색 성공(증거 문장 포함), 근거 누락(증거 문장 일부만 포함), 답변 불가(증거 없음)
- 산출물: 가상 규정 3건(텍스트 파일)
- 산출물: 질문 5건 목록(근거 여부 표기)
- 산출물: 평가 기준 문서(검색 성공/근거 누락/답변 불가 정의)
- 완료 기준: 미확인

### 2. 최소 RAG 파이프라인 구현 및 검증

- 목표: 로컬에서 동작하는 최소 RAG 파이프라인을 구현하여 5개 질문에 대해 근거 표시 또는 '근거 없음'으로 응답하고, 결과를 평가·문서화
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 환경 구성: Python(이미 숙련), FAISS 또는 in-memory 벡터 인덱스, 무료 로컬 임베딩(예: sentence-transformers) 사용
- 활동: 규정 텍스트를 소문단 단위로 분할하고 임베딩 생성 후 인덱싱
- 활동: 간단한 검색(상위 k=2~3)과 응답 생성(간단한 템플릿 또는 소형 LLM 호출)으로 근거 문장 포함 여부 판단
- 활동: 5개 질문에 대해 실행하고 결과를 평가(검색 성공/근거 누락/답변 불가) 및 실패 원인 기록
- 산출물: 실행 가능한 코드(간단한 노트북 또는 스크립트)
- 산출물: 인덱스(로컬 파일)와 검색 결과 로그
- 산출물: 평가 리포트: 각 질문에 대한 응답, 근거 문장(있으면), 분류(검색 성공/근거 누락/답변 불가) 및 한계 설명
- 완료 기준: 미확인
