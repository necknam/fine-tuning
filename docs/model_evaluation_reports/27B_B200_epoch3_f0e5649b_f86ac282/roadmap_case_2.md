# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

시간 우선: 2주 내 최소 동작 RAG 시제품(근거 표시·근거 없음 구분)

주당 3시간, 총 6시간(2주)으로 제한된 시간 안에 '가상 규정 3건'을 인덱싱하고, 5개 질문(근거 있는 3건·근거 없는 2건)에 대해 검색·응답·근거 표시를 구현하는 최소 RAG 시제품을 완성합니다. 목표는 프로덕션 배포가 아닌 학습용 동작 확인이며, 각 단계는 실제 구현·검증 산출물을 중심으로 설계되어 시간 효율을 극대화합니다.

### 1. 데이터 준비 및 인덱싱

- 목표: 가상 규정 3건을 구조화·토큰화·벡터 인덱싱하여 검색 가능한 상태로 만들기
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(예: 인사규정·데이터관리규정·AI운영규정)을 텍스트로 준비(각 규정 1~2페이지 분량 권장)
- 활동: 문서 분할(섹션·조항 단위) 및 메타데이터(문서ID·조항ID) 추가
- 활동: 간단한 임베딩(예: 로컬 임베딩 모델 또는 API 사용)으로 벡터 생성
- 활동: 벡터 인덱스(예: FAISS 또는 간단한 in-memory 인덱스)에 저장
- 산출물: 가상 규정 원문(3개 파일) 및 메타데이터 포함 CSV/JSON
- 산출물: 임베딩 생성 스크립트(실행 가능한 Python 노트북 또는 스크립트)
- 산출물: 벡터 인덱스 파일(또는 인덱스 생성 코드)
- 완료 기준: 3개 규정 문서가 벡터 인덱스에 저장되어 있고, 간단한 쿼리로 관련 문장(조항)을 검색할 수 있음(검색 결과에 문서ID·조항ID 포함)

- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi

### 2. 검색·응답 파이프라인 구현 및 검증

- 목표: 검색 결과를 기반으로 LLM 응답을 생성하고, 각 응답에 근거(출처·문장)를 표시하거나 근거 없음으로 분류하는 로직 구현
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과(상위 k개)를 프롬프트에 포함시켜 LLM에 질의(간단한 프롬프트 템플릿 사용)
- 활동: 응답에 대해 근거 매핑: 응답 문장에 대응하는 원문 문장(또는 조항)을 찾아 출처 표시
- 활동: 근거가 없는 경우(검색 결과와 응답이 불일치하거나 관련 문장이 없음) '근거 없음'으로 분류하는 규칙 구현
- 활동: 5개 질문(근거 있는 3건·근거 없는 2건)으로 동작 검증 및 결과 기록
- 산출물: 검색→프롬프트→응답 파이프라인 코드(노트북 또는 스크립트)
- 산출물: 5개 질문별 응답과 근거 매핑 결과(테이블 또는 JSON)
- 산출물: 간단한 검증 리포트(성공/실패 사례와 원인 요약)
- 완료 기준: 5개 질문 중 최소 3건에 대해 응답과 함께 원문 근거(문서ID·조항ID·원문 문장)를 표시하고, 나머지 2건은 '근거 없음'으로 명확히 구분하여 결과 리포트 제출
