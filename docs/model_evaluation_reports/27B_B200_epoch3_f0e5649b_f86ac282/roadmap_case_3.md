## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 집중 실습: 최소 RAG 시제품으로 근거 표시 및 근거 없는 질문 구분

주어진 2주(총 6시간) 동안 Python 기반 최소 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건에 대해 근거를 표시하고, 근거가 없는 질문은 '근거 없음'으로 구분하는 것을 목표로 합니다. 개발 경험(4점)을 활용하여 설계·구현·검증을 빠르게 수행하되, LLM·RAG는 처음이므로 핵심 개념(임베딩, 유사도 검색, 간단한 프롬프트)만 실습합니다. 예산(20,000원)은 유료 서비스·데이터 구매에 사용하거나 무료 도구로 대체할 수 있으며, 비용이 확인되지 않은 자료는 무료·소요 시간으로 단정하지 않습니다.

### 1. 요구·데이터 준비 및 설계

- 목표: 가상 규정 3건과 질문 5건을 확정하고, 각 문서의 문장 단위로 인덱싱 가능한 형태로 준비한다. 검색 성공·근거 누락·답변 불가의 판정 기준을 정의한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 1~2페이지 분량)을 작성하거나 제공된 샘플을 사용한다.
- 활동: 질문 5건을 설계: 명확한 근거가 있는 질문 3건, 근거가 불명확한 질문 1건, 근거가 전혀 없는 질문 1건.
- 활동: 문서를 문장 단위로 분할하고 각 문장에 ID(문서ID:문장ID)를 부여한다.
- 활동: 검색 성공 기준 정의: 검색된 문장이 질문의 핵심 키워드·의미를 포함하고, 프롬프트에서 해당 문장을 근거로 답변 생성 시 출처를 표시할 수 있어야 함.
- 활동: 근거 없음 판정 기준 정의: 검색 결과의 유사도 점수가 임계값(예: cosine similarity < 0.35)이거나, 검색된 문장이 질문의 핵심을 충족하지 못할 경우 '근거 없음'으로 처리.
- 산출물: 가상 규정 3건(텍스트 파일 또는 JSON)과 질문 5건 목록
- 산출물: 문장 단위 인덱스(문서ID:문장ID 포함) CSV 또는 JSON
- 산출물: 검색 성공·근거 없음 판정 기준 문서(간단한 1페이지)
- 완료 기준: 미확인

### 2. 최소 RAG 구현 및 검증

- 목표: 임베딩 기반 유사도 검색과 간단한 프롬프트 조합으로 질문에 대해 근거 문장을 찾아 표시하고, 근거가 없으면 '근거 없음'으로 응답하도록 구현·검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 임베딩 생성: 문장별 임베딩을 생성(예: 로컬 임베딩 모델 또는 API 사용). 비용·시간이 확인되지 않은 외부 API는 사용 전 비용·응답시간 확인 필요.
- 활동: 벡터 인덱스 구성: FAISS 또는 유사한 경량 인덱스로 문장 임베딩을 인덱싱.
- 활동: 검색·프롬프트 파이프라인 구현: 질문 임베딩으로 상위 k개 문장 검색 후, 검색된 문장을 프롬프트에 포함시켜 LLM에 근거를 표시하도록 요청(출처 문서ID·문장ID 포함).
- 활동: 근거 없음 처리: 검색 유사도 임계값 미달 시 LLM 호출 없이 '근거 없음' 응답을 반환.
- 활동: 검증: 질문 5건에 대해 기대 결과(근거 표시 또는 근거 없음)와 실제 결과를 비교하여 성공/실패를 기록.
- 활동: 간단한 성능·한계 문서화: 검색 정확도(정성적), 응답 시간, 비용(사용한 유료 서비스·예상 비용) 및 한계(임베딩 품질·문서 분할 영향)를 기술.
- 산출물: 실행 가능한 코드(예: Jupyter 노트북 또는 Python 스크립트) — 임베딩 생성, 인덱싱, 검색, 프롬프트 조합, 근거 표시 로직 포함
- 산출물: 검증 결과표: 질문별 기대 결과 vs 실제 결과(근거 표시/근거 없음) 및 검색된 문장 ID
- 산출물: 간단한 사용법·한계 문서(1페이지)
- 완료 기준: 미확인
