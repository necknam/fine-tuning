## 계획

1주 집중 실습: SQLite 기반 재고 데이터 모델링 및 JOIN 검증

주어진 1주(총 4시간) 내에 로컬 SQLite 환경에서 재고 품목·입출고 테이블을 설계하고, 외래키 제약과 JOIN 결과를 검증하는 산출물을 완성한다. 시간 우선 관점에서 설계·구현·검증의 핵심 단계만 수행하고, 불필요한 확장(예: 클라우드 배포, 복잡한 인덱스 튜닝)은 배제한다.

### 1. 요구·스키마 설계

- 목표: 핵심 엔티티(품목, 입출고)와 관계(외래키)를 정의하고 SQLite DDL을 작성한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항(필드·관계)을 1페이지로 정리
- 활동: ER 다이어그램(간단한 텍스트 또는 이미지) 작성
- 활동: SQLite DDL(테이블 생성, PK, FK, 기본 제약) 작성
- 산출물: 요구사항 1페이지(텍스트)
- 산출물: 간단한 ER 다이어그램(텍스트 또는 이미지)
- 산출물: SQLite DDL 파일(.sql)
- 완료 기준: 미확인

### 2. 샘플 데이터 적재 및 JOIN 검증

- 목표: 샘플 데이터를 삽입하고, 외래키 제약이 동작하는지 확인하며 JOIN 쿼리의 결과 정확성을 검증한다.
- 기간: 0.25 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 데이터(품목 5개, 입출고 10건 등) 삽입 스크립트 작성
- 활동: 외래키 제약 위반 시 에러 발생 여부 확인
- 활동: 대표 JOIN 쿼리(품목별 총입고/총출고, 현재 재고 계산) 실행 및 결과 검증
- 산출물: 데이터 삽입 스크립트(.sql)
- 산출물: JOIN 쿼리 목록 및 실행 결과 스냅샷
- 산출물: 외래키 제약 테스트 결과(성공/실패 로그)
- 완료 기준: 미확인

### 3. 간단한 성능·정확성 점검 및 산출물 정리

- 목표: 기본 쿼리 실행계획을 확인하고, 결과 비교·문서화하여 최종 산출물을 정리한다.
- 기간: 0.25 · 시간: 미확인시간 · 비용: 미확인원
- 활동: EXPLAIN QUERY PLAN으로 주요 쿼리 실행계획 확인
- 활동: 예상 결과와 실제 결과 비교(간단한 테스트 케이스)
- 활동: 최종 산출물(DDL, 데이터, 쿼리, 검증 결과)을 한 폴더로 정리
- 산출물: 쿼리 실행계획 스냅샷
- 산출물: 검증 결과 요약(간단한 표 또는 텍스트)
- 산출물: 최종 산출물 폴더(DDL, 데이터, 쿼리, 검증 결과)
- 완료 기준: 미확인
