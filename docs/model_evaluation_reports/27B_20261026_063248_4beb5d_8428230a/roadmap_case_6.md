# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선·짧은 실험 중심 로드맵

가용 시간(총 6시간)과 예산(0원)을 고려해 2주(주당 3시간) 동안 작은 신경망 실험 하나를 구현하고 학습 로그를 정리해 손실 변화와 입력·출력 차원의 관계를 확인하는 데 집중합니다. 실서비스 성능 개선이나 대규모 데이터 처리는 목표로 하지 않습니다.

### 1. 환경 준비 및 최소 실험 구현

- 목표: 작은 신경망(예: 1~2개의 은닉층)을 구현해 입력·출력 차원과 손실 변화만 관찰할 수 있도록 한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 또는 무료 클라우드(예: Google Colab)에서 Python 환경 준비(필요 라이브러리 설치)
- 활동: 간단한 합성 데이터(예: 2차원 분류용 작은 데이터셋) 생성 또는 사용
- 활동: 작은 신경망 모델(입력층→은닉층 1~2개→출력층) 구현 및 학습 스크립트 작성
- 활동: 학습 중 에포크별 손실과 정확도(또는 분류 지표)를 기록
- 산출물: 환경 점검 기록(사용한 Python/라이브러리 버전, 실행 명령)
- 산출물: 간단한 신경망 코드(예: PyTorch 또는 TensorFlow 핵심 코드 1개 파일)
- 산출물: 학습 로그(에포크별 손실·정확도 CSV 또는 로그 파일)
- 완료 기준: 미확인

### 2. 결과 정리 및 간단한 분석

- 목표: 학습 로그를 정리해 손실 변화와 모델 동작을 비교·요약하고 결과표를 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 에포크별 손실·정확도 로그를 CSV로 정리
- 활동: 간단한 시각화(손실 곡선, 정확도 곡선) 생성
- 활동: 입력·출력 차원, 하이퍼파라미터(학습률, 배치크기)와 손실 변화의 관계를 짧은 노트로 정리
- 활동: 실험 한계와 다음 실험 아이디어(우선순위 1~2개)를 기술
- 산출물: 에포크별 손실·성능을 정리한 결과표(CSV 또는 스프레드시트)
- 산출물: 간단한 시각화(손실 곡선, 정확도 곡선) 이미지 파일
- 산출물: 짧은 실험 보고서(목표, 설정, 관찰된 손실 변화, 한계)
- 완료 기준: 미확인
