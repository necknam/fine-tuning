- 관점: 비용 우선

## 계획

비용 우선·짧은 주기 실습 중심 로드맵

2주(총 6시간) 동안 단일 서버와 이중화 아키텍처의 차이를 다이어그램과 장애 대응표로 정리하는 실습 중심 계획입니다. 예산 0원, 주당 3시간을 반영하여 이론 반복 없이 설계·비교·문서화 산출물에 집중합니다. 제공된 무료 강좌를 보조 자료로 권합니다.

### 1. 단일 서버 아키텍처 이해 및 문서화

- 목표: 단일 서버 구성의 핵심 구성요소와 장애 발생 시 영향 범위를 이해하고 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 단일 서버 아키텍처(컴퓨팅·스토리지·네트워크)를 다이어그램으로 작성
- 활동: 단일 서버에서 발생할 수 있는 주요 장애 모드(하드웨어·소프트웨어·네트워크)를 목록화
- 활동: 각 장애 모드에 대한 영향 범위와 우선순위를 간단히 기술
- 산출물: 간단한 단일 서버 아키텍처 다이어그램(컴포넌트·네트워크·스토리지 표기)
- 산출물: 단일 서버의 주요 장애 모드 목록(하드웨어·소프트웨어·네트워크)
- 완료 기준: 미확인

### 2. 이중화 아키텍처 설계 및 장애 대응표 작성

- 목표: 이중화 구성의 기본 패턴을 설계하고 단일 서버 대비 장애 대응 차이를 표로 정리한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 이중화 패턴(예: 액티브-패시브, 액티브-액티브) 중 하나를 선택해 다이어그램으로 설계
- 활동: 장애 발생 시 탐지·격리·복구 절차를 단계별로 정리한 장애 대응표 작성
- 활동: 단일 서버와 이중화 구조의 복구 시간·복잡도·비용(정성적) 비교
- 산출물: 이중화(예: 액티브-패시브, 액티브-액티브) 아키텍처 다이어그램
- 산출물: 장애 대응표(장애 유형별 탐지·격리·복구 절차와 예상 RTO/RPO 간단 표기)
- 산출물: 단일 서버 대비 이중화 구조의 장단점 비교표
- 완료 기준: 미확인
