## 계획

시간 우선: 1주(총 4시간) 내 완료 가능한 최소 산출물 중심 실습

가용 시간(1주, 주 4시간)과 예산(0원)을 우선 반영하여 범위를 최소화했습니다. 목표는 로컬 SQLite 환경에서 재고 품목·입출고 테이블을 설계하고 외래키 제약과 JOIN 결과를 검증하는 작은 SQL 산출물(DDL, 샘플 데이터, 검증 쿼리)을 만드는 것입니다. 시작점(start_stage=2)을 고려해 기초 데이터 모델링 지식은 이미 보유하고 있다고 가정하고, 설계→구현→검증의 최소 흐름만 수행합니다.

### 1. 설계·구현·검증(단기 실습)

- 목표: 로컬 SQLite에서 재고 품목·입출고 테이블을 설계하고 외래키 제약과 JOIN 결과를 검증하는 산출물을 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 요구사항(필드·관계)을 간단히 정의: 품목(id, name, price), 입출고(id, item_id, qty, type, ts) 등
- 활동: ER 다이어그램을 손으로 그어 관계(1:N 등)와 PK/FK를 명시
- 활동: SQLite DDL 작성: CREATE TABLE, FOREIGN KEY 제약 포함
- 활동: 샘플 데이터(각 테이블 5~10건) 삽입 스크립트 작성
- 활동: JOIN 쿼리(예: 품목별 총 입고량, 최근 출고 내역) 작성 및 결과 검증
- 산출물: ER 다이어그램(간단한 표기)
- 산출물: SQLite용 DDL 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: 검증용 SQL 쿼리 목록 및 실행 결과 스냅샷
- 완료 기준: 미확인
