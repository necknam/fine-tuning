## 계획

비용 우선·단기 문서화 중심 접근

주어진 1주(총 3시간) 동안 실제 계정·외부 API 호출 없이 가상 서비스의 읽기·쓰기 권한표를 작성하고 과도한 권한 3가지를 문서로 점검한다. 시간·비용 제약을 고려해 범위를 '문서화·분석'으로 한정한다.

### 1. 권한표 작성 및 과도 권한 식별

- 목표: 가상 서비스의 읽기·쓰기 권한표를 작성하고 과도한 권한(과다부여) 사례 3가지를 식별·문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 서비스(예: 스토리지, 컴퓨트, 로그, 관리 콘솔) 목록을 정의한다.
- 활동: 각 서비스에 대해 최소권한 원칙에 따른 읽기·쓰기 권한표를 작성한다.
- 활동: 현실적 시나리오를 바탕으로 과도한 권한(예: 전체 삭제 권한, 관리자 권한의 불필요한 부여, 광범위한 읽기 권한) 3가지를 선정하고 위험을 설명한다.
- 활동: 문서화 결과를 검토해 개선 권고(권한 축소·분리·모니터링 제안)를 작성한다.
- 산출물: 가상 서비스 목록(서비스별 목적·리소스 범위 포함)
- 산출물: 읽기·쓰기 권한표(서비스별 최소권한 권장값 포함)
- 산출물: 과도한 권한 3건 목록(각 항목별 위험 설명 포함)
- 완료 기준: 미확인
