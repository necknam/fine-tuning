# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 집중: 관계형 모델 설계→구현→검증(중복 ID 거절 포함)

주당 3시간, 총 2주(총 6시간) 내에 가상 지점-지역 관계의 최소 관계형 스키마를 설계하고, 샘플 데이터로 지역별 지점 수를 반환하는 SQL 질의를 작성·검증합니다. 중복 지점 ID 삽입 시 무결성 제약으로 거절되는지 테스트합니다. GIS 서버 구축은 제외합니다. 시간 제약으로 설계·구현·검증의 핵심 흐름만 수행합니다.

### 1. 요구·모델 설계

- 목표: 핵심 엔티티(지역, 지점)와 관계(지역-지점)를 정의하고 ERD와 테이블 DDL 초안을 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 요구(지역별 지점 수 조회, 중복 ID 방지)를 3개 항목으로 정리
- 활동: 간단한 ERD(지역: region_id PK, region_name; 지점: branch_id PK, region_id FK, branch_name) 작성
- 활동: 테이블 DDL 초안 작성(제약: PK, FK, UNIQUE(branch_id))
- 산출물: 요구사항 3개 항목 문서(간단 텍스트)
- 산출물: ERD 이미지 또는 텍스트 다이어그램
- 산출물: 테이블 DDL 초안(SQL 파일)
- 완료 기준: ERD와 DDL 초안이 작성되어 지역별 지점 수를 계산할 수 있는 조인 경로가 명확히 정의되어 있을 것(총 3시간 내 완료).

### 2. 구현·검증

- 목표: 샘플 데이터로 지역별 지점 수를 반환하는 SQL을 작성하고, 중복 지점 ID 삽입 시 무결성 제약으로 거절되는지 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 SQLite 또는 선택한 RDBMS에 DDL 적용 및 샘플 데이터(지역 3개, 지점 6개) 삽입
- 활동: 지역별 지점 수를 반환하는 SQL(SELECT region_id, COUNT(*) FROM branches JOIN regions ...) 작성 및 실행
- 활동: 중복 branch_id 삽입 시 UNIQUE/PK 제약으로 실패하는지 테스트(예: INSERT 중복 시도 및 에러 확인)
- 산출물: 실행 가능한 SQL 스크립트(DDL + 샘플 데이터 + 조회 쿼리)
- 산출물: 검증 결과(지역별 지점 수 출력 스크린샷 또는 쿼리 결과 텍스트)
- 산출물: 중복 삽입 시도 로그(에러 메시지 포함)
- 완료 기준: 지역별 지점 수 쿼리가 예상 결과(샘플 데이터 기준)를 반환하고, 중복 ID 삽입 시 DB가 무결성 제약으로 삽입을 거부하는 것이 재현 가능해야 함(총 3시간 내 완료).
