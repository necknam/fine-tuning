## 계획

2주 실전 소규모 실험(로컬 기준선 + 오분류 해석)

가용 시간(총 6시간)과 예산(0원)을 고려해 로컬 환경에서 작은 공개 데이터로 분류 기준선을 만들고, 학습·검증 분리와 오분류 3건 해석을 완료하는 2주(총 6시간) 계획입니다. 각 주차는 3시간씩 배정되어 있으며, 산출물은 실행 가능한 코드·검증 지표·오분류 해석 문서입니다.

### 1. 환경 준비 및 데이터 분리

- 목표: 로컬에서 재현 가능한 실행 환경을 만들고 공개 예제 데이터(작은 분류 문제)를 불러와 학습/검증 분리를 완료한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 Python 환경(예: venv)과 필요한 패키지 설치(예: scikit-learn, pandas, numpy)
- 활동: 작은 공개 예제 데이터셋(예: Iris 또는 Wine 등) 선택 및 로컬에 저장
- 활동: 데이터 전처리(결측·간단한 특성 확인)와 학습/검증 분할(예: stratified split) 수행
- 활동: 간단한 기준선 모델(예: 로지스틱 회귀 또는 결정트리) 학습 및 평가 스크립트 작성
- 산출물: 환경 설정 기록(사용한 Python 버전, 주요 패키지 버전)
- 산출물: 데이터 요약(샘플 수, 클래스 분포, 특성 목록)
- 산출물: 학습/검증 분리 코드와 분리 결과(샘플 수)
- 완료 기준: 미확인

### 2. 기준선 모델 학습·검증 및 오분류 해석

- 목표: 기준선 모델의 학습·검증을 완료하고, 오분류 사례 3건을 선정해 원인(데이터 편향·특성 결측·경계 사례 등)을 분석·기록한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기준선 모델 학습(에포크/하이퍼파라미터 기록) 및 검증 지표 수집
- 활동: 혼동행렬과 클래스별 지표 계산
- 활동: 오분류 사례 3건 선정(다양한 클래스/상황 포함) 및 각 사례에 대한 입력 특성·예측 확률·가능 원인 기술
- 활동: 간단한 개선 아이디어(예: 특성 추가, 전처리 변경, 모델 복잡도 조정) 우선순위 작성

- 산출물: 검증 결과(정확도, 혼동행렬, 클래스별 정밀도/재현율)
