# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선·짧은 주기 실습: 최소 재현 → 잠금 적용 → 비교 분석

주당 3시간, 총 2주(총 6시간) 안에 로컬에서 재현 가능한 최소 동시성 버그(스레드 2개, 공유 카운터)를 작성하고, 뮤텍스 적용 전후의 로그를 비교해 원인·효과를 문서화합니다. 비용은 들이지 않고 로컬 환경(개인 PC)과 무료 도구만 사용합니다.
