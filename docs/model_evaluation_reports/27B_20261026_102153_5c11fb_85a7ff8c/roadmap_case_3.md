# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실습 중심 RDBMS 모델링 및 검증 로드맵

주당 3시간, 총 2주(총 6시간) 안에 가상 지점-지역 관계를 관계형 DB로 모델링하고 지역별 지점 수를 반환하는 SQL 질의와 중복 ID 거절(제약조건) 검증까지 완료합니다. 시간 제약이 크므로 설계는 최소한의 정규화(ERD 1장)와 단일 테이블/관계 설계로 축소하고, 검증은 로컬 SQLite 또는 무료 DB 환경에서 샘플 데이터(지역 3개, 지점 8개)로 수행합니다. GIS 서버 구축은 제외합니다.

### 1. 요구·모델 설계 및 환경 준비

- 목표: 핵심 엔티티(지역, 지점)와 관계(지역-지점)를 정의하고, 중복 ID를 방지할 제약조건을 설계한다. 로컬 SQLite 또는 무료 RDBMS 환경을 준비한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항 정리: 지역(region)과 지점(branch) 속성 목록 작성(예: region_id, region_name; branch_id, branch_name, region_id FK).
- 활동: ERD 1장 작성(도구: draw.io 또는 손그림 스캔).
- 활동: 중복 ID 정책 결정: branch_id를 PK로 설정하거나 UNIQUE 제약 적용.
- 활동: 로컬 DB 환경 준비: SQLite 파일 생성 또는 무료 RDBMS(예: DB Browser for SQLite) 설치.
- 산출물: 요구사항 1페이지(속성 목록 포함)
- 산출물: ERD 이미지(1장)
- 산출물: 설계 메모: 중복 ID 방지 방식 명시
- 산출물: 로컬 DB 연결 확인 스크린샷
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. 구현·검증 및 결과 보고

- 목표: SQL 스키마를 구현하고 샘플 데이터를 삽입하여 지역별 지점 수를 반환하는 질의를 검증하고, 중복 ID 삽입 시 제약조건으로 거부되는지 시나리오로 증명한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: SQL 스크립트 작성: CREATE TABLE region, CREATE TABLE branch(FOREIGN KEY region_id), UNIQUE/PK 제약 포함.
- 활동: 샘플 데이터 삽입: 지역 3개, 지점 8개(지역별 분포 불균형 포함).
- 활동: 검증 질의 실행: SELECT region_id, COUNT(*) FROM branch GROUP BY region_id; 결과 스크린샷 저장.
- 활동: 중복 ID 테스트: 동일한 branch_id 삽입 시도 및 실패 로그 캡처.
- 활동: 간단한 결과 보고서(1페이지) 작성: 설계 요약, 검증 결과, 한계 및 다음 단계 제안.
- 산출물: SQL 스키마 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: 검증 질의 결과 스크린샷 및 중복 삽입 실패 로그
- 산출물: 1페이지 결과 보고서
- 완료 기준: 미확인
