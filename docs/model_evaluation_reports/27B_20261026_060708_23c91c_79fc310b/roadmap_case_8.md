# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

2주 실습 중심 RAG 검색 실패 재현 및 원인 분석

주당 2시간, 총 2주(총 4시간)를 사용해 기존 Python 환경과 가상 문서 3건만으로 RAG 검색 실패를 재현하고 원인을 기록합니다. 외부 유료 서비스나 새 강좌 구매 없이 로컬 실험으로 완료 기준(성공 2건, 실패 1건 구분)을 충족합니다.

### 1. 실험 설계 및 환경 준비

- 목표: 가상 문서 3건(정상 2건, 의도적 오류 1건)과 재현 시나리오 정의, 로컬 실행 스크립트 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건 생성(정상 문서 2건, 의도적 오류 포함 문서 1건)
- 활동: 간단한 검색 파이프라인 설계(문서 토큰화 → 임베딩(로컬 간단 유사도) → 검색 쿼리 매칭)
- 활동: 로컬 Python 스크립트(예: 단일 파일)로 실험 자동화: 입력 문서, 쿼리, 기대 결과 정의
- 활동: 완료 기준 정의: 성공(정상 문서 2건이 쿼리로 매칭됨)과 실패(오류 문서가 매칭되지 않거나 잘못된 매칭 발생) 구분 기준 명시
- 산출물: 가상 문서 3건(텍스트 파일)
- 산출물: 실험 설계 문서(쿼리·기대 결과·완료 기준 포함)
- 산출물: 로컬 실행 스크립트(README 포함)
- 완료 기준: 미확인

### 2. 실행·관찰·원인 분석

- 목표: 검색 파이프라인을 실행해 실패를 재현하고, 로그·유사도 점수·토큰화 결과로 원인을 규명하여 보고서 작성
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 스크립트 실행으로 검색 결과 수집(성공/실패 케이스 기록)
- 활동: 실패 케이스에 대해 토큰화 결과·임베딩 유사도·인덱싱 상태를 점검
- 활동: 원인 가설(예: 토큰화 누락, 임베딩 차원 불일치, 문서 메타데이터 누락)과 재현 절차 정리
- 활동: 간단한 수정(예: 토큰화 필터 추가, 문서 정규화) 적용 후 재실행으로 영향 확인
- 산출물: 실험 실행 로그(성공/실패 케이스 포함)
- 산출물: 원인 분석 보고서(가설, 근거, 재현 절차, 수정 시도 및 결과)
- 산출물: 최종 요약(성공 2건·실패 1건 구분 및 향후 개선 권고)
- 완료 기준: 미확인
