- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

2주 집중: 최소 RAG 시제품으로 근거 표시 및 실패 분류

주당 3시간, 총 2주(총 6시간) 안에 Python 기반 최소 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건에 대해 근거를 표시하고, 근거가 없는 질문은 '근거 없음'으로 분류하는 것을 목표로 합니다. 이미 보유한 Python·데이터 처리 경험은 반복 학습하지 않고 바로 시제품 구현에 활용합니다. 시간 제약 때문에 외부 유료 서비스나 복잡한 인프라는 사용하지 않고, 로컬 텍스트 인덱싱(간단한 벡터 유사도)과 경량 LLM 호출(또는 규칙 기반 응답)로 구현합니다. 결과물은 코드(스크립트), 입력 데이터(가상 규정 3건), 평가표(질문 5건과 기대 근거/정답) 및 짧은 실행 가이드입니다.

### 1. 데이터 준비 및 평가 기준 정의

- 목표: 가상 규정 3건(각 200~500자)과 질문 5건을 준비하고, 각 질문에 대해 기대 근거(문서·문장)와 '근거 없음' 여부를 정의한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건 작성(또는 선택) 및 메타데이터(문서ID, 섹션) 추가
- 활동: 질문 5건 작성: 명확한 근거가 있는 3건, 모호하거나 근거가 없는 2건 포함
- 활동: 각 질문에 대해 기대 출력(정답 요약)과 기대 근거(문서ID·문장)를 표로 정리
- 활동: 간단한 성공/실패 기준 정의: 근거가 표시되어야 하는 경우와 '근거 없음'으로 분류해야 하는 경우
- 산출물: 가상 규정 3건(텍스트 파일, 문서ID 포함)
- 산출물: 질문 5건 목록 및 기대 근거/정답 표(CSV 또는 마크다운)
- 산출물: 간단한 성공/실패 기준 문서(1페이지)
- 완료 기준: 미확인

### 2. 최소 RAG 구현 및 검증

- 목표: 로컬 텍스트 인덱싱(간단한 토큰화 + TF-IDF 또는 임베딩 유사도)과 경량 응답 생성(규칙 기반 또는 단일 LLM 호출)으로 RAG 파이프라인을 구현하고, 평가표에 따라 근거 표시와 실패 분류를 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 검색 인덱스 구현: 문서 분절(문장 단위), TF-IDF 또는 임베딩(로컬 라이브러리)으로 유사도 계산
- 활동: 응답 생성 전략 결정: (A) 규칙 기반(검색된 문장 조합 + 템플릿) 또는 (B) 단일 LLM 호출(프롬프트에 검색 문장 포함) 중 시간 내 구현 가능한 방식 선택
- 활동: 응답에 근거 표시: 각 응답에 사용된 문서ID·문장(또는 스니펫)을 포함
- 활동: 평가: 준비된 5개 질문에 대해 실행하고, 기대 근거와 실제 표시 근거를 비교하여 성공/실패를 기록
- 활동: 실패 분석: 근거 누락·잘못된 근거·근거 없음 분류의 원인 간단히 기록
- 산출물: 실행 가능한 스크립트(예: Python .py 또는 Jupyter 노트북) — 입력: 규정 텍스트, 질문; 출력: 응답 + 근거
- 산출물: 평가 결과표(질문별 기대 근거 vs 실제 근거, 성공/실패 표시)
- 산출물: 간단한 실행 가이드(README, 1페이지)
- 완료 기준: 미확인
