# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

2주 집중: 관계형 모델 설계→구현→검증(중복 ID 거절 포함)

주당 3시간, 총 2주(총 6시간) 내에 가상 지점-지역 관계의 관계형 DB 모델을 설계하고, 지역별 지점 수를 반환하는 SQL 질의와 중복 ID를 거부하는 제약(UNIQUE) 및 간단한 검증 스크립트를 구현·검증한다. GIS 서버 구축은 제외하고 로컬 SQLite 또는 제공된 테스트 RDBMS를 사용한다. 시간 제약 때문에 범위는 단일 ERD, 최소 테이블 2개(branches, regions), FK 관계, 집계 질의, 중복 삽입 실패 테스트로 한정한다.

### 1. 요구·모델 설계

- 목표: 핵심 엔티티(branches, regions)와 관계(지역-지점)를 정의하고 ERD를 작성한다. 중복 ID 정책(UNIQUE 제약)을 명시한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 요구(지역별 지점 수 조회, 중복 ID 거부)를 3문장으로 정리
- 활동: 테이블 목록과 각 컬럼(예: branch_id, region_id, name, location) 정의
- 활동: ERD(간단한 다이어그램) 작성 및 FK 관계 명시
- 활동: 중복 ID를 막기 위한 UNIQUE 제약 또는 PK 설계 결정
- 산출물: 요구 3문장(지역별 집계·중복 거절 포함)
- 산출물: ERD 이미지(PNG) 또는 텍스트 기반 ERD
- 산출물: 테이블·컬럼 명세(간단한 CSV 또는 마크다운 표)
- 완료 기준: ERD와 테이블 명세가 존재하고, 중복 ID를 방지할 UNIQUE/PK 설계가 문서화되어 있어야 함.

### 2. 구현·검증

- 목표: 로컬 테스트 DB에 스키마를 적용하고, 지역별 지점 수를 반환하는 SQL을 작성·실행한다. 중복 ID 삽입 시 실패를 자동 검증하는 테스트를 수행한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 SQLite 또는 제공된 테스트 RDBMS에 CREATE TABLE 스크립트 적용
- 활동: 샘플 데이터(지역 3개, 지점 8개 등) 삽입
- 활동: 지역별 지점 수를 반환하는 SQL(예: SELECT region_id, COUNT(*) FROM branches GROUP BY region_id) 작성 및 실행
- 활동: 중복 ID 삽입 시 실패를 검증하는 간단한 스크립트(예: INSERT 후 예외/오류 확인) 작성
- 활동: 결과 스크린샷 또는 쿼리 출력 저장
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql 또는 CSV)
- 산출물: 지역별 집계 쿼리와 실행 결과(텍스트 또는 스크린샷)
- 산출물: 중복 삽입 테스트 스크립트와 실패 로그(간단한 텍스트)
- 완료 기준: 지역별 집계 쿼리가 예상 결과(샘플 데이터 기준)를 반환하고, 중복 ID 삽입 시 DB가 삽입을 거부하는 것이 테스트 로그로 확인되어야 함.
