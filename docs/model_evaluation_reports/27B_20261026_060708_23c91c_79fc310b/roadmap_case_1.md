# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

짧은 실험 중심의 동시성 이해 로드맵 (2주, 총 6시간)

2주(총 6시간) 동안 로컬 환경에서 작은 실험을 통해 동시성 문제(경합 상태)를 재현하고, 잠금 적용 전후의 로그를 비교하여 원인과 효과를 관찰한다. 비용 우선 관점으로 유료 서비스나 외부 인프라 없이 로컬 도구만으로 완료 가능하도록 범위를 축소했다.

### 1. 재현 및 기초 확인

- 목표: 로컬에서 스레드 두 개가 공유 카운터를 동시에 증가시킬 때 발생하는 값 불일치(경합 상태)를 재현하고 로그로 확인한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발환경 준비: 컴파일러(gcc) 또는 Python3, 간단한 편집기, 터미널 확보
- 활동: 작은 연습문제 설계: 두 스레드가 N번(예: 1,000,000)씩 공유 카운터를 증가시키는 프로그램 작성
- 활동: 잠금(뮤텍스/락) 없이 실행하여 최종 카운터 값과 기대값(2N)의 차이를 로그로 수집
- 활동: 동시성 오류가 재현되는지 여러 실행(최소 5회)으로 확인하고 로그 저장
- 산출물: 동시성 오류 재현 코드(예: C 또는 Python 스레드 구현)와 실행 스크립트
- 산출물: 잠금 미적용 상태에서의 실행 로그(최소 5회 반복)와 최종 카운터 값 기록
- 산출물: 간단한 실행·검증 지침(README)
- 완료 기준: 미확인

### 2. 동기화 적용 및 비교 분석

- 목표: 뮤텍스(또는 언어별 잠금)를 적용해 동일한 실험을 반복 실행하고 잠금 적용 전후의 로그·최종값 차이를 비교·분석한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 잠금 적용: 뮤텍스(또는 언어별 동기화 primitive)를 사용해 공유 카운터 증가를 보호
- 활동: 잠금 적용 전/후를 동일 조건에서 반복 실행(각 최소 5회)하여 로그 수집
- 활동: 로그 비교: 잠금 미적용에서의 값 손실(예: 기대값 대비 감소)과 잠금 적용에서의 일관성 확인
- 활동: 결과 요약: 재현 방법, 로그 스니펫, 최종값 표, 관찰된 차이와 한계(스케줄링 영향, 타이밍 민감도) 기술
- 산출물: 잠금 적용 코드와 잠금 미적용 코드 비교용 실행 로그(각 최소 5회 반복)
- 산출물: 간단한 비교 리포트(최종값 표, 재현 방법, 관찰된 차이, 한계 및 다음 실험 제안)
- 산출물: 실행 스크립트(자동으로 잠금 전/후를 번갈아 실행하여 로그를 수집)
- 완료 기준: 미확인
