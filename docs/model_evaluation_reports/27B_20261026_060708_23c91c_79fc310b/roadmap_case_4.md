# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선·짧은 주기 실습: 다이어그램 중심의 장애 대응 이해

제한된 시간(2주)과 예산(0원)을 고려해, 실제 인프라 생성 없이 다이어그램과 장애 대응표 작성으로 단일 서버와 이중화 구조의 차이를 학습한다. 각 주당 3시간씩 총 6시간을 배정하여 설계·비교·문서화까지 완료한다.

### 1. 아키텍처 비교 및 다이어그램 작성

- 목표: 단일 서버와 이중화 구조의 차이를 시각화하고 핵심 구성 요소를 식별한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 단일 서버 아키텍처(컴퓨팅, 네트워크, 스토리지, 애플리케이션 계층)를 다이어그램으로 작성
- 활동: 이중화 아키텍처(예: 로드밸런서 + 복수 인스턴스, 복제 스토리지) 다이어그램 작성
- 활동: 각 다이어그램에 장애 발생 시 영향 범위(단일 장애점, 트래픽 분산 등)를 주석으로 표기
- 산출물: 간단한 단일 서버 아키텍처 다이어그램 (PDF 또는 이미지)
- 산출물: 이중화(예: 로드밸런서+멀티인스턴스) 아키텍처 다이어그램 (PDF 또는 이미지)
- 산출물: 각 아키텍처의 장애 모드 목록(간단 표)
- 완료 기준: 미확인

### 2. 장애 시나리오 및 대응표 작성

- 목표: 각 아키텍처에 대해 현실적인 장애 시나리오를 정의하고, 탐지·대응·복구 절차를 표로 정리한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 단일 서버와 이중화 구조에서 발생할 수 있는 대표 장애(서버 장애, 네트워크 장애, 디스크 고장, 애플리케이션 오류)를 선정
- 활동: 각 장애에 대해 탐지 방법(모니터링 지표), 초기 대응(임시 복구), 근본 원인 조사 및 복구 절차를 표로 작성
- 활동: 비용 우선 관점에서 예방·복구 비용과 운영 복잡성(예: 모니터링·자동화 필요성)을 간단히 비교
- 산출물: 장애 대응표(장애 유형, 탐지 방법, 우선순위, 권고 조치, 예상 복구 시간(목표) 포함)
- 산출물: 간단한 장애 시나리오 2건(단일 서버 vs 이중화)과 기대 동작 설명
- 산출물: 학습 회고(무엇이 비용·운영 관점에서 다른지 요약)
- 완료 기준: 미확인
