## 계획

2주 집중: 최소 RAG 시제품으로 근거 표시 및 실패 분류

주당 3시간, 총 6시간(2주) 안에 Python 기반 최소 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건에 대해 근거를 표시하고, 근거가 없는 질문은 '답변 불가'로 분류하는 것을 목표로 합니다. 시간 우선 관점에서 설계·구현·검증을 최소 단위로 압축하고, 이미 보유한 Python·데이터 처리 경험은 반복 학습하지 않습니다. 예산(20,000원)은 선택적 유료 자료 구매나 클라우드 비용에 사용 가능하나, 본 계획은 무료 강좌와 로컬 실행을 우선합니다.

### 1. 데이터 준비 및 기준 정의

- 목표: 가상 규정 3건과 질문 5건을 확정하고, 각 질문에 대해 기대되는 근거(문서·구간) 또는 '근거 없음'을 라벨링한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 200~500자)을 작성하거나 제공된 샘플을 정리한다.
- 활동: 질문 5건을 작성(근거 있음 3건, 근거 없음 2건 권장)하고 각 질문에 기대 출력(근거 문서·구간 또는 '답변 불가')을 라벨링한다.
- 활동: 간단한 평가 기준을 정의: 정답 근거를 포함하면 성공, 근거를 잘못 표시하거나 근거 없음 판정을 못 하면 실패로 분류.
- 산출물: 가상 규정 3건(텍스트 파일)
- 산출물: 질문 5건과 라벨(정답 근거 매핑)이 포함된 CSV 또는 JSON
- 산출물: 간단한 평가 기준 문서(성공/실패 정의)
- 완료 기준: 미확인

### 2. 최소 RAG 구현 및 검증

- 목표: 로컬 환경에서 임베딩 생성→벡터 검색→간단한 생성(템플릿 또는 경량 LLM 호출) 파이프라인을 구현하고, 5개 질문에 대해 근거 표시 및 실패 분류를 수행해 결과를 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 개발 환경 준비: Python, 가상환경, 필요한 라이브러리(예: FAISS 또는 단순 cosine 유사도, 임베딩 라이브러리) 설치.
- 활동: 문서 분할(간단한 문장 단위) 및 임베딩 생성 스크립트 작성.
- 활동: 검색 단계에서 상위 K(예: 2) 문서 선택 후, 선택된 문서의 원문 구간에 근거 태그를 붙여 출력하는 간단한 생성 로직 구현(템플릿 기반 또는 API 호출).
- 활동: 5개 질문을 실행해 결과(근거 포함/없음)를 수집하고, 라벨과 비교해 성공/실패를 기록.
- 활동: 실패 사례(잘못된 근거, 근거 누락, 근거 없음으로 잘못 분류)를 분류하고 원인(임베딩 품질, 분할 크기, 검색 K 값 등)을 간단히 분석.
- 산출물: 실행 가능한 스크립트(임베딩 생성, 검색, 생성/응답 포맷팅)
- 산출물: 5개 질문에 대한 실행 결과(각 질문에 대해 제시된 근거와 분류 결과)
- 산출물: 간단한 검증 리포트(성공/실패 표, 실패 원인 메모)
- 완료 기준: 미확인
