# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선의 최소 RAG 시제품(6주, 주 3시간)

주당 3시간, 총 6주(총 18시간)로 가상 규정 3건과 질문 5건을 대상으로 최소 기능 RAG 시제품을 구현합니다. 목표는 검색 성공·근거 누락·답변 불가 사례를 구분하고, 각 질문에 대해 근거(문서·절차·문장)를 표시하는 것입니다. 비용은 20,000원 이내로 유지하며, 유료 서비스는 사용하지 않습니다. Microsoft Learn의 무료 모듈을 참고 자료로 사용합니다.

### 1. 1단계 · 데이터 준비 및 평가 기준 정의

- 목표: 가상 규정 3건(각 1~2페이지 분량)과 질문 5건(검색 성공 2건, 근거 누락 2건, 답변 불가 1건)을 확정하고, 각 질문에 대해 기대 근거(문서·절차·문장)를 표로 정리
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 가상 규정 3건 작성(각 문서에 문서 ID, 절차 ID, 문장 ID 부여)
- 활동: 질문 5건 작성 및 각 질문에 대해 기대 근거(문서·절차·문장) 표 작성
- 활동: 평가 기준 정의: 검색 성공(정확한 문서·절차·문장 매칭), 근거 누락(검색은 되나 근거 미표시), 답변 불가(검색 실패 또는 근거 없음)
- 산출물: 가상 규정 3건(텍스트 파일)
- 산출물: 질문 5건 목록 및 기대 근거 매핑표(CSV)
- 산출물: 평가 기준 문서(간단한 체크리스트)
- 완료 기준: 가상 규정 3건(텍스트 파일) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · 검색·인덱싱 구현

- 목표: 문서 분할(문장/절차 단위)과 벡터 인덱싱을 구현하여 검색 후보를 생성하고, 검색 결과에 대해 근거 매핑을 수행
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 문서 분할 전략 결정(문장 단위 + 절차 단위 병행)
- 활동: 로컬 임베딩 모델(예: sentence-transformers)로 벡터 생성 및 인덱싱(FAISS 또는 in-memory)
- 활동: 검색 API(간단한 함수) 구현: 입력 질문 → 상위 N개 문서·절차·문장 반환
- 활동: 검색 결과에 대해 기대 근거와 매칭하는 스크립트 작성
- 산출물: 문서 분할 스크립트
- 산출물: 벡터 인덱스(로컬 파일)
- 산출물: 검색 함수(입력 질문 → 후보 목록) 및 매칭 스크립트
- 완료 기준: 문서 분할 스크립트 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · 응답 생성 및 근거 표시

- 목표: 검색 결과를 기반으로 답변을 생성하고, 답변에 근거(문서·절차·문장)를 표시하는 로직을 구현. 근거가 없는 경우 '근거 없음'으로 구분
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 간단한 프롬프트 템플릿 설계(검색 결과 포함)
- 활동: 로컬 LLM 또는 경량 모델(예: Hugging Face의 소형 모델)로 답변 생성(비용·시간 고려)
- 활동: 답변에 근거 태그(문서 ID·절차 ID·문장 ID)를 삽입하는 포맷 정의
- 활동: 근거가 없는 경우를 감지하여 '근거 없음'으로 표시하는 로직 구현
- 산출물: 프롬프트 템플릿
- 산출물: 응답 생성 스크립트(로컬 모델 사용)
- 산출물: 근거 표시 포맷 예시 및 샘플 출력
