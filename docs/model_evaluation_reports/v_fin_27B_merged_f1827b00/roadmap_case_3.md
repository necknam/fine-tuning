# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

업무 적용 우선: 최소 기능 RAG 시제품으로 근거 표시·검증 구현

4주(총 12시간) 동안 Python 기반 최소 RAG 시제품을 구현하여 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문을 구분하는 것을 목표로 합니다. 주당 3시간, 총 예산 20,000원(추가 비용 발생 가능)을 반영하여 실습 중심의 단계별 작업을 계획했습니다. 이미 보유한 Python·데이터 처리 경험은 반복 학습하지 않고, 검색·프롬프트·검증에 집중합니다. 각 단계는 1주(3시간)씩 배정되어 총 4주(12시간)로 완료됩니다.

### 1. 1단계 · 요구 정의 및 데이터 준비

- 목표: 학습 범위와 성공 기준을 확정하고, 3건의 가상 규정 텍스트를 검색 가능한 형태로 준비한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 목표 질문 5건(근거 있음/근거 없음 포함)을 정의하고 각 질문에 대한 기대 근거(문장·조항)를 명시
- 활동: 가상 규정 3건(각 1~2페이지 분량)을 준비하고, 문장 단위로 분할하여 메타데이터(문서 ID, 조항 번호)를 부여
- 활동: 간단한 검색 인덱스(예: SQLite FTS 또는 in-memory BM25)를 구성하여 검색 테스트를 수행
- 산출물: 요구 명세서(질문 5건, 성공/실패 판정 기준 포함)
- 산출물: 데이터 준비 스크립트(텍스트 분할·메타데이터 포함)
- 산출물: 간단한 검색 인덱스(로컬 파일 또는 SQLite)
- 완료 기준: 요구 명세서(질문 5건, 성공/실패 판정 기준 포함) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · 검색·정렬 파이프라인 구현

- 목표: 문서 검색과 후보 근거 추출을 구현하고, 검색 품질을 정량적으로 평가한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 검색 파이프라인 구현(토큰화→인덱싱→쿼리→정렬) 및 상위 k 후보 반환
- 활동: 각 질문에 대해 검색된 후보와 기대 근거를 비교하여 매칭 여부 기록
- 활동: 검색 실패(근거 누락) 사례를 수집하고 원인(토큰화·메타데이터·문장 분할)을 분석
- 산출물: 검색·정렬 파이프라인 코드(검색→정렬→상위 k 반환)
- 산출물: 검색 평가 리포트(정확도·재현율·근거 매칭 여부 표)
- 산출물: 간단한 검색 실패 사례 목록
- 완료 기준: 검색·정렬 파이프라인 코드(검색→정렬→상위 k 반환) 작성 완료 및 요구 기준 충족 검증

### 3. 3단계 · RAG 파이프라인 및 프롬프트 설계

- 목표: 검색 결과를 프롬프트에 안전하게 삽입하여 LLM이 근거를 인용하도록 하고, 근거가 없을 때 '근거 없음'을 반환하도록 한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 검색 결과를 기반으로 프롬프트 템플릿을 설계(시스템 메시지·컨텍스트 주입 규칙 포함)
- 활동: LLM 호출(로컬 또는 API)을 통해 응답 생성 및 응답에 근거(문장·조항)를 매핑
- 활동: 근거가 없는 질문에 대해 모델이 근거를 지어내지 않도록 검증 로직(예: 인용된 문장이 검색 후보에 존재하는지 확인) 구현
- 산출물: RAG 시제품 코드(검색→프롬프트→LLM 호출→응답 포맷)
- 산출물: 응답별 근거 표시(문장·조항) 및 근거 없음 판정 로직
- 산출물: 시제품 데모(5개 질문에 대한 응답과 근거 표시)
- 완료 기준: RAG 시제품 코드(검색→프롬프트→LLM 호출→응답 포맷) 작성 완료 및 요구 기준 충족 검증
- 추천 자료: 프로덕션 AI 에이전트를 위한 고급 프롬프트 전략 설계 · ID MS_d1f2eed6c592 · DB 비용 0.00원 · 이용 상태 미확인
- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/aaai-design-advanced-prompt-production-agents/?WT.mc_id=api_CatalogApi

### 4. 4단계 · 평가·검증 및 개선 계획

- 목표: 시제품을 평가하고, 검색·프롬프트·데이터 측면에서 개선 우선순위를 도출한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 정의한 5개 질문에 대해 시제품을 실행하고, 각 응답의 근거 매칭 여부를 기록
- 활동: 정량 지표(정확도·재현율·근거 누락률)와 정성 피드백(근거 표현의 명확성)을 정리
- 활동: 개선 항목(예: 메타데이터 보강, 프롬프트 강화, 검색 파라미터 조정)을 우선순위화하고 다음 단계 제안
- 산출물: 평가 리포트(정확도·재현율·근거 누락률·오답률)
- 산출물: 개선 우선순위 목록(검색·프롬프트·데이터 중 우선 개선 항목)
- 산출물: 최종 시제품 데모(5개 질문 응답과 근거 표시 포함)
- 완료 기준: 평가 리포트(정확도·재현율·근거 누락률·오답률) 작성 완료 및 요구 기준 충족 검증
