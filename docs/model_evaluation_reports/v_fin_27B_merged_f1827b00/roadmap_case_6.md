## 계획

비용 우선의 최소 기능 RAG 시제품(7주, 주 3시간)

주당 3시간, 총 7주(총 21시간) 동안 로컬 환경에서 문서 인덱싱→벡터 검색→프롬프트 기반 LLM 호출→추적 로그 수집까지의 최소 기능 RAG 시제품을 구현합니다. 예산은 10,000원(현금)으로 제한되어 있어 유료 API·유료 코스를 사용하지 않고 로컬 모델·오픈소스 도구로 구성합니다. 지원금(30,000원)은 미확정이므로 계획에 포함하지 않습니다.

### 1. 1단계 · 환경 준비 및 데이터 준비

- 목표: 로컬에서 문서 인덱싱과 벡터 검색을 실행할 수 있는 최소 환경 확보
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 로컬 개발 환경(가상환경, Python 3.9+) 준비
- 활동: 간단한 문서(예: 사내 FAQ 10개)를 준비하고 텍스트 전처리 스크립트 작성
- 활동: 로컬 임베딩 모델(예: sentence-transformers)로 벡터 생성 및 로컬 벡터 DB(FAISS 또는 ChromaDB)에 저장
- 활동: 검색 API(간단한 Python 스크립트)로 쿼리 입력 시 상위 k개 문서 반환 확인
- 산출물: 환경 구성 체크리스트(설치 명령·버전·검증 스크립트)
- 산출물: 샘플 문서 10개(텍스트)와 간단한 인덱스(로컬 벡터 DB)
- 산출물: 검색 결과 예시(쿼리 5개)와 기대 결과 비교표
- 완료 기준: 환경 구성 체크리스트(설치 명령·버전·검증 스크립트) 작성 완료 및 요구 기준 충족 검증

### 2. 2단계 · RAG 파이프라인 구현

- 목표: 검색 결과를 컨텍스트로 사용해 LLM이 근거 문장을 포함해 답변하도록 파이프라인 구현
- 기간: 3 · 시간: 9시간 · 비용: 0원
- 활동: 검색 결과를 프롬프트에 삽입하는 템플릿 설계(시스템 메시지·사용자 메시지 분리)
- 활동: 로컬 또는 API 기반 LLM(예: OpenAI 호환 API 또는 로컬 모델) 호출 코드 작성
- 활동: 응답에 원문 인용(문서 ID·문장) 포함하도록 포맷 지정
- 활동: 샘플 질의 10개에 대해 응답 수집 및 간단 평가(정확성·관련성)
- 산출물: RAG 파이프라인 코드(검색→컨텍스트 삽입→LLM 호출)
- 산출물: 샘플 질의 10개에 대한 응답 로그(원문 인용 포함)
- 산출물: 간단한 평가표(정확성·관련성·응답 길이)
- 완료 기준: RAG 파이프라인 코드(검색→컨텍스트 삽입→LLM 호출) 작성 완료 및 요구 기준 충족 검증

- 산출물: 간단한 추적 시각화(로그 기반) 또는 추적 요약 리포트

- 완료 기준: 추적 로그(요청·검색·프롬프트·응답) 샘플 작성 완료 및 요구 기준 충족 검증
