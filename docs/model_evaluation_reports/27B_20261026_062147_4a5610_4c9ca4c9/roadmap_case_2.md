# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

1주 집중: SQLite 기반 최소 재고 데이터모델 설계 및 JOIN 검증

가용 시간(총 4시간)에 맞춰 목표 범위를 최소화하여 로컬 SQLite에서 재고 품목·입출고 테이블을 설계하고, 외래키 제약과 JOIN 결과를 검증하는 산출물을 만든다. 설계·구현·검증의 핵심 단계만 수행하고 문서화한다.

### 1. 요구·스키마 설계

- 목표: 핵심 엔티티(품목, 입출고)와 최소 필드·관계 정의
- 기간: 0.25 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 목표 범위를 재고 품목(제품명, SKU, 재고수)과 입출고(입출고ID, 품목ID, 유형(입고/출고), 수량, 발생일)로 축소
- 활동: ER 다이어그램(간단한 텍스트 표기) 작성
- 활동: 외래키 제약(입출고.품목ID → 품목.ID) 명시
- 산출물: 간단한 ER 텍스트(테이블·컬럼·PK·FK 표기)
- 산출물: 설계 결정 사항(왜 이 최소 필드만 선택했는지) 1페이지
- 완료 기준: ER 텍스트와 외래키 정의가 문서화되어 있고, 각 테이블의 최소 3개 샘플 레코드 예시가 제시되어 있을 것

### 2. SQLite 구현 및 데이터 적재

- 목표: 로컬 SQLite에 테이블 생성, 외래키 활성화, 샘플 데이터 삽입
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 SQLite 파일 생성 및 연결(예: sqlite3 CLI 또는 Python sqlite3 모듈)
- 활동: CREATE TABLE 문으로 품목·입출고 테이블 생성(외래키 제약 포함)
- 활동: 샘플 데이터(각 테이블 3~5건) 삽입
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: 실행 로그(테이블 생성·삽입 성공 메시지)
- 완료 기준: DDL과 삽입 스크립트를 실행했을 때 오류 없이 테이블이 생성되고 샘플 데이터가 조회되어야 함

### 3. JOIN 검증 및 결과 문서화

- 목표: 대표 JOIN 쿼리 실행으로 관계 무결성 확인 및 결과 비교
- 기간: 0.25 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 품목과 입출고를 INNER JOIN, LEFT JOIN으로 조회하는 쿼리 작성
- 활동: 외래키 위반 시나리오(존재하지 않는 품목ID 삽입)를 테스트하여 제약 동작 확인
- 활동: 쿼리 결과 스냅샷(스크린샷 또는 CSV)과 기대 결과 비교
- 산출물: JOIN 쿼리 목록(.sql)
- 산출물: 쿼리 결과 스냅샷(예: CSV 또는 텍스트)
- 산출물: 간단한 검증 보고서(기대값 vs 실제값, 발견된 문제 및 해결안)
- 완료 기준: 작성한 JOIN 쿼리의 결과가 설계에서 기대한 관계(예: 각 입출고가 올바른 품목과 연결됨)를 만족하고, 외래키 위반 테스트에서 제약이 동작함을 확인할 것
