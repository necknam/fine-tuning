# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

1주(총 3시간) — 가상 권한표 문서화 및 과도 권한 식별

가용 시간(1주, 주 3시간)과 예산(0원)을 고려해 실제 계정·외부 API 호출 없이 문서 기반 점검만 수행합니다. 목표는 가상 서비스의 읽기·쓰기 권한표를 작성하고, 과도한 권한 3가지를 식별해 개선 권고안을 문서로 제출하는 것입니다. 시간 제약으로 인해 심층 자동화·테스트는 배제하고, 설계·검증 산출물에 집중합니다.

### 1. 범위 정의 및 가상 리소스 목록 작성

- 목표: 점검 대상(가상 서비스·리소스)과 권한 모델(읽기/쓰기/관리)을 명확히 정의
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 서비스 목록(예: 가상 스토리지, 가상 컴퓨팅, 가상 네트워크) 5개 항목 작성
- 활동: 각 리소스에 대해 필요한 최소 권한(읽기/쓰기/관리)을 정의
- 활동: 점검 범위와 제약(실제 계정·API 호출 금지) 명시
- 산출물: 가상 리소스 목록(간단한 표, 5개 항목)
- 산출물: 점검 범위 및 제약사항 1문단
- 완료 기준: 가상 리소스 5개와 각 리소스의 최소 권한 정의가 문서로 존재하면 완료

### 2. 권한표 작성 및 과도 권한 식별

- 목표: 리소스별 읽기·쓰기 권한을 표로 정리하고, 과도한 권한 3가지를 근거와 함께 식별
- 기간: 0.33 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 리소스별 읽기·쓰기 권한표(행: 리소스, 열: 읽기/쓰기/관리) 작성
- 활동: 권한 부여의 합리적 근거(업무 필요성)를 각 항목에 간단히 기술
- 활동: 과도한 권한 3가지를 선정하고 각각의 위험·영향 설명
- 산출물: 리소스별 권한표(CSV 또는 마크다운 표)
- 산출물: 과도한 권한 3건 목록(각 항목에 위험 설명 포함)
- 완료 기준: 권한표와 과도 권한 3건이 문서로 제출되면 완료

### 3. 개선 권고안 작성 및 제출

- 목표: 우선순위별 개선 권고안(간단한 정책 예시 포함)과 1페이지 요약 작성
- 기간: 0.17 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 각 과도 권한에 대해 권고 조치(권한 축소, 역할 분리, 조건부 정책 등) 제시
- 활동: 우선순위(높음/중간/낮음)를 부여하고 적용 난이도·영향 간단히 기술
- 활동: 1페이지 요약(핵심 발견·권고·다음 단계) 작성
- 산출물: 개선 권고안 문서(각 권고에 적용 예시 포함)
- 산출물: 1페이지 요약(발견·권고·다음 단계)
- 완료 기준: 개선 권고안과 1페이지 요약이 제출되면 완료
