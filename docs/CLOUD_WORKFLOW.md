## 최신 실행 범위와 다른 PC 후속 작업

P01 비교는 현행대로 유지한다. 내용 품질 gate 통과 후 P02~P06은 RunPod에서 학습·2/5에포크 가중치 저장·원격 백업 및 파일 해시 검증만 한다. 현재 PC의 GPU로 모델을 실행하지 않는다. 저장 전용 경로는 train_save_only이고 모델 답변 생성 전에 반환한다. P06 저장·외부 검증 및 필요한 GPU 작업 종료 후 STOP을 시도한다.

Cloud에서 가중치를 선택해 다른 PC 실행기가 동일10개 답변을 생성하고 결과를 Cloud에 저장하는 연결은 미구현 후속 작업으로 이관한다. 현재 PC에 설치·실행하지 않으며 이 작업을 기다려 RunPod를 유지하지 않는다. [다른 PC 보고서 생성 핸드오프](다른PC_보고서생성_핸드오프.md)를 따른다.
