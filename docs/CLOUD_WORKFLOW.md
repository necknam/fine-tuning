# Cloud 실험 작업 현황

2026-10-23 기준. 로컬 DB는 사용자가 관리하며 완료나 Cloud와 동일 상태로 간주하지 않는다.

## 데이터와 실험

- 최신 수정 후보: qwen_factory/data/production/curation_1500_reviewed_v4/release. 1,200 학습 / 150 검증 / 150 별도 평가.
- 실제 토크나이저 최대 9,230토큰. 학습 설정 10,240, 답변 생성 상한 4,096. 1,500건 모두 실제 encode_all 경로로 final_assistant_only 마스킹 검증 완료. 잘라내지 않는다.
- 비교 설정: hyperparameters.compare.baseline_v1.yaml / hyperparameters.compare.reviewed_v4.yaml. 같은 모델 리비전·학습 조건으로 각 5에포크, 저장·비교는 2·5에포크.
- 고정 보고서 10개는 직원 ID [12,14,6,8,16,7,15,17,13,12]를 재사용한다. 첫 실전 평가 시 DB 근거와 프로필을 한 묶음으로 고정해 두 데이터 버전이 같은 입력을 사용한다.
- 새 직원 100명 전체를 무작위 재선택하면 비교 조건이 달라지므로 기존 고정10개 배정은 유지한다.
- 데이터 파일은 선택한 설정의 해시와 일치해야 한다. Cloud에 파일이 없으면 학습·검증·별도 평가·고정 입력 파일 네 개를 준비 화면에서 업로드한다.

## Supabase

- growpath_hr TEST_MANUAL 100명. 5개 부서 각 20명(부서장 1명+직원 19명). 기존9명 보존, 91명 추가.
- 100명 모두 사용자 지정 공통 테스트 비밀번호를 개별 솔트 Argon2id 해시로 저장·검증했다. 평문은 문서에 기록하지 않는다.
- 사번 NOT NULL·공백 금지·기관별 UNIQUE 적용. 직무·스킬·자격·학력은 기존 구조와 FK를 사용한다.
- 실제 팀원5명의 시트 정보는 아직 적재하지 않았다. 신규 가데이터와 비밀번호 변경은 Supabase에만 반영했다.
- Cloud가 독립 관리하는 계정이 있으면 구형 로컬→Cloud 덮어쓰기 도구는 중단한다.
- 읽기 전용 실험 계정은 TEST_MANUAL 프로필100명을 조회할 수 있지만 비밀번호 해시·이메일에는 접근하지 못한다.
- 직원 생성: database/scripts/seed_cloud_test_workforce.py. 비밀번호 재설정: database/scripts/set_cloud_test_passwords.py. 기본 실행은 미리보기, 실제 변경은 --apply.

## 검증 상태와 남은 작업

공장 테스트71개 실행, 1개 건너뜀, 실패0. 데이터 형식/합계/수정 보존 검사와 마스킹 검증은 통과했지만 실제 학습 효과를 의미하지 않는다. 프로젝트 가족12개 및 독립적인 전수 의미 검수 부재의 한계를 유지한다.

Cloud 배포 화면 확인, B200 모델 로딩·메모리·학습 검증, 이전·개선 데이터의 2·5에포크 응답 비교 및 최종 평가가 남았다. RunPod가 꺼져 있는 동안 학습 또는 성능 검증 완료로 보고하지 않는다.
