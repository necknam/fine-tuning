06. 사용자가 실제로 할 일

  1. 화면 실행 — 프로젝트에서 Streamlit을 실행하고 로컬 화면을 엽니다.
  2. 연결·인증 적용 — RunPod Jupyter 연결 후 HF·Neon 인증정보를 따로 적용합니다. 재시작 후 메모리의 인증정보는 다시 적용해야 합니다.
  3. 설정 선택 — P01 기준 또는 P00 커스텀을 고르고 파라미터를 수정합니다. 평가 입력 파일은 data/eval/prompts.jsonl을 선택하고 10개인지 확인합니다.
  4. 실험 등록 — 실행 중인 작업이 있으면 다음 순서에 들어갑니다. 현황에서 현재 단계·다음 단계·시간을 확인합니다.
  5. 보고서 평가 — 생성 완료 후 보고서를 열고 입력·답변을 비교해 1~5점을 저장합니다. 이름을 달리하면 복수 평가자가 평가할 수 있습니다.
보고서 이름 예시: v1_2.5(5점 만점)
평가한 입력들의 평균을 반영합니다. 미평가 입력이 남으면 현재 평균은 임시 평균입니다. “미평가 입력만 보기”를 켜면 이미 평가한 답변은 숨겨집니다.

평가 파일은 한 줄에 입력 한 건인 JSONL입니다. 정답은 없어도 됩니다. 파일만 늘리면 예전 보고서의 답변이 추가 생성되는 것은 아니며, 선택한 파일로 작업을 등록해야 합니다.
