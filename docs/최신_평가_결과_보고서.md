   * **학습 수렴도**: `P01`(LR 1e-4, Loss 0.4492), `P03`(LR 7.5e-5, Loss 0.4746), `P02`(LR 5e-5, Loss 0.5086) 순으로 학습 손실이 낮게 수렴했으며, 세 프리셋 모두 940스텝 동안 발산이나 NaN 없이 유한 손실(`finite_loss=True`)로 완주함.
