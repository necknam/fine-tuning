# 공용 입장 비밀번호

Google OAuth와 사용자별 역할 대신 공용 비밀번호 하나를 사용합니다.
입장한 사람은 모두 실험 실행, AI 평가 요청, 보고서 조회, 사람 평가 등 같은 기능을 사용합니다.
평가자 이름은 기존 평가 화면에서 직접 입력합니다. 개별 계정을 식별하는 로그인은 아닙니다.

## 로컬

프로젝트 `.env`에서 다음 항목에 사용할 비밀번호를 직접 입력합니다.

```dotenv
DASHBOARD_PASSWORD=원하는비밀번호
```

실제 `.env`에는 항목만 추가했으며 기본 비밀번호는 지정하지 않았습니다.
설정 후 start_dashboard.ps1로 실행합니다.

## Streamlit Cloud

App settings → Secrets에 최상위 문자열로 등록합니다.

```toml
DASHBOARD_PASSWORD = "원하는비밀번호"
```

실제 값은 GitHub에 올리지 않습니다. `.streamlit/secrets.toml.example`에는 가짜 값만 있습니다.
설정 우선순위는 기존과 동일하게 Secrets → 환경변수 → .env입니다.

## 동작

- 비밀번호 미설정 시 입장을 막습니다. 인증을 생략하는 우회 설정은 없습니다.
- 인증 전에 DB 문서 복원, RunPod 연결, AI 자동 평가를 실행하지 않습니다.
- 입력한 비밀번호는 비교 후 입력 상태에서 지우고, 세션에는 검증용 HMAC만 보관합니다.
- 비밀번호 변경 후 다음 화면 실행/자동 갱신에서 재인증합니다.
- 왼쪽 나가기 버튼은 해당 세션의 인증정보와 메모리의 RunPod 연결 정보를 지웁니다.
- 나가기는 이미 실행 중인 RunPod 학습이나 독립 AI 평가 작업을 중단하지 않습니다.
- 새 브라우저 세션은 비밀번호를 다시 입력해야 합니다. 자동 로그인 쿠키는 만들지 않습니다.
- 자동 갱신 fragment도 인증을 다시 확인합니다.

검증: Streamlit AppTest로 오입력/정상 입력, 비밀번호 원문 제거, 변경 시 무효화,
나가기, 미설정 차단, 실제 대시보드 인증 전 DB 접근 차단을 확인했습니다.
검증에 실제 Neon/RunPod/OpenAI 호출은 사용하지 않았습니다.
