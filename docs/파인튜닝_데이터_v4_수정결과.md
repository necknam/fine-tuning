# 추가 리뷰 반영 v4

v3 원본을 보존하고 v4/release에 1,500건을 생성했다. 제작 당시 출처 추적용 1,200/150/150 분할 파일과 유형 비율을 보존했다. 현재 실행은 all.jsonl 1,500건 전부를 학습에 사용하고 평가에는 고정10개 입력만 사용한다.

- 시나리오 예상 총비용 계산 166건. 실제 DB 강좌비와 합성 사용자 환경 견적을 구분하며, 실제 청구금액으로 표현하지 않는다. 모든 계산 사례의 단계 비용 합계가 총비용과 일치한다.
- 승인·유효·활성 상태이며 추출 검토가 필요한 원문을 제외한 실제 DB 청크를 사용해 규정 발췌 사례 30건을 추가했다. 개인별 지원 자격 확정은 하지 않는다.
- 자료 교체 33건, 완료 단계 변경 재확인 45건 추가.
- 진행 점검 완료 11 / 부분 완료 11 / 실패 12 / 증거 부족 12 / 지연 14건. 실행 기록은 합성 자료임을 명시한다.
- 시간 배경 숫자를 현재 제약과 일치시키고 긴 설문을 축약했다. 운영 검증 코드에는 8/10/12문항 강제 규칙이 없어 문항 수 자체는 유지했다.
- 자기평가에는 합성 실행 증거의 성공·실패를 구분하고 확인 과제를 조정한다. 제약 대응은 정상·실패 입력을 포함한 구체적 축소안을 추가한다.
- 빈 후보에 대한 잘못된 ‘제공된 후보’ 문구를 수정했다.

형식·시간·수정 보존 검사 통과, 완전 중복 0, 분할 간 동일 답변 그룹 0. 독립적인 전수 의미 검수와 모델 성능 개선을 증명하는 결과는 아니다. 프로젝트 가족은 기존 12개로, 관점별 계획의 현실성과 규정 적용 판단은 추가 평가가 필요하다. 이 문서의 데이터 제작·정적 검증 시점에는 학습을 실행하지 않았다. 실제 실행 상태는 CLOUD_WORKFLOW.md와 RunPod 작업 로그를 따른다.
