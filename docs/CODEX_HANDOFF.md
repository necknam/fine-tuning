## 이후 결정된 흐름과 미구현 범위

사전점검이 유효하면 H100에서 전체1,500건을 기본모델부터 새로 학습한다. 2·3·4·5 epoch별 파라미터·가중치와 같은10개 출력(최대40개)을 비교한다. 개선이 미미하면 중단하고 최대5 epoch다. 선택 가중치를 최종 사용한다. 전체학습 후 기존150건은 독립테스트가 아니다.10개 결과는 작은 표본이므로 일반성능 보장으로 해석하지 않는다.

기존production 설정·control_pipeline은1,200/150/150·4/5 저장 흐름을 유지한다. H100 전체학습·epoch별 검토 후 진행을 위한 코드·설정 전환과 실제 속도·메모리 측정은 남아 있다. 새 실험 전환이 이미 구현됐거나 H100이 시작됐다고 보고하지 않는다.

## 의존성·검증

DB영역은 psycopg3.3.6·dotenv1.2.4·httpx0.28.1·PyYAML6.0.3만 직접 요구한다. Streamlit/OpenAI/NumPy는 제거한 앱 전용 의존성이므로 DB 설치에서 제외했다. 팩토리 로컬/GPU requirements를 분리하고 GPU 커널버전을 고정했다. RunPod pip check 통과, Windows 설치 dry-run 해결 성공. 공용 llm_env는 버전차이와 기존 gradio/HF Hub·typeddict/pydantic 충돌이 있어 별도 가상환경을 사용한다.

DB분리 후 회귀40건 통과. 전체복원 검증 통과. 실제 공통10개 출력의 유효성은 수정평가가 끝난 후 갱신한다. 현재 코드·데이터·백업은 원본 project 저장소만 push하며 V2의 push금지 훅은 유지한다.
