# 개선 v4 P02~P06 조건부 실행 계획

사용자는 실행 범위를 P06까지 확대했다. P01은 현재 실행과 기존 저장 가중치 비교를 유지한다. 기존 데이터보다 개선되거나 비슷하고 중대한 오류가 늘지 않았다는 고정10개 출력 내용 검토를 통과해야 P02 이후를 진행한다. 학습 손실만으로 통과시키거나 사용자 평가 점수를 임의 작성하지 않는다.

## 학습과 로컬 생성 분리

P02~P06은 RunPod에서 전체 1,500건을 각각 5에포크 학습하고 2·5에포크 가중치를 저장·원격 업로드·해시 검증한다. 답변 생성은 로컬 Streamlit에서 가중치를 선택하면 P01과 동일한 고정10개 입력으로 자동 진행하는 방식으로 변경한다. RunPod 저장 전용 경로(train_save_only)는 구현·배포했으며 전체 테스트98개 중97개 통과·1개 건너뜀을 확인했다. 업로드 가중치를 다시 내려받아 파일 해시를 검증하고 기존 P01 고정10 입력과 실행 정보를 HF local_evaluation/<run_id>에 보관한다. 로컬 Streamlit 추론 화면은 아직 구현·검증 중이며 전체 준비 완료로 간주하지 않는다. 새로운 DB 스냅샷은 만들지 않는다. 로컬 DB는 변경하지 않는다.

| 순서 | 프리셋 | P01에서 변경 |
| --- | --- | --- |
| 1 | P02 | 학습률 5e-5 |
| 2 | P03 | 학습률 7.5e-5 |
| 3 | P04 | 학습률 1.5e-4 |
| 4 | P05 | LoRA r16 / alpha32 |
| 5 | P06 | LoRA r64 / alpha128 |

공통: seed42, 최대길이10240, BF16 LoRA, B200 고속 FLA/Triton3.6, 저장2·5에포크. P06도 build_plans로 설정·데이터 검증을 수행한다. 현재 P01 품질 판정 전이므로 추가 GPU 작업은 제출하지 않는다. 실행 계획 파일명은 기존 제어 코드 호환을 위해 conditional-p02-p05-plan.json 및 Pod outputs/conditional_p02_p05/plan.json을 유지하지만 내용의 최종 프리셋은 P06이다.

## 시간 예산

최근 20~25초/스텝 기준 470스텝은 프리셋당 순수 학습 약2시간37분~3시간16분이다. P06은 LoRA 용량을 확대하므로 속도·메모리·저장 비용은 실제 실행 후 재측정한다. 전체 남은 RunPod 시간은 약16~20시간의 임시 예산이며 로컬 답변 생성 시간은 제외한다. 실제 대기·업로드 시간에 따라 달라진다.

## P06 저장 완료 후 Pod 정지

P05에서 정지하지 않는다. P06까지 모든 2·5에포크 가중치의 원격 업로드·해시 검증, 고정10 입력 및 로컬 실행용 자료의 외부 저장과 필요한 GPU 작업 종료를 확인한 뒤 승인 Pod kq65qxmwibvy27의 STOP만 시도한다. 로컬 답변 생성을 기다리느라 Pod를 유지하지 않는다. DELETE/Terminate/볼륨 삭제는 하지 않는다.

관리 API 사전 조회는403으로 거부된 상태다. 실제 STOP 및 관리 상태를 확인할 수 없으면 지정 이메일로 수동 정지 또는 상태 확인이 필요하다고 알린다. 연결 끊김만으로 성공을 주장하지 않는다. 로컬 RTX4060 8GB는 27B BF16 모델 전체를 GPU에 올릴 수 없으므로 로컬 메모리 배치·정밀도·속도를 별도로 검증하고 결과에 기록한다.
