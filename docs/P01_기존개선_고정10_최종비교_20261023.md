## 판정: 조건 미충족 — P02~P06 미실행

사용자 조건은 기존 데이터 대비 동등 이상이면서 중대한 오류가 늘지 않을 때만 추가 학습하는 것이다. **입력5의 명시적1주·4시간 제한을 기존2·5에포크는 지켰으나 개선2에포크는2주·8시간,개선5에포크는4주·16시간으로 초과했다.** 이 회귀 때문에 품질gate를 FAILED로 판정했다. 규정 인용과 미확인비용 처리의 일부 개선만으로 이 조건을 통과시키지 않았다. 학습손실은 판정 근거로 사용하지 않았다.

규정 ID가 실제 후보 안에 있는지와 문자열 배열 형식인지는 별도 지표다. 개선2에포크의 객체 인용3건은 실제 ID가 맞으므로 근거 날조로 세지 않았다. 인용이 없다고 해서 규정이 반드시 모든 과제에 적용된다고 주장하지도 않는다. 승인 근거가 제공됐는데 없다고 답한 진술은 별도 결함으로 검토했다. 모든40개에서 자료/규정의 후보 밖 ID는 발견되지 않았다.

## 내용 비교

기존 모델은 표본 수·쿼리 수·단계별 시간·테스트 수 등 실행 범위를 구체적으로 줄이는 데 강점이 있었다. 개선 모델은 비용 미확인을 명시하고 기대값/실제값·실패 기록을 반복하며 일부 실제 규정 ID를 인용했다. 반면 규정이 없다는 잘못된 진술, 시작 단계 설명과 기초 재배정의 불일치, 공통 문구 반복, 개선5 입력4의0시간 단계와 입력7의 중국어 혼입이 남았다. 기존에도 근거 없는 강좌4~7주차 상세,미확인 도서비 처리 누락,합성 프로필 역량을 이미 검증된 지식으로 가정한 부분이 있다. 두 데이터 모두 완성됐다고 판정하지 않는다.

기간0주 입력7은 모든 가중치가 확인 질문과 빈 일정을 반환했다. 부분수정 입력9·10은 모든 가중치에서 요청 외 보존 경로·완료 기록·총12시간0원을 유지했다.
