# 연도·월 선택 팝업 달력

원본 시트에 바인딩하는 Apps Script다. 별도 날짜입력 탭이나 웹 앱 배포는 사용하지 않는다.

## 설치

1. 편집 권한이 있는 Google 계정으로 원본 시트를 연다.
2. 확장 프로그램 → Apps Script에서 기존 코드를 확인한 뒤 이 패키지의 Code.gs와 Calendar.html을 추가한다. 기존 onOpen이 있으면 메뉴 생성 부분을 합치고 덮어쓰지 않는다.
3. appsscript.json은 기존 설정을 보존하면서 현재 문서·팝업 UI 권한과 V8을 반영한다.
4. 저장하고 시트를 새로 열면 상단에 ‘날짜 선택’ 메뉴가 나타난다.
5. 팀원입력의 날짜 셀 하나를 선택 → 날짜 선택 → 선택한 셀의 달력 열기. 최초 실행 시 Google 권한 화면에서 현재 문서와 팝업 UI 범위를 확인한다.

## 사용

입사일·현 부서 시작일·입학일·졸업일의 D~H만 지원한다. 연도와 월을 드롭다운으로 바로 고른 뒤 일자를 클릭하고 저장한다. 기본 더블클릭 달력은 Google의 기능이며, 이 맞춤 달력은 상단 메뉴로 연다. 기존 날짜는 달력을 여는 것만으로 바뀌지 않는다.

행 번호 대신 A열 항목을 다시 확인하고, 다른 직원 칸·수식 셀은 수정하지 않는다. 팝업이 열린 뒤 다른 사용자가 값을 바꾸면 저장을 거부한다. 시작·종료 날짜 역전과 잘못된 날짜를 검사한다. 외부 전송·DB 접근·설치형 트리거·공개 웹 앱은 없다. 시트의 Google 계정 편집 권한이 필요하며 익명 편집 세션에서는 설치·권한 부여가 불가능하다.

현재 상태: 로컬 검증 완료. 사용자가 Google 시트의 Apps Script 설치·실행 확인 완료를 전달했다.
