# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

시간 우선: 2주(총 6시간)로 최소 RAG 시제품 구현

주당 3시간, 총 2주(총 6시간) 안에 '가상 규정 3건'을 인덱스하고 5개 질문(근거 있음 3건, 근거 없음 2건)에 대해 근거를 표시하거나 근거 없음으로 판정하는 최소 RAG 시제품을 완성합니다. Python·데이터 처리 경험은 활용하되, LLM·RAG는 처음이므로 설계·검증 중심으로 시간을 배분합니다. 비용은 20,000원 이내로 제한하며, 유료 서비스는 사용하지 않습니다.

### 1. 데이터 준비 및 검색 파이프라인 설계

- 목표: 가상 규정 3건(문서화)을 텍스트로 정리하고, 간단한 분할·토큰화·임베딩 파이프라인을 설계한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 1~2페이지 분량)을 텍스트로 정리(총 3개 파일).
- 활동: 문서 분할 전략(문장 단위 또는 200~300 토큰) 결정 및 샘플 분할 적용.
- 활동: 임베딩 모델 선택(로컬 경량 모델 또는 API 사용 여부 결정) — 비용·시간 제약 고려.
- 활동: 간단한 검색 스크립트(예: FAISS 또는 in-memory cosine similarity)로 검색 테스트.
- 산출물: 가상 규정 텍스트 3건(.txt 또는 .md)
- 산출물: 분할된 문서 샘플(예: 10개 청크)
- 산출물: 검색 스크립트(검색 입력→상위 3개 청크 출력)
- 완료 기준: 검색 스크립트가 5개 질문 중 3개(근거 있음)에 대해 관련 청크를 상위 3개 내에 반환하면 완료.

### 2. 최소 RAG 구현 및 검증

- 목표: 검색 결과를 기반으로 간단한 응답 생성(템플릿 또는 경량 LLM 호출)을 구현하고, 5개 질문을 실행해 근거 표시·근거 없음 판정을 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과와 템플릿을 결합해 근거 문장을 포함하는 응답 생성(예: '근거: <문장>' 형식).
- 활동: 근거 없음 판정 로직(검색 점수 임계값 또는 관련성 검사) 구현.
- 활동: 5개 질문(근거 있음 3건, 근거 없음 2건)에 대해 자동화된 테스트 스크립트 실행.
- 활동: 결과를 정리해 성공/실패 사례를 표로 작성.
- 산출물: RAG 실행 스크립트(검색→응답 생성)
- 산출물: 5개 질문의 실행 결과(각 질문에 대해 근거 문장 또는 '근거 없음' 표기)
- 산출물: 간단한 결과 요약표(성공/실패/원인)
- 완료 기준: 5개 질문 중 3개에 대해 근거 문장을 표시하고, 2개에 대해 '근거 없음'으로 판정하면 완료. 결과 요약표에 각 사례의 원인(검색 실패, 임베딩 불일치 등)을 기술해야 함.
