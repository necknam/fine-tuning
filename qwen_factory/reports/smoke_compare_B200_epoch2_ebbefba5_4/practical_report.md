# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 중심의 실전 개선 로드맵 (1주, 총 4시간)

사용자 요청에 따라 기존 검색 코드의 검증(근거 누락 검출)과 회귀 시험 추가에 집중한다. 전체 기간 1주(총 4시간)로, 시작점(사전 학습)은 이미 완료된 것으로 간주하여 기초 학습을 배정하지 않는다. 목표는 검증 절차·샘플·자동화 스크립트와 회귀 테스트를 만들어 누락 사례를 탐지하고, 우선순위 높은 수정안을 제안하는 것이다.

### 1. 검증 계획 및 샘플 준비

- 목표: 검증 범위와 기준을 확정하고, 검증에 사용할 샘플 문서·쿼리·기대 근거를 준비한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검증 목표(누락 유형, 허용 오차, 우선순위)를 문서화
- 활동: 검증용 샘플 문서 10건 선정(다양한 길이·포맷 포함)
- 활동: 검증 스크립트(분할·검색·근거 매칭)를 작성하여 자동화
- 산출물: 검증 계획서(검증 항목·데이터·성공 기준 포함)
- 산출물: 검증용 샘플 문서 10건(원문·분할 결과 포함)
- 산출물: 검증 스크립트(분할·검색·근거 매칭 자동화)
- 완료 기준: 미확인

### 2. 검증 실행 및 회귀 테스트 작성

- 목표: 샘플을 대상으로 누락 검출을 수행하고, 누락 사례를 분류해 회귀 테스트를 작성한다.
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플에 대해 분할·검색을 실행하고 기대 근거와 실제 결과를 비교
- 활동: 누락 사례를 유형별로 분류(예: 분할 경계 문제, 토큰화 문제, 검색 임베딩 문제)
- 활동: 회귀 테스트 케이스를 작성하여 자동 실행 가능하게 구성
- 활동: 우선순위 높은 수정안 1~2개를 제안하고 적용 가이드 작성
- 산출물: 검증 결과 리포트(누락 사례 목록·원인 분류 포함)
- 산출물: 회귀 테스트 스위트(자동 실행 가능한 테스트 케이스)
- 산출물: 간단한 수정안(우선순위 1~2개) 및 적용 가이드
- 완료 기준: 미확인
