# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선의 2주 실전 프로토타입 로드맵

주당 3시간, 총 2주(총 6시간)와 현금 예산 10,000원 내에서 RAG(검색 증강 생성)의 핵심 흐름—문서 검색(증거 확보)과 생성형 응답 연결—을 최소 기능으로 구현하고 검증하는 실습 중심 로드맵입니다. 지원금(미확정)은 예산에서 차감하지 않았으며, 모든 활동은 무료 도구·로컬 환경 또는 유료 비용이 들지 않는 방식으로 설계했습니다. 시간 제약 때문에 목표는 '작은 검색 시제품'으로 축소했습니다.

### 1. 검색 기반 RAG 프로토타입 구축

- 목표: 문서 인덱싱과 검색 파이프라인을 최소 기능으로 구현하여 질의에 대해 후보 문장(증거)을 반환하는 시스템 확보
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 작업 범위 축소: 검증할 근거 문장 도메인(예: 사내 정책/기술 문서) 1개 선택
- 활동: 로컬 문서(또는 샘플 데이터)를 준비하고 텍스트 분절·메타데이터 태깅
- 활동: 간단한 임베딩 생성(로컬 또는 무료 API/로컬 모델 사용) 및 벡터 인덱스 구축(FAISS 등)
- 활동: 검색 API(간단한 Python 스크립트)로 top-k 검색 구현 및 기본 정렬·필터링
- 활동: 검색 결과의 정밀도·재현도 간단 측정(수동 라벨 10~20개 질의)
- 산출물: 간단한 문서 인덱스(예: 50~200개 문장/문서)와 검색 API(로컬 스크립트)
- 산출물: 검색 정확도 체크리스트(정밀도@5 등)와 간단한 테스트셋(10~20개 질의)
- 산출물: README: 재현 방법 및 비용·시간 추정
- 완료 기준: 미확인

### 2. 증거 기반 생성형 응답 연결 및 검증

- 목표: 검색된 근거를 기반으로 생성형 응답을 만들고, 응답에 근거 출처를 표시하여 검증 가능한 출력 확보
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과 상위 k개를 프롬프트로 조합하여 LLM에 질의(간단한 프롬프트 템플릿 사용)
- 활동: 응답에 출처(문서 ID/문장 위치)를 포함하도록 포맷 설계
- 활동: 간단한 평가: 근거 일치율(응답이 제시한 근거가 검색 결과와 일치하는지) 및 사용자 시나리오 5개 검증
- 활동: 비용·시간 관점의 한계와 개선 포인트 문서화
- 산출물: 증거 기반 응답 생성 스크립트(검색 결과 + LLM 호출)
- 산출물: 응답 평가표(근거 일치 여부, 신뢰도 표시)와 테스트 결과
- 산출물: 최종 요약 보고서: 구현 방법, 비용·시간, 한계 및 다음 단계 제안
- 완료 기준: 미확인
