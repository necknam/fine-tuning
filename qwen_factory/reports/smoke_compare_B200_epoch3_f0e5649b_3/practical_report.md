- 관점: 비용 우선

## 계획

2주 실습형 RAG 검색 실패 재현 및 원인 기록

주어진 2주(총 4시간) 동안 외부 유료·강좌 없이 Python 환경과 가상 문서 3건만으로 RAG 검색 실패를 재현하고, 각 실패의 원인 가설과 재현 절차를 문서화한다. 목표는 '성공 2건과 실패 1건'을 구분할 수 있는 실험 설계·실행·기록을 완료하는 것이다.

### 1. 실험 설계 및 환경 준비

- 목표: 가상 문서 3건과 재현 가능한 실험 절차(입력·출력·판정 기준)를 확정
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건(짧은 문장 3개)을 직접 작성하여 저장(예: JSON 또는 텍스트 파일)
- 활동: 간단한 검색 파이프라인(문서 임베딩→쿼리 임베딩→유사도 계산)을 Python으로 구현(외부 API 사용 금지)
- 활동: 성공/실패 판정 기준 정의: 유사도 임계값(예: cosine similarity >= 0.75) 또는 토큰 오버랩 기준을 문서화
- 활동: 실험 케이스 3개(정상 2건, 실패 1건)를 설계하고 각 케이스의 기대 결과와 실패 원인 가설을 기록
- 산출물: 가상 문서 3건(파일 또는 코드 스니펫)
- 산출물: 간단한 검색 파이프라인 코드(로컬 실행 가능한 Python 스크립트)
- 산출물: 실험 설계 문서(케이스별 입력·기대 결과·판정 기준)
- 완료 기준: 미확인

### 2. 실험 실행·분석·보고서 작성

- 목표: 설계한 실험을 실행하여 성공 2건·실패 1건을 구분하고, 실패 원인을 분류·기록하여 재현 가능한 보고서 제출
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬에서 파이프라인을 실행하여 각 케이스의 유사도·토큰 오버랩 결과 수집
- 활동: 실패 케이스에 대해 원인 가설(예: 토큰화 차이, 임베딩 모델의 문맥 이해 부족, 쿼리 불명확성)을 하나 이상 제시
- 활동: 각 실패에 대해 재현 절차(입력, 코드 실행 명령, 기대 출력)를 단계별로 기록
- 활동: 최종 보고서 작성: 실험 목적, 방법, 결과(성공/실패 표), 원인 가설, 재현 절차, 한계 및 다음 실험 제안
- 산출물: 실험 실행 로그(출력 스니펫 포함)
- 산출물: 실패 원인 분류표(케이스별 원인 가설과 근거)
- 산출물: 최종 실험 보고서(재현 절차 포함)
- 완료 기준: 미확인
