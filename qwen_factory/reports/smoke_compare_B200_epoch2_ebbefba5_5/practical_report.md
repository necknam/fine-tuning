## 계획

비용 우선: 2주(총 6시간)로 최소 기능 RAG 검색 시제품 구현

사용자 가용 시간(2주, 주 3시간)과 현금 예산(10,000원)을 우선 반영해, 외부 유료 서비스 없이 로컬/무료 도구로 '문서 검색 → 간단한 RAG 파이프라인 → 근거 문장 출력'의 최소 기능 시제품을 구현합니다. 목표는 프로덕션 배포가 아닌, 검색 정확도와 근거 제시 방식을 검증하는 실험적 시제품입니다. 지원금(30,000원)은 미확정이므로 계획에 포함하지 않습니다.

### 1. 환경 준비 및 데이터 준비

- 목표: 로컬 개발 환경 구성(가상환경, 의존성) 및 테스트용 문서 10~30개 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 Python 가상환경 생성 및 핵심 라이브러리 설치(예: python, pip, jupyter, requests, numpy 등)
- 활동: 샘플 문서(텍스트/마크다운) 10~30개 수집 및 전처리(문단 분할, 불필요 문자 제거)
- 활동: 간단한 인덱싱 방식 결정(벡터 인덱스 vs 키워드 인덱스) 및 선택 근거 기록
- 산출물: 환경 설정 스크립트(예: requirements.txt 또는 environment.yml)
- 산출물: 전처리된 샘플 문서 집합(10~30개)
- 산출물: 인덱싱 방식 선택 메모(왜 그 방식을 선택했는지 1~2문장)
- 완료 기준: 미확인

### 2. 간단한 RAG 파이프라인 구현 및 검증

- 목표: 검색(벡터 또는 키워드) → 상위 문서 선택 → LLM 호출(프롬프트로 근거 문장 추출) → 출력 검증
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 인덱스 생성(선택한 방식에 따라) 및 검색 함수 구현
- 활동: 간단한 프롬프트 템플릿 작성(근거 문장 추출 지시 포함)
- 활동: 샘플 질문 5~10개로 파이프라인 실행 및 결과(검색된 문서, 추출된 근거 문장) 기록
- 활동: 정확도·한계(검색 실패, 근거 불일치 등)를 간단히 평가
- 산출물: RAG 파이프라인 코드(검색 + 프롬프트 + 출력)
- 산출물: 샘플 질문과 그에 대한 출력 로그(최소 5개 사례)
- 산출물: 간단한 평가 노트(성공/실패 사례와 원인)
- 완료 기준: 미확인
