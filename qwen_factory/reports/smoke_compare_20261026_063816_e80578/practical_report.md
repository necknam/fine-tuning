## 계획

1주 집중 실습: SQLite 재고 모델 설계·외래키·JOIN 검증

주어진 1주(총 4시간) 안에 로컬 SQLite 환경에서 재고 품목·입출고 테이블을 설계하고, 외래키 제약과 JOIN 쿼리의 결과를 검증하는 산출물을 만든다. 시간 우선 관점에서 범위를 '작은 테이블 2개 + 샘플 데이터 + 검증 쿼리'로 축소하여 실습·검증까지 완료한다.

### 1. 설계·구현·검증

- 목표: 로컬 SQLite에서 재고 모델의 최소 기능(테이블·FK·JOIN)을 구현하고 검증 산출물을 제출한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 ER 다이어그램 작성(텍스트 또는 이미지)
- 활동: SQLite 스크립트 작성: CREATE TABLE items, CREATE TABLE transactions(외래키 포함), 샘플 INSERT
- 활동: JOIN 쿼리 작성 및 실행(품목별 합계, 최근 거래 조회 등)
- 활동: 외래키 위반 테스트(무효 FK 삽입 시도) 및 결과 기록
- 활동: 검증 리포트 작성(쿼리 결과, FK 동작 확인)
- 산출물: items_and_transactions.sql (테이블 생성·샘플 데이터 포함)
- 산출물: verification_queries.sql (JOIN 쿼리 목록)
- 산출물: er_diagram.txt 또는 er_diagram.png
- 산출물: verification_report.md (쿼리 결과와 FK 위반 로그 포함)
