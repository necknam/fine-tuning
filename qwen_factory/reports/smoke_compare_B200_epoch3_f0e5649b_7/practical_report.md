# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선의 2주 실습형 RAG 검증 로드맵

주어진 2주(총 6시간) 동안 비용 우선 관점에서 최소한의 도구와 로컬 리소스를 사용해 '검색 결과와 실제 근거 대조'를 검증하는 학습 시제품을 완성합니다. 목표는 복잡한 인프라 없이도 검색 품질과 생성 품질의 불일치를 식별하고, 간단한 추적 로그로 실패 사례를 분류하는 것입니다. 시간·예산 제약이 있으므로 범위를 작은 문서 집합(예: 10~30개 문서)과 단일 모델(로컬 또는 무료 API)로 제한합니다.

### 1. 데이터 준비 및 검색 파이프라인 구축

- 목표: 작은 문서 집합을 인덱싱하고 검색 결과를 원문 근거와 대조하는 검증 파이프라인을 구현한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 학습용 문서 집합 준비(간단한 텍스트 파일 또는 CSV, 메타데이터 포함)
- 활동: 로컬 벡터 인덱스 생성(예: FAISS, ChromaDB, 또는 간단한 TF-IDF + cosine 유사도)
- 활동: 검색 쿼리 실행 및 검색 결과와 원문(문서 ID·스니펫)을 매칭하는 검증 스크립트 작성
- 활동: 검증 메트릭(정확도, 정밀도, 재현율) 계산 및 간단한 보고서 작성
- 산출물: 간단한 문서 집합(예: 10~30개 문서)과 메타데이터 스키마
- 산출물: 검색 인덱스(로컬 벡터 DB 또는 검색 라이브러리)와 검색 API(간단한 함수/스크립트)
- 산출물: 검색 결과와 원문 근거를 비교하는 검증 스크립트(정확도·정밀도·재현율 계산)
- 완료 기준: 미확인

### 2. RAG 기반 에이전트 프로토타입 및 추적

- 목표: 검색 결과를 생성 모델에 안전하게 주입하여 근거 기반 응답을 생성하고, 실패 사례를 추적·분석한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 프롬프트에 안전하게 주입하는 템플릿 설계(출처 표기·오버레이 방지)
- 활동: 간단한 에이전트 흐름 구현(검색 → 프롬프트 구성 → 모델 호출 → 응답 포맷팅)
- 활동: 추적(로그)을 통해 프롬프트·검색 결과·모델 응답을 기록하고 실패 사례를 분류
- 활동: 성능 비교: 검색 품질(정확도)과 생성 품질(근거 일치 여부)을 비교하여 개선 포인트 도출
- 산출물: RAG 기반 질의응답 시제품(간단한 프롬프트 템플릿 포함)
- 산출물: 에이전트 동작 로그(프롬프트, 검색 결과, 모델 응답)
- 산출물: 성능 비교 보고서(검색 품질 vs 생성 품질, 실패 사례 목록)
- 완료 기준: 미확인
