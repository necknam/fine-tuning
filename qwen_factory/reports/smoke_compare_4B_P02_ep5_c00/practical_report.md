## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

6주·주당 3시간·비용 우선: 가상 규정 기반 최소 RAG 시제품

가용 시간(총 18시간)과 비용 우선 조건을 반영하여, 3건의 가상 규정 문서를 인덱싱하고 5건의 질문(2건 근거 포함, 3건 근거 없음)에 대해 검색·정리·응답을 수행하는 최소 기능 RAG 시제품을 6주(주 3시간) 안에 완성합니다. 각 단계는 실제 산출물(인덱스, 검색 로그, 응답 비교표)과 완료 기준을 포함하며, 추가 비용·승인은 확인되지 않았으므로 예산·지원금 차감은 하지 않습니다.

### 1. 1단계 · 환경·자료 준비 및 데이터 정제

- 목표: 가상 규정 3건의 텍스트를 수집·정제하고 검색용 인덱스(간단한 문서 컬렉션)를 준비한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 가상 규정 3건의 텍스트를 확보(학습용 샘플)
- 활동: 텍스트 전처리(누락 문자 제거, 줄바꿈 정리)
- 활동: 간단한 문서 인덱스(예: CSV + 검색 스크립트) 생성
- 산출물: 정제된 규정 텍스트 파일(3건)
- 산출물: 문서 인덱스 파일(검색용)
- 완료 기준: 3건의 규정 텍스트가 인덱스에 적재되어 검색 스크립트로 문서 조회가 가능한 상태

### 2. 2단계 · 검색 파이프라인 구현 및 테스트

- 목표: 문서 검색(벡터 또는 키워드)과 결과 정렬을 구현하고, 5개 질문의 검색 결과를 수집한다.
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 검색 엔진(간단한 벡터 또는 키워드) 연결
- 활동: 5개 질문(2건 근거 포함, 3건 근거 없음)에 대해 검색 실행
- 활동: 검색 로그와 관련 문서 ID를 수집
- 산출물: 검색 스크립트(실행 방법 포함)
- 산출물: 5개 질문별 검색 결과 로그
- 완료 기준: 5개 질문에 대해 검색 결과가 수집되어 각 질문의 관련 문서 ID가 기록되어 있음

### 3. 3단계 · 응답 생성·근거 표시·평가

- 목표: 검색 결과를 바탕으로 간단한 응답을 생성하고, 각 응답에 근거 문서를 표시·검증한다.
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 검색 결과 기반 응답 생성(간단한 템플릿 또는 LLM 호출)
- 활동: 각 응답에 관련 문서 ID를 표시하고 근거 유무 판정
- 활동: 검색 성공·근거 누락·답변 불가 사례를 분류
- 산출물: 5개 질문별 응답과 표시된 근거 문서 ID
- 산출물: 검색 성공/누락/답변 불가 분류표
- 완료 기준: 각 응답에 관련 문서 ID가 표시되고, 근거 없는 질문이 구분되어 분류표에 기록됨

### 4. 4단계 · 검증·문서화·한계 분석

- 목표: 검색 성공·근거 누락·답변 불가 사례를 구분하고, 시제품의 한계와 다음 단계 권고를 문서화한다.
- 기간: 1 · 시간: 3시간 · 비용: 0원
- 활동: 검색 로그와 응답을 비교하여 오류 유형 정리
- 활동: 시제품 사용법과 재현 절차 문서화
- 활동: 추가 개선(예: 더 큰 문서셋, RAG 통합) 권고
- 산출물: 검증 보고서(검색 성공/누락/답변 불가 사례 포함)

- 완료 기준: 검증 보고서와 사용법 문서가 작성되어 시제품의 한계와 다음 단계가 명시됨
