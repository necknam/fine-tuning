# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선: 최소 자원(시간·예산)으로 실패 재현→원인 분석→간단 수정 실험

2주(총 4시간) 동안 외부 유료·강좌 자원을 사용하지 않고, 이미 있는 Python 환경과 가상 문서만으로 RAG 검색 실패를 재현하고 원인을 기록하는 실습 중심 로드맵입니다. 각 단계는 1주(2시간)씩 배정되어 총 가용 시간 내에 완료되도록 설계되었습니다.

### 1. 환경 준비 및 실패 재현

- 목표: 가상 문서 3건을 준비하고, 간단한 검색 파이프라인을 구현해 실패(빈 결과)를 재현할 수 있게 한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건 작성(각 문서에 고유 토픽·키워드 포함, JSON 형식 저장)
- 활동: 간단한 검색 함수 구현(문서 텍스트와 쿼리 문자열을 비교하는 키워드 매칭 방식)
- 활동: 테스트 쿼리 3개(성공 2건, 실패 1건으로 설계)를 실행해 결과 기록
- 산출물: 가상 문서 3건(각각 다른 토픽/키워드 포함)을 저장한 JSON 파일
- 산출물: 간단한 검색 함수(예: keyword_search(documents, query)) 구현 코드
- 산출물: 검색 실행 로그(각 쿼리에 대한 반환 결과와 빈 결과 여부)
- 완료 기준: 미확인

### 2. 원인 분석 및 최소 수정 실험

- 목표: 재현된 실패의 원인을 가설화하고, 최소한의 수정으로 실패를 줄이는 실험을 수행해 결과를 기록한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 실패 사례에 대해 원인 가설 수립(예: 토큰화 미비, 대소문자·공백 차이, 동의어 미포함)
- 활동: 가설별로 간단한 수정 적용(토큰화, lowercasing, 간단한 정규화) 후 재실행
- 활동: 수정 전후 결과를 비교해 어떤 변경이 실패를 줄였는지 문서화
- 산출물: 실패 원인 분석 보고서(간단한 텍스트 파일 또는 마크다운)
- 산출물: 수정 전후 비교 로그(검색 결과 차이)
- 산출물: 간단한 개선 코드(예: 토큰화·정규화 적용)와 실행 결과
- 완료 기준: 미확인
