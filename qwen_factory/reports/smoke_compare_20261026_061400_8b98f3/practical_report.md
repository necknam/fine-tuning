# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실습형 RDBMS 데이터 모델링 로드맵

주어진 2주(총 6시간) 동안 실제 업무 적용 관점에서 관계형 DB로 가상 지점-지역 모델을 설계하고, 지역별 지점 수 집계 쿼리와 중복 ID 거절(제약) 검증을 완료한다. 시간 제약이 강하므로 설계·구현·검증에 집중하고, GIS 서버 구축은 제외한다.

### 1. 요구 분석 및 ERD 설계

- 목표: 업무 적용 관점에서 필요한 최소 엔티티·속성·관계와 제약(예: PK, FK, UNIQUE)을 정의하고 ERD를 산출한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 업무 요구(지역별 지점 수 조회, 중복 ID 방지)를 1~2문장으로 정리
- 활동: 엔티티(예: Branch, Region)와 주요 속성 목록 작성
- 활동: 관계(예: Branch.region_id → Region.id)와 정규화 수준 결정
- 활동: ERD(간단한 다이어그램) 작성 및 제약(UNIQUE, NOT NULL, FK) 명시
- 산출물: 요구 요약(1~2문장)
- 산출물: ERD 다이어그램(이미지 또는 텍스트 설명)
- 산출물: 테이블 목록 및 각 테이블의 PK/FK/UNIQUE 제약 정의
- 완료 기준: 미확인

### 2. 스키마 구현·샘플 데이터 적재 및 검증

- 목표: ERD를 실제 SQL 스키마로 구현하고, 샘플 데이터로 지역별 지점 수를 반환하는 쿼리와 중복 ID 입력 시 제약으로 거절되는지 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: ERD에 따라 CREATE TABLE 문 작성(예: Region, Branch)
- 활동: UNIQUE 제약 또는 PK로 중복 ID 거절 규칙 적용
- 활동: 샘플 데이터(지역 3개, 지점 10개 등) 적재
- 활동: 지역별 지점 수를 반환하는 SQL 쿼리 작성 및 실행(예: SELECT region_id, COUNT(*) FROM Branch GROUP BY region_id)
- 활동: 중복 ID 삽입 시도하여 제약으로 거절되는지 확인
- 산출물: DDL 스크립트(CREATE TABLE 등)
- 산출물: 샘플 데이터 적재 스크립트
- 산출물: 지역별 지점 수를 반환하는 SQL 쿼리 및 실행 결과
- 산출물: 중복 ID 삽입 시도 로그(거절 확인)
- 완료 기준: 미확인
