# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선·짧은 기간에 검증 가능한 RAG 시제품 구축

주어진 2주(총 6시간)와 예산 0원 조건에서, 기존 Python·데이터 처리 경험을 활용해 '검색 결과와 근거 문서의 일치 여부'를 검증하는 최소 기능 시제품을 구현합니다. 목표는 복잡한 인프라 없이 로컬 환경에서 재현 가능한 검증 파이프라인(문서 인덱스 + 검색 + 간단한 생성형 연결 + 검증 스크립트)을 만들고, 결과의 신뢰성(근거 일치)을 측정하는 것입니다. 시간 제약 때문에 외부 유료 서비스나 대규모 클러스터는 사용하지 않습니다.

### 1. 검색 파이프라인 및 검증 기준 수립

- 목표: 문서 인덱싱과 검색(검색 결과)을 구현하고, 검색 결과와 가상 문서(테스트 케이스)를 비교하는 자동화된 검증 스크립트를 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 테스트용 문서 20~50개(가상) 생성 및 메타데이터(문서ID, 요약) 준비
- 활동: 간단한 벡터 인덱스(로컬 라이브러리 또는 임베딩+유사도 계산) 구현
- 활동: 검색 함수 구현(쿼리 입력 → 상위 K개 문서 반환)
- 활동: 검색 결과와 기대 문서(정답 라벨)를 비교하는 검증 스크립트 작성(정확도·재현율 계산)
- 산출물: 간단한 문서 인덱스(예: JSON/CSV)와 검색 함수(유사도 기반) 구현 코드
- 산출물: 검색 결과와 가상 문서(테스트 케이스)를 비교하는 단위 테스트 스크립트
- 산출물: 간단한 README: 실행 방법과 테스트 케이스 설명
- 완료 기준: 미확인

### 2. 생성형 에이전트 연결 및 근거 대조

- 목표: 검색 결과를 컨텍스트로 주입해 생성형 응답을 얻고, 응답이 근거 문서와 일치하는지 검증하는 간단한 에이전트 시제품을 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 선택해 프롬프트에 안전하게 주입하는 템플릿 설계
- 활동: 로컬 또는 API 기반 LLM(사용 가능한 무료/로컬 옵션)으로 응답 생성 파이프라인 연결
- 활동: 응답과 근거 문서 간 일치 여부(예: 핵심 문장 포함 여부)를 검증하는 자동화 테스트 작성
- 활동: 간단한 로그/추적(요청·응답·검색 결과)을 남겨 디버깅 가능하게 구성
- 산출물: 검색 결과를 컨텍스트로 주입해 응답을 생성하는 간단한 에이전트 코드
- 산출물: 에이전트 응답과 근거 문서 간 일치 여부를 확인하는 테스트 케이스
- 산출물: 간단한 실행 가이드(로컬 실행 방법)
- 완료 기준: 미확인
