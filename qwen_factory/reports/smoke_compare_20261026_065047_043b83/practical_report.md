# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선의 2주 실습형 학습 로드맵

주당 3시간, 총 6시간(2주)을 사용해 단일 서버와 이중화(예: 활성/스탠바이, 로드밸런서 기반) 구조의 차이를 다이어그램과 장애 대응표로 정리한다. 유료 리소스 생성·배포는 하지 않으며, 학습은 문서·다이어그램·시나리오 기반 연습으로 구성한다. 비용 우선 관점에서 무료 학습 자료와 로컬 도구(텍스트 편집기, 다이어그램 도구)만 사용한다.

### 1. 기초 정리 및 아키텍처 다이어그램 작성

- 목표: 단일 서버와 이중화 구조의 핵심 차이(장애 발생 시 영향 범위, 복구 절차, RTO/RPO 차이)를 다이어그램으로 정리한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 핵심 개념(단일 장애점, 활성/스탠바이, 로드밸런서, 데이터 동기화)을 1페이지 요약으로 정리
- 활동: 단일 서버 아키텍처 다이어그램 1개 작성(컴포넌트·데이터 흐름 포함)
- 활동: 이중화 아키텍처 다이어그램 1개 작성(예: 활성/스탠바이 또는 로드밸런서 기반)
- 활동: 각 다이어그램에 장애 발생 시 영향 범위와 복구 절차 주석 추가
- 산출물: 핵심 개념 요약(1페이지)
- 산출물: 단일 서버 아키텍처 다이어그램(이미지 또는 텍스트 설명)
- 산출물: 이중화 아키텍처 다이어그램(이미지 또는 텍스트 설명)
- 산출물: 각 다이어그램에 대한 장애 영향·복구 절차 주석
- 완료 기준: 두 다이어그램과 핵심 개념 요약이 제출되고, 각 다이어그램에 장애 영향·복구 절차 주석이 포함되어 있으면 완료로 본다.
- 추천 자료 MS_5f3eec6bc5b7: 제공 근거에서 확인되지 않음

### 2. 장애 시나리오 설계 및 대응표 작성

- 목표: 대표 장애 시나리오(서버 장애, 네트워크 단절, 스토리지 장애 등)에 대해 이중화 구조에서의 탐지·격리·복구 절차를 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 대표 장애 시나리오 3개 선정(예: 단일 서버 장애, 네트워크 링크 장애, 스토리지 장애)
- 활동: 각 시나리오에 대해 탐지 방법(모니터링 지표), 초기 대응(격리/재시도), 복구 절차(스탠바이 전환, 데이터 동기화 확인)를 단계별로 작성
- 활동: 각 절차에 예상 소요 시간(예상 RTO)과 담당자 역할(가상)을 표로 정리
- 활동: 간단한 연습 문제(시나리오별 체크리스트)를 만들어 스스로 점검
- 산출물: 장애 시나리오 목록(3개)
- 산출물: 각 시나리오별 대응표(탐지·격리·복구 절차, 예상 RTO, 담당 역할)
- 산출물: 간단한 연습 문제(체크리스트)
- 완료 기준: 3개 시나리오에 대한 대응표와 연습 체크리스트가 제출되고, 각 절차에 예상 RTO와 담당 역할이 명시되어 있으면 완료로 본다.
- 추천 자료 KMOOC_18100: 제공 근거에서 확인되지 않음
