- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 실무 우선 RAG 시제품 — 가상 규정 기반 근거 표시·검증

주당 3시간, 총 2주(총 6시간) 안에 가상 규정 3건과 질문 5건을 사용해 검색·인덱싱·응답 흐름을 구현하고 근거 표시·누락·미응답을 판정하는 최소 시제품을 만든다. 단계 작업은 실제 환경 확인 전 로컬 파일 기반 검색과 간단한 LLM 래퍼로 진행한다. 예산은 소규모 유료 자료 구매나 유료 툴试用에 사용 가능하나, 비용 미확정 항목은 무료·소요시간으로 단정하지 않는다.

### 1. 사전점검·환경·데이터 준비

- 목표: 가상 규정 3건과 질문 5건의 범위 확정 및 로컬 인덱스 준비
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서별 1~3페이지)과 질문 5건 작성
- 활동: 로컬 파일 기반 검색(예: FAISS 또는 간단한 임베딩+유사도 검색) 환경 구성
- 활동: 문서 전처리(토큰화·인덱싱) 및 질문-문서 매핑 초안 작성
- 산출물: 가상 규정 3건 파일(텍스트)
- 산출물: 작성된 질문 5건 목록
- 산출물: 로컬 인덱스(인덱스 파일 또는 메모)와 문서-질문 매핑표
- 완료 기준: 미확인

### 2. 검색·응답 연결 및 검증

- 목표: 검색 결과를 LLM에 전달해 답변 생성하고, 근거 표시·누락·미응답을 판정하는 테스트 실행
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 프롬프트로 조합해 LLM(로컬 또는 무료 API)에 입력하는 간단한 래퍼 구현
- 활동: 5개 질문에 대해 검색 근거를 명시하도록 응답 형식(예: [근거문서ID])을 지정
- 활동: 검색 실패·중복·정렬 오류 및 근거 누락 사례를 만들고 판정 기준에 따라 기록
- 산출물: 검색→LLM 전달 스크립트(코드)
- 산출물: 5개 질문의 응답 로그(각 응답에 근거 표시 포함)
- 산출물: 검증표: 검색 성공/누락/미응답/정확도 판정
- 완료 기준: 미확인
