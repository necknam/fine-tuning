## 계획

2주·총 6시간으로 완성하는 분류 기준선 실험

가용 시간 6시간과 예산 0원을 고려해 데이터 이해→작은 모델 실험→오분류 해석의 순서로 진행합니다. 로컬 Python 환경과 공개 예제 데이터만 사용하며 목표는 완전한 제품화가 아닌 재현 가능한 기준선과 한계 분석을 얻는 것입니다.

### 1. 데이터 확인 및 기준선 설계

- 목표: 데이터의 클래스 분포와 결측·이상치를 확인하고, 평가 지표(정확도·정밀도·재현율 중 우선순위)를 정한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 Python(venv) 환경 준비: Python 3.8+, pandas, scikit-learn 설치(총 설치·검증 20분)
- 활동: 공개 예제 CSV(예: iris 또는 wine)를 선택해 10~200행 규모로 제한
- 활동: 간단 EDA: 클래스별 샘플 수, 결측값, 특징 분포 요약(주피터 노트북에 기록)
- 활동: 학습/검증 분리 전략 결정(랜덤 70/30 또는 Stratified split) 및 평가 지표 확정
- 산출물: 환경 설치·실행 확인 스크린샷 또는 터미널 로그(20분 내)
- 산출물: EDA 노트북(데이터 샘플, 클래스 분포, 결측값 표)
- 산출물: 기준선 설계 문서(사용 지표·분리 방법·데이터 크기 제한)
- 완료 기준: 로컬에서 데이터 로드와 EDA가 재현 가능하고, 학습/검증 분리 및 평가 지표가 문서화되어 있어야 함.
- 추천 자료 MS_2065fa1a7d7c: 제공 근거에서 확인되지 않음

### 2. 작은 모델 학습·검증·오분류 분석

- 목표: 간단한 모델을 학습·검증해 기준선 성능을 얻고, 오분류 3건을 선정해 원인 가설을 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 모델 선택: 로지스틱 회귀 또는 작은 MLP(1~2 은닉층) 중 하나를 선택
- 활동: 학습 스크립트/노트북 작성(전처리·학습·검증 포함) 및 1회 실행(학습 시간 30~60분 내로 제한)
- 활동: 검증 결과에서 오분류 샘플 3건 추출(예: 혼동된 클래스 쌍에서 선택)
- 활동: 각 오분류에 대해 가능한 원인(라벨 노이즈·특성 부족·경계 근접성)과 다음 실험(특성 추가·모델 복잡도 조정·데이터 증강)을 기술
- 산출물: 학습·검증 노트북 또는 스크립트(재현 가능한 명령 포함)
- 산출물: 검증 결과 요약(정확도·혼동행렬·주요 지표)
- 산출물: 오분류 3건 분석 문서(각 건에 대한 관찰·가설·다음 실험 제안)
- 완료 기준: 로컬에서 동일한 노트북/스크립트로 기준선 학습·검증을 재현할 수 있고, 오분류 3건에 대한 분석이 문서화되어 있어야 함.
