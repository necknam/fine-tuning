# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

비용 우선·단기 실습 중심 RAG 시제품 로드맵

주어진 제약(총 2주, 주 3시간, 예산 0원)을 반영하여 외부 제공 강좌의 실제 ID만 사용하고, 가상 문서 검색 결과와 실제 근거를 대조하는 소규모 시제품을 만드는 데 집중합니다. 단계별 활동과 산출물은 사용자가 직접 실행·검증할 수 있도록 구체화했으며, 추가 비용·장비·승인이 필요한 항목은 명시했습니다.

### 1. 환경 준비 및 데이터 준비

- 목표: 가상 문서 5개와 검색 쿼리 5개를 준비하고 로컬 검색 인덱스 생성
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 5개(각 1~2페이지 분량) 작성
- 활동: 검색 쿼리 5개(검색 목표와 기대 답변 명시) 작성
- 활동: 로컬 검색 인덱스(예: FAISS 또는 간단한 inverted index) 생성
- 산출물: 가상 문서 5개(파일)
- 산출물: 검색 쿼리 5개 목록
- 산출물: 로컬 검색 인덱스 파일
- 완료 기준: 5개 문서가 로컬 인덱스에 인덱싱되고, 각 쿼리에 대해 인덱스가 반환하는 상위 3개 결과를 확인할 수 있을 때 완료

### 2. 검색·생성 파이프라인 구현

- 목표: 검색 결과를 생성 모델에 주입하고 간단한 RAG 응답을 생성
- 기간: 1.0 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 생성 모델 프롬프트에 주입하는 스크립트 작성
- 활동: 동적 컨텍스트 주입(검색 결과 삽입) 로직 구현
- 활동: 간단한 오류 처리(검색 실패 시 기본 응답) 구현
- 산출물: 검색→프롬프트 주입 스크립트
- 산출물: 샘플 입력/출력 로그(5건)
- 완료 기준: 5개 쿼리에 대해 검색 결과를 생성 모델에 주입하고 응답을 생성할 수 있을 때 완료

### 3. 평가·비교·문서화

- 목표: 검색 정밀도·응답 근거 일치도 평가 및 결과 문서화
- 기간: 0.5 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과 정밀도(정확히 관련 문서 비율) 측정
- 활동: 응답에 근거가 있는지(검색 문서와 일치하는지) 수동 점검
- 활동: 결과 요약 및 개선 포인트 문서화
- 산출물: 평가 리포트(정밀도·응답 근거 일치도 표)
- 산출물: 개선 권고 3개
- 완료 기준: 평가 리포트와 개선 권고가 작성되고, 각 쿼리에 대해 검색 결과와 응답 근거를 대조한 표가 존재할 때 완료
