# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선: 로컬 재현 중심의 실패 재현·원인 기록 실습

사용자 제공 조건(기간 2주, 주 2시간, 예산 0원)을 반영하여 외부 유료 서비스나 추가 자료 없이 로컬 Python 환경에서 가상 문서 3건으로 검색 실패를 재현하고 원인을 기록하는 실습 중심 로드맵입니다. 각 단계는 재현 가능한 스크립트와 로그를 산출물로 요구하며, 성공 2건과 실패 1건을 구분하는 기준을 명확히 합니다.

### 1. 재현 환경 구성 및 실패 재현

- 목표: 가상 문서 3건으로 검색 실패를 재현하고, 성공 2건과 실패 1건을 구분할 수 있는 재현 스크립트와 로그를 확보한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 문서 3건(짧은 텍스트)을 로컬 파일로 준비
- 활동: 간단한 검색 파이프라인 구현(예: 토큰화·문장 단위 매칭 또는 임베딩 유사도 계산)
- 활동: 검색 결과 기반의 간단한 응답 생성(문장 추출 또는 템플릿 조합) 구현
- 활동: 성공 2건과 실패 1건을 구분하는 기준 정의(예: 검색 결과에 관련 문장이 포함되는지 여부) 및 재현 테스트 실행
- 산출물: 실행 가능한 재현 스크립트(검색·응답 생성 포함)
- 산출물: 성공 2건과 실패 1건의 재현 로그(입력 쿼리, 검색 결과, 생성 응답, 실패 원인 메모)
- 완료 기준: 미확인

### 2. 원인 분석 및 수정 전후 비교

- 목표: 재현된 실패의 원인을 구체적으로 기록하고, 수정 전후의 동작 차이를 비교할 수 있는 로그를 확보한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 실패 케이스의 입력·검색 결과·응답을 캡처하여 원인 가설 작성(예: 토큰화 불일치, 문서 분할 문제, 유사도 임계값 부적절)
- 활동: 가설별 간단한 수정(예: 토큰화 방식 변경, 임베딩 임계값 조정, 문서 분할 크기 변경)을 적용하여 재실행
- 활동: 수정 전후의 검색 결과와 응답을 비교하여 개선 여부와 한계 기록
- 산출물: 원인 분석 보고서(실패 원인 목록과 재현 조건)
- 산출물: 수정 전후 비교 로그(수정 적용 시 기대되는 개선 포인트 포함)
- 완료 기준: 미확인
