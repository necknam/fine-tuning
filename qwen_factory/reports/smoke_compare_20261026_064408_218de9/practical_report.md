# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

1주 집중: SQLite 기반 최소 데이터모델 설계→쿼리 검증

가용 시간(총 4시간)에 맞춰 목표 범위를 최소화하여 로컬 SQLite에서 재고 품목과 입출고 로그를 표현하는 최소 테이블(품목, 입출고)을 설계하고, 외래키 제약과 JOIN을 통해 입출고 합계를 검증하는 SQL 스크립트와 간단한 검증 결과를 산출한다. 시간 제약 때문에 클라우드·유료 서비스·대규모 성능 튜닝은 포함하지 않는다.

### 1. 설계·구현·검증 (단일 주)

- 목표: 최소 테이블 설계(필드·PK·FK), SQLite 스크립트 작성, 샘플 데이터 삽입, JOIN 쿼리로 재고 합계 검증
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 요구사항 축소: 품목(items)과 입출고(stock_movements) 두 테이블만 정의(필드 최소화).
- 활동: ER 다이어그램(간단한 텍스트 표기) 작성: items(id PK, name, unit), stock_movements(id PK, item_id FK->items.id, movement_type[IN\|OUT], quantity, occurred_at).
- 활동: SQLite용 DDL 스크립트 작성(create table, foreign key 제약 포함) 및 샘플 데이터(각 품목당 최소 2건의 입출고) 삽입 스크립트 작성.
- 활동: JOIN 쿼리 작성: items LEFT JOIN stock_movements로 품목별 현재 재고(입-출) 계산 쿼리 작성 및 실행.
- 활동: 검증: 쿼리 결과를 수동 계산(간단한 표)과 비교하여 일치 여부 확인. 외래키 위반 시 동작(제약 적용 여부) 간단히 확인.
- 산출물: 간단한 ER 텍스트(또는 ASCII 다이어그램) 파일
- 산출물: SQLite DDL 스크립트(.sql) — create table 및 foreign key 포함
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 산출물: 검증용 JOIN 쿼리 및 실행 결과(쿼리 출력 스냅샷 또는 CSV)
- 산출물: 검증 설명서(간단한 텍스트): 기대값과 실제값 비교, 발견된 한계(예: 동시성·성능 미검증)
- 완료 기준: 제출된 SQLite 스크립트를 실행했을 때(로컬 sqlite3 환경) 테이블이 생성되고, 제공한 JOIN 쿼리의 결과가 검증 설명서에 적힌 기대값과 일치하면 완료로 간주. 모든 산출물은 총 작업시간 4시간 내에 작성·검증되어야 함.
