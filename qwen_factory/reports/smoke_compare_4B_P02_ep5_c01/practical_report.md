# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

8주 시간 우선 RAG 시제품: 가상 규정 기반 근거 표시·거부 흐름 구현

주당 3시간, 총 8주(총 24시간)를 사용해 가상 규정 3건(검토 필요 상태)을 검색 인덱스로 만들고, 질문 5건에 대해 검색 결과와 답변 근거를 표시하는 최소 RAG 시제품을 구현합니다. 각 단계는 실제 구현·검증 산출물을 만들고, 검색 성공·근거 누락·답변 불가 사례를 구분하는 기준을 문서화합니다. 예산은 20,000원 이내로 제한하며 추가 유료 자료·서비스는 확인되지 않았으므로 임의로 도입하지 않습니다.

### 1. 1단계 · 진단·설계

- 목표: 가상 규정 3건의 구조와 질문 5건의 기대 답변·검증 기준 정의
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 가상 규정 3건의 메타데이터(문서 ID, 섹션, 관련 키워드) 표 작성
- 활동: 질문 5건과 기대 답변·검증 체크리스트 작성
- 활동: 검색 인덱스 스키마(필드·매핑 규칙) 설계
- 산출물: 가상 규정 3건의 메타데이터(문서 ID, 섹션, 관련 키워드) 표
- 산출물: 질문 5건과 기대 답변·검증 체크리스트
- 완료 기준: 각 가상 규정 문서에 대해 검색할 수 있는 메타데이터 필드가 정의되고, 5개 질문의 기대 답변과 검증 체크리스트가 작성되어 있어야 함

### 2. 2단계 · 검색 인덱스·간단 RAG 구현

- 목표: 가상 규정 3건을 인덱싱하고, 질문 5건에 대해 검색 결과를 반환하는 최소 파이프라인 구현
- 기간: 3 · 시간: 9시간 · 비용: 0원
- 활동: 문서 인덱싱 스크립트 작성(문서 ID·키워드 매핑)
- 활동: 검색 쿼리 예시와 인덱스 조회 로직 구현
- 활동: 간단한 RAG 파이프라인 코드(검색→문맥 추출→응답 생성)와 실행 스크립트 작성
- 산출물: 검색 인덱스(문서 ID·키워드 매핑)와 검색 쿼리 예시
- 산출물: 간단한 RAG 파이프라인 코드(검색→문맥 추출→응답 생성)와 실행 스크립트
- 완료 기준: 5개 질문 중 최소 3건에 대해 검색 결과와 관련 문맥을 반환하고, 검색 실패·부분 매칭·답변 불가 사례를 구분하는 로그를 생성해야 함
- 추천 자료: 추적을 사용하여 생성형 AI 앱 분석 및 디버그 · ID MS_41fd82f2348f · DB 비용 0.00원 · 이용 상태 미확인

### 3. 3단계 · 프롬프트·응답 검증 및 문서화

- 목표: 프롬프트와 모델 응답을 통해 검색 결과를 보존하고, 근거 없는 답변을 식별하는 기준을 적용
- 기간: 2 · 시간: 6시간 · 비용: 0원
- 활동: 프롬프트 템플릿(검색 결과 주입 포함)과 테스트 케이스 5건 작성
- 활동: 프롬프트 변형으로 검색 결과 보존 여부 검증
- 활동: 검증 보고서(검색 성공/부분/실패, 근거 표시 여부, 답변 불가 판정 근거) 작성
- 산출물: 프롬프트 템플릿(검색 결과 주입 포함)과 테스트 케이스 5건
- 산출물: 검증 보고서(검색 성공/부분/실패, 근거 표시 여부, 답변 불가 판정 근거)
- 완료 기준: 5개 질문에 대해 프롬프트 적용 전후의 응답 차이를 기록하고, 검색 결과와 최종 응답의 연결(또는 연결 불가)을 문서화해야 함
