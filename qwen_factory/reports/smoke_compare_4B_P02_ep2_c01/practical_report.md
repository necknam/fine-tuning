# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 시간 우선
- 기간: 8주 · 주당 3시간 · 예산 20000원

## 계획

시간 우선: 8주 내 최소 RAG 시제품(가상 규정 기반 근거 표시)

주당 3시간, 총 8주(총 24시간)를 사용해 가상 규정 3건(검색 문서)과 질문 5건을 대상으로 RAG 기반 근거 표시 시제품을 구현합니다. 각 단계는 검색·정제·응답·검증 순으로 진행하며, 각 단계의 산출물과 완료 기준을 명확히 합니다. 예산(20,000원)은 필요 시 유료 자료 구매에 사용 가능하나, 현재 추천 자료는 무료입니다. 규정·지원금 승인 여부는 확인 필요하며 미확정 지원금은 예산에서 차감하지 않습니다.

### 1. 요구·데이터 준비

- 목표: 가상 규정 3건과 질문 5건의 목록 확정 및 검색용 텍스트 준비
- 기간: 2 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(문서 텍스트) 작성 또는 확보
- 활동: 질문 5건 작성(간단한 근거 표시 기준 포함)
- 활동: 검색용 텍스트(문서)와 질문 매핑표 작성
- 산출물: 문서 3건(텍스트 파일 또는 JSON)
- 산출물: 질문 5건 목록(매핑표 포함)
- 산출물: 검색 매핑표(문서 ID ↔ 질문 ID)
- 완료 기준: 문서 3건과 질문 5건이 매핑표로 정리되어 검색 파이프라인에 입력 가능해야 함

### 2. 검색·정제 파이프라인 구현

- 목표: 문서 검색(간단한 키워드/벡터 유사도)과 관련 문서 정제(중복·불완전 제거)
- 기간: 3 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 검색 엔진(키워드 또는 임베딩 기반 유사도) 구현
- 활동: 검색 결과에 대한 정제 규칙(중복 제거, 불완전 문서 제거) 적용
- 활동: 검색 결과 로그와 정제 전후 비교
- 산출물: 검색 파이프라인 코드(간단한 구현)
- 산출물: 정제 전후 문서 목록 및 로그
- 산출물: 검색 결과 샘플(정제 전/후)
- 완료 기준: 검색 파이프라인이 문서 3건에 대해 검색 결과를 반환하고 정제 규칙이 적용되어 정제된 문서 목록이 생성되어야 함

### 3. 응답 생성 및 근거 표시

- 목표: LLM 기반 응답 생성과 검색 결과에 근거를 표시하는 템플릿 구현
- 기간: 2 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 LLM(로컬 또는 API) 호출로 답변 생성
- 활동: 검색 결과와 답변을 연결하는 근거 표시 템플릿 구현
- 활동: 답변에 근거가 없는 경우를 식별하는 규칙 추가
- 산출물: 응답 생성 코드(검색 결과 포함)
- 산출물: 근거 표시 템플릿 예시
- 산출물: 샘플 답변(검색 성공/누락/불가)
- 완료 기준: 5개 질문에 대해 LLM이 응답을 생성하고, 검색 결과와 근거 표시 템플릿이 적용되어 근거 유무가 표시되어야 함
- 추천 자료: Microsoft Foundry를 사용하여 생성 AI 모델 성능 최적화 · ID MS_df219eb945ff · DB 비용 0.00원 · 이용 상태 미확인
- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi

### 4. 검증·보고

- 목표: 검색 성공·근거 누락·답변 불가 사례를 구분하고 개선 포인트 도출
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 성공/누락/불가 사례 분류
- 활동: 간단한 성능 지표(검색 관련성, 근거 표시 정확도) 측정
- 활동: 개선 포인트와 다음 단계 제안 작성
- 산출물: 검증 보고서(사례별 분류 및 개선 제안)
- 산출물: 간단한 성능 지표 요약
- 완료 기준: 검증 보고서가 작성되어 검색 성공·근거 누락·답변 불가 사례가 구분되고 개선 포인트가 도출되어야 함
