# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 집중 실습: 관계형 모델 설계→쿼리 검증→중복제어 테스트

주당 3시간, 총 2주(총 6시간) 내에 관계형 데이터 모델링의 핵심(ER 설계, 정규화, 제약조건)을 적용해 가상 지점-지역 모델을 구현하고, 지역별 지점 수 집계 쿼리와 중복 ID 삽입 거절 시나리오를 검증한다. GIS 서버 구축은 제외하고, 로컬 RDBMS(예: SQLite 또는 PostgreSQL)와 간단한 스크립트로 실습한다. 시간 제약으로 인해 설계·구현·검증의 최소 범위에 집중한다.

### 1. 요구·ER 설계 및 스키마 작성

- 목표: 핵심 엔티티(지역, 지점)와 관계(지역-지점 다대일)를 정의하고, 정규화(최소 3NF)와 제약(UNIQUE, NOT NULL, FK)을 포함한 DDL을 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항(필수 속성, 관계, 제약)을 1페이지로 정리
- 활동: ER 다이어그램(간단한 도식) 작성
- 활동: DDL(테이블 생성, 인덱스, 제약) 작성 및 로컬 DB에 적용
- 활동: 간단한 데이터 샘플(지역 3개, 지점 10개) 생성 스크립트 작성
- 산출물: 요구사항 1페이지(텍스트)
- 산출물: ER 다이어그램 이미지 또는 텍스트 설명
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 삽입 스크립트(.sql)
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

### 2. 샘플 데이터 로드·쿼리·중복제어 검증

- 목표: 샘플 데이터로 지역별 지점 수 집계 쿼리를 실행하고, 중복 ID 삽입 시 제약으로 실패하는지 확인해 검증 보고서를 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 샘플 데이터 로드 및 기본 조회(지역별 지점 수) 쿼리 실행
- 활동: 중복 ID 삽입 시나리오(예: 동일 지점 ID 재삽입)를 스크립트로 준비하고 실행
- 활동: 쿼리 결과와 제약 위반 로그를 캡처하여 검증 보고서 작성
- 활동: 간단한 성능/정확도 체크(예: 집계 결과 수동 확인)
- 산출물: 집계 쿼리 결과 스냅샷(지역별 지점 수)
- 산출물: 중복 삽입 시도 스크립트 및 실패 로그
- 산출물: 검증 보고서(요약 1페이지)
- 완료 기준: 미확인
