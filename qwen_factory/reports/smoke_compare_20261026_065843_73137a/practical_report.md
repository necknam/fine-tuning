- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 Python 환경(venv)과 필요한 패키지 설치: Python, numpy, pandas, matplotlib, TensorFlow 또는 PyTorch(선택).
- 활동: 작업용 노트북 파일(.ipynb) 생성: 데이터 로드(또는 합성 데이터 생성), 전처리, 모델 정의(입력 차원 명시), 학습 루프, 에포크별 손실 기록.
- 활동: 작은 합성 데이터(예: 2차원 입력, 2클래스 분류) 또는 공개 소규모 데이터셋 사용(다운로드 필요 시 로컬로 저장).
- 활동: 기준선 모델 학습(예: 1~2 은닉층, 각 층 16~32 유닛) 후 에포크별 손실과 최종 손실을 CSV로 저장.
- 산출물: Jupyter 노트북(.ipynb) — 데이터 생성/로드, 모델 정의, 학습 코드 포함
