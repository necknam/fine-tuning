# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 기존 검색 코드에 근거 누락 검출과 회귀 시험 추가
- 관점: 업무 적용 우선
- 기간: 5주 · 주당 4시간 · 예산 0원

## 계획

검증 우선 실무 적용 로드맵 (1주, 총 4시간)

1주(총 4시간) 동안 기존 검색 코드의 검증(근거 누락 검출)과 회귀 시험 추가에 집중한다. 시작점은 3으로 고정되어 있어 기초 재학습은 배정하지 않고, 즉시 실무 적용 가능한 검증·테스트 산출물을 만든다. 예산은 0원으로 가정하여 무료 도구와 기존 코드·데이터만 사용한다.

### 1. 검증·회귀 추가

- 목표: 기존 검색 코드의 근거 누락을 자동으로 검출하고, 회귀 시험을 추가해 변경 시 성능 저하를 방지할 수 있게 한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기존 검색 파이프라인의 입력·출력 형식과 현재 테스트 케이스 수집(1일 중 1시간)
- 활동: 누락 기준 정의: 문서-응답 매핑 기준과 허용 누락 임계값 결정(1시간)
- 활동: 검증 스크립트 작성: 문서 분할 결과와 검색 결과 비교로 누락 사례 추출(1시간)
- 활동: 회귀 테스트 작성: 핵심 시나리오 3개(정상, 경계, 오류) 자동화(1시간)
- 산출물: 검증용 샘플 데이터셋(문서 원본 + 기대 근거 매핑)
- 산출물: 검증 스크립트(정확도/재현율/누락률 계산)
- 산출물: 회귀 테스트 스위트(자동 실행 가능한 테스트 케이스)
- 산출물: 검증 결과 리포트(기초 성능 지표와 누락 사례 목록)
- 완료 기준: 미확인
