## 계획

2주 실습형 RDBMS 모델링 및 검증 로드맵

주당 3시간, 총 2주(총 6시간) 내에 관계형 DB로 가상 지점-지역 모델을 설계하고, 지역별 지점 수 집계 쿼리와 중복 ID 거절(제약) 검증을 완료한다. GIS 서버 구축은 제외하고 데이터 모델·쿼리·검증에 집중한다. 비용은 0원으로 제한되어 외부 유료 서비스는 사용하지 않는다.

### 1. 요구·모델 설계 및 스키마 구현

- 목표: 간단한 ERD 작성, 정규화 적용, 테이블·PK·FK·제약(UNIQUE 등) 정의 및 샘플 데이터 로드
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항(필드 목록, 관계, 제약)을 1페이지로 정리
- 활동: ERD(간단한 다이어그램) 작성 및 정규화(최소 3NF) 적용
- 활동: DDL(테이블 생성, PK, FK, UNIQUE 제약) 작성
- 활동: 샘플 데이터(지역 5개, 지점 20개)를 CSV로 준비하고 로컬 RDBMS에 로드
- 산출물: 요구사항 1페이지(필드·관계·제약 명시)
- 산출물: ERD 이미지 또는 텍스트 설명
- 산출물: DDL 스크립트(.sql)
- 산출물: 샘플 데이터 CSV 및 로드 스크립트
- 완료 기준: 미확인
- 추천 자료 KMOOC_20252: 제공 근거에서 확인되지 않음

- 목표: 지역별 지점 수 집계 쿼리 작성·실행, 중복 ID 삽입 시 제약 위반 검증, 간단한 성능·정확성 비교 및 결과 문서화
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원

- 활동: 중복 ID 삽입 시 UNIQUE 제약 위반을 재현하는 테스트 케이스 작성 및 실행
- 활동: 쿼리 결과와 제약 위반 로그를 캡처하여 비교·분석
