# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

비용 우선의 2주 RAG 검색 시제품(작동하는 최소 기능)

주어진 2주(총 6시간)와 현금 예산 10,000원 내에서 '문서 검색 → 간단한 RAG 파이프라인 → 근거 문장 확인'을 목표로 최소 동작 시제품을 구현합니다. 외부 유료 서비스·유료 데이터셋은 사용하지 않고, 로컬/무료 도구와 공개 샘플 문서(또는 사용자가 제공한 소규모 문서)로 검증합니다. 지원금(30,000원)은 미확정이므로 계획에 포함하지 않습니다.

### 1. 요구·데이터 준비 및 기준선 측정

- 목표: 검증 가능한 소규모 문서 집합과 평가 기준(정성·정량)을 마련한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 목표 질의 5~10개(예: 사실 확인형 질문)를 정의하고, 각 질의에 대해 '정답 근거 문장'을 수동으로 라벨링한다.
- 활동: 사용할 소규모 문서(10~50개)를 준비한다(공개 샘플 또는 내부 문서의 일부). 문서 형식은 텍스트(.txt/.md)로 통일한다.
- 활동: 간단한 기준선 검색(키워드 매칭 또는 TF-IDF)을 구현하여 각 질의에 대해 상위 3개 문서를 반환하고, 정답 근거 문장이 포함되는지 확인한다.
- 활동: 비용·시간 제약(총 6시간, 현금 10,000원)을 문서화하고, 어떤 유료 리소스는 사용하지 않을지 명시한다.
- 산출물: 질의 목록(5~10개)과 각 질의에 대한 수동 라벨(정답 근거 문장)
- 산출물: 소규모 문서 집합(파일 목록 및 샘플 3개)
- 산출물: 기준선 검색 결과(각 질의에 대해 상위 3개 문서와 매칭 여부 표)
- 산출물: 제약 문서(시간·비용·사용 불가 리소스 목록)
- 완료 기준: 미확인

### 2. 간단한 RAG 파이프라인 구현 및 검증

- 목표: 검색(벡터 또는 키워드) + 간단한 생성(프롬프트)으로 근거 문장을 확인하는 최소 동작 파이프라인을 구현하고, 비용·시간·한계를 문서화한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 로컬 임베딩(예: Hugging Face의 무료 임베딩 모델) 또는 TF-IDF 기반 벡터 인덱스를 구축한다(외부 유료 API 사용 금지).
- 활동: 검색 결과를 상위 1~3개 문서로 제한하고, 그 문서를 컨텍스트로 하여 간단한 프롬프트(예: '주어진 문서에서 질의에 대한 근거 문장을 찾아라')로 생성 모델을 호출한다(로컬 또는 무료 티어 사용).
- 활동: 각 질의에 대해 검색된 문서와 생성된 근거 문장을 비교하여 정성 평가(정답 포함 여부)와 정량 지표(정답 포함률, 평균 검색 랭크)를 계산한다.
- 활동: 비용·시간·한계(예: 임베딩 모델의 메모리 사용, 무료 API 호출 한도)를 기록하고, 개선 포인트를 정리한다.
- 산출물: 동작하는 RAG 시제품 코드(간단한 README 포함)
- 산출물: 각 질의에 대한 검색 결과와 생성된 근거 문장(테이블 또는 JSON)
- 산출물: 정성·정량 평가 결과(정답 포함률, 평균 검색 랭크) 및 한계·개선 제안
- 산출물: 비용·시간 사용 내역(예상/실제)
