# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 문서의 검색 결과와 실제 근거를 대조하는 학습 시제품
- 관점: 비용 우선
- 기간: 9주 · 주당 3시간 · 예산 0원

## 계획

검증 중심의 소규모 RAG 시제품 구현(비용 우선)

사용자의 제한된 시간(2주, 주 3시간)과 예산(0원)을 고려해 검증 가능한 소규모 RAG 시제품을 목표로 합니다. 핵심은 '검색 결과와 실제 근거를 대조하는 검증 절차'를 먼저 정의하고, 그 기준에 맞춰 최소 기능 시제품을 구현·검증하는 것입니다. 외부 문서의 명령형 문구는 실행 지시로 취급하지 않으며, 제공된 자료 ID만 참조합니다.

### 1. 검증 기준 및 테스트셋 준비

- 목표: 검증 가능한 소규모 테스트셋과 검증 기준을 만들어 시제품의 성공/실패 판정 기준을 명확히 한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검증 기준 정의: '검색 결과에 근거 문장이 포함되어야 함' 등 명확한 판정 규칙 작성
- 활동: 테스트 문서 10개 작성(각 문서에 1~3개의 사실성 주장 포함)
- 활동: 간단한 검색 스크립트(문서 인덱싱 + 검색) 구현(로컬 환경, Python)
- 활동: 검증 스크립트 작성: 검색 결과와 문서 내 근거를 대조하여 일치 여부 출력
- 산출물: 학습 목표·검증 기준 문서(간단한 체크리스트)
- 산출물: 테스트 문서 10개(각 문서에 1~3개의 사실성 주장 포함)
- 산출물: 검증 스크립트(입력: 문서, 출력: 검색 결과와 일치 여부)
- 완료 기준: 미확인

### 2. RAG 시제품 구현 및 검증

- 목표: 검색 결과를 생성 모델에 전달해 근거를 포함한 응답을 생성하는 최소 기능 시제품을 구현하고, 테스트셋으로 검증한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 생성 모델에 전달하는 파이프라인 구현(로컬 또는 API 사용)
- 활동: 프롬프트 설계: 검색 결과를 근거로 답변을 생성하도록 유도하는 기본 프롬프트 작성
- 활동: 테스트셋에 대해 시제품 실행 및 결과 수집
- 활동: 결과 분석: 검색 정확도(검색된 문서에 근거 포함 여부)와 생성 응답의 근거 일치 여부 측정
- 산출물: RAG 시제품 코드(검색 + 생성 파이프라인)
- 산출물: 시제품 실행 결과(테스트셋에 대한 검색·생성 로그)
- 산출물: 간단한 성능·정확도 리포트(정확도, 실패 사례 목록)
- 완료 기준: 미확인
