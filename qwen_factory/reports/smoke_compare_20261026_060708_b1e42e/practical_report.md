## 계획

1주 집중 실습: SQLite 기반 재고 데이터모델 설계 및 JOIN 검증

주어진 1주(총 4시간) 내에 로컬 SQLite 환경에서 재고 품목과 입출고 테이블을 설계하고, 외래키 제약과 JOIN 쿼리의 결과를 검증하는 산출물을 만든다. 시간 우선 관점으로 범위를 최소화하여 설계·구현·검증을 완료한다.

### 1. 설계 및 환경 준비

- 목표: 테이블 스키마(품목, 입출고)와 검증 기준 정의, 로컬 SQLite 환경 준비
- 기간: 0.25 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 간단한 요구사항(품목 속성, 입출고 이벤트 속성) 6개 항목으로 정리
- 활동: ER 다이어그램(간단한 텍스트 표기) 작성
- 활동: 로컬 SQLite 설치 확인(예: sqlite3 CLI 또는 Python sqlite3 모듈)
- 활동: 검증 기준(예: 외래키 위반 시 예외 발생 여부, JOIN 결과 행 수 기대치) 정의
- 산출물: 테이블 스키마 정의 파일(schema.sql) — CREATE TABLE 문 포함
- 산출물: 간단한 ER 텍스트(텍스트 파일 또는 주석)
- 산출물: 검증 체크리스트(외래키·JOIN 기대 결과 포함)
- 완료 기준: 미확인

### 2. 구현 및 검증

- 목표: DDL·샘플 데이터 적재, 외래키 제약 확인, JOIN 쿼리 실행 및 결과 검증
- 기간: 0.75 · 시간: 미확인시간 · 비용: 미확인원
- 활동: schema.sql을 SQLite에 적용하여 테이블 생성
- 활동: 샘플 데이터(품목 5개, 입출고 이벤트 10건) 삽입
- 활동: 외래키 제약이 동작하는지 의도적 위반 케이스로 확인
- 활동: JOIN 쿼리(예: 품목별 총 입고량, 최근 출고 이력) 작성 및 결과 비교
- 활동: 간단한 자동화 검증 스크립트(예: Python sqlite3로 쿼리 실행 후 기대값과 비교) 작성
- 산출물: 데이터 적재 스크립트(data.sql 또는 CSV + 적재 스크립트)
- 산출물: JOIN 쿼리 모음(joins.sql)과 실행 결과 스냅샷
- 산출물: 검증 스크립트(예: verify.py)와 검증 결과(성공/실패 로그)
