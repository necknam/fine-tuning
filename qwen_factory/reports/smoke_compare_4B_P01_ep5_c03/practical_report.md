- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

비용 우선: 최소 자원으로 검색 실패 재현 및 원인 기록

사용자의 제약(기간 10주, 주당 2시간, 예산 0원)을 반영하여 외부 유료 자료나 추가 비용을 도입하지 않고, 이미 있는 Python 환경과 가상 문서만 사용해 3건의 검색 실패를 재현하고 원인을 기록하는 실습 로드맵을 제시합니다. 각 단계는 실제 산출물과 완료 기준을 포함하며, 단계 시간 합계는 사용자 가용 시간(총 20시간) 내에 맞춥니다. 규정·지원금 관련 확정 근거는 제공된 승인 자료로 확인 필요로 표시합니다.

### 1. 1단계 · 환경 점검 및 실패 시나리오 정의

- 목표: 실행 가능한 Python 환경 확인과 3개의 구체적 실패 시나리오(예: 관련 문서 없음, 문서 존재·문맥 누락, 인덱스 미적용)를 정의
- 기간: 2 · 시간: 4시간 · 비용: 0원
- 활동: Python 환경(버전, 패키지) 확인 및 간단한 검색/문맥 코드 스니펫 실행
- 활동: 가상 문서 3건(간단한 텍스트 파일 또는 JSON) 준비
- 활동: 각 문서에 대해 실패 시나리오 1건씩 정의(시나리오 문서화)
- 산출물: 환경 점검 노트(버전·패키지 목록)
- 산출물: 3건의 실패 시나리오 문서(각 시나리오의 기대 동작·검증 방법 포함)
- 완료 기준: 환경 점검 노트와 3건의 실패 시나리오 문서가 작성되어 실행 가능한 상태

### 2. 2단계 · 간단한 검색·문맥 구성 및 실패 재현

- 목표: 가상 문서와 간단한 검색/문맥 구성으로 3건의 실패를 재현하고 로그·응답을 수집
- 기간: 4 · 시간: 8시간 · 비용: 0원
- 활동: 간단한 검색(예: 텍스트 검색 또는 간단한 벡터 검색) 코드 작성
- 활동: 문맥(검색 결과 상위 문서)을 구성하여 LLM 입력으로 전달
- 활동: 각 실패 시나리오를 실행하고 로그·응답을 수집
- 산출물: 실행 스크립트(검색·문맥 구성 코드)
- 산출물: 각 실패에 대한 원시 로그와 LLM 응답 캡처
- 완료 기준: 각 실패 시나리오에 대해 실행 스크립트와 원시 로그·응답이 확보되어 재현 가능

### 3. 3단계 · 원인 분석 및 개선 제안 작성

- 목표: 각 실패의 원인(인덱스·쿼리·문맥·응답 처리)을 정리하고 우선순위별 개선안을 작성
- 기간: 3 · 시간: 6시간 · 비용: 0원
- 활동: 로그·응답을 바탕으로 원인 가설 수립(각 실패별 1~3개 원인)
- 활동: 개선안(예: 인덱스 구성 변경, 쿼리 수정, 문맥 추가)과 기대 효과를 문서화
- 활동: 개선안 적용을 위한 최소 변경 목록 작성
- 산출물: 원인 분석 문서(각 실패별 원인·증거·개선안 포함)
- 산출물: 우선순위별 개선안 목록(간단한 구현 단계 포함)
- 완료 기준: 각 실패에 대해 원인 가설과 개선안이 문서화되어 우선순위가 명시됨

### 4. 4단계 · 결과 정리 및 검증 체크리스트 작성

- 목표: 실패 재현 결과와 개선안을 요약하고, 재현·검증 체크리스트를 완성하여 다음 단계로 전달
- 기간: 1 · 시간: 2시간 · 비용: 0원
- 활동: 실패 재현 결과 요약(성공 2건, 실패 1건 기준 포함)
- 활동: 검증 체크리스트(재현 절차·검증 방법·필요 자료) 작성
- 활동: 결과물 정리 및 전달용 요약 문서 작성
- 산출물: 결과 요약 보고서(실패 재현 결과·원인·개선안 포함)
- 산출물: 검증 체크리스트
- 완료 기준: 결과 요약 보고서와 검증 체크리스트가 작성되어 다음 단계(실제 적용 또는 추가 실험)로 전달 가능
