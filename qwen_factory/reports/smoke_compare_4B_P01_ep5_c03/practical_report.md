# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 추가 외부 자료 없이 가상 문서 3건의 검색 실패를 재현하고 원인을 기록하기
- 관점: 비용 우선
- 기간: 10주 · 주당 2시간 · 예산 0원

## 계획

2주·총 4시간 내 가상 문서 검색 실패 재현 및 원인 기록

이미 있는 Python 환경과 가상 문서만 사용해 RAG 관련 검색 실패를 재현하는 최소 실험을 2주(주 2시간) 안에 완료합니다. 외부 유료 자료·추가 환경 설정 없이, 실패 재현 절차와 로그·간단 진단을 산출물로 남깁니다. 성공 기준은 재현 가능한 실패 사례 2건과 실패 원인 후보 1개 이상을 문서화하는 것입니다.

### 1. 환경 점검 및 실패 재현

- 목표: 가상 문서 3건과 검색 쿼리 3개를 준비해 검색 실패를 재현하고 로그를 확보
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 이미 설치된 Python 환경에서 검색/문서 인덱싱 관련 최소 구성 확인(예: 로컬 파일 기반 인덱스 또는 간단한 검색 라이브러리)
- 활동: 가상 문서 3건(텍스트 파일)을 생성하고 각 문서에 메타데이터(제목, 카테고리 등)를 추가
- 활동: 검색에 사용할 쿼리 3개(정확 매칭, 부분 매칭, 관련성 낮은 쿼리)를 작성
- 활동: 각 쿼리에 대해 검색 실행 후 결과와 로그(에러·응답·타임스탬프)를 수집
- 산출물: 가상 문서 3건(파일 경로 또는 내용 스니펫)
- 산출물: 사용한 쿼리 3개와 실행 명령/스크립트
- 산출물: 검색 실행 로그(각 쿼리별 응답 및 에러 포함)
- 완료 기준: 3개 쿼리 중 최소 2건에서 검색 실패(예: 결과 없음 또는 에러)를 재현하고 해당 로그를 확보했을 때 완료

### 2. 간단 진단 및 결과 정리

- 목표: 로그와 재현 절차를 바탕으로 실패 원인 후보를 정리하고 개선 포인트를 문서화
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 수집한 로그를 검토해 가능한 원인(인덱스 미생성, 메타데이터 불일치, 토큰화/인덱싱 오류 등)을 목록화
- 활동: 각 실패 사례에 대해 재현 절차(명령·파일·환경)를 단계별로 기록해 재현 가능성을 높임
- 활동: 간단한 진단(예: 인덱스 재생성, 메타데이터 점검, 쿼리 정규화)을 실행해 원인 후보를 검증
- 활동: 최종 보고서에 실패 사례, 로그 스니펫, 원인 후보, 권장 다음 단계(우선순위 포함)를 작성
- 산출물: 실패 재현 절차 문서(명령·환경·파일 포함)
- 산출물: 로그 분석 요약(각 실패별 원인 후보)
- 산출물: 최종 보고서(실패 2건·실패 1건의 구분 기준과 개선 권고 포함)
- 완료 기준: 최종 보고서에 재현 가능한 실패 사례 2건과 실패 원인 후보 1개 이상을 문서화했을 때 완료
