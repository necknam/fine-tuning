- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 업무 적용 우선
- 기간: 4주 · 주당 3시간 · 예산 20000원

## 계획

2주 집중 실습: 최소 RAG 시제품(근거 표시·분류 포함)

주당 3시간, 총 6시간(2주)으로 Python 기반 최소 RAG 시제품을 구현합니다. 목표는 가상 규정 3건에서 질문 5건에 대해 근거를 표시하고, 근거가 없는 질문은 '근거 없음'으로 분류하는 것입니다. 이미 아는 Python 기초는 반복하지 않고, 검색·정렬·응답 생성·검증에 집중합니다. 비용은 20,000원 이내로 유지하며, 유료 서비스는 사용하지 않습니다.

### 1. 데이터 준비 및 검색 파이프라인 구현

- 목표: 가상 규정 3건을 구조화하고, 간단한 검색(키워드 또는 임베딩 기반)으로 관련 문단 1~3개를 반환하는 파이프라인을 구현한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 200~500자)을 JSON/텍스트로 정리(문서 ID 포함)
- 활동: 문서 분할(문단 단위) 및 인덱싱(간단한 TF-IDF 또는 로컬 임베딩 사용)
- 활동: 검색 함수 구현: 입력 질문 → 상위 1~3개 문단 반환
- 활동: 간단한 테스트: 5개 질문 중 3개에 대해 검색 결과 확인
- 산출물: 가상 규정 JSON 파일(3건)
- 산출물: 검색 스크립트(파이썬) 및 실행 예시
- 산출물: 검색 결과 로그(5개 질문 중 3개에 대한 상위 문서·문단)
- 완료 기준: 미확인

- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi

### 2. 응답 생성·근거 표시·검증

- 목표: 검색 결과를 바탕으로 답변을 생성하고, 각 답변에 근거(문서 ID·문단 위치)를 표시한다. 근거가 없는 질문은 '근거 없음'으로 분류하고, 간단한 평가표를 작성한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과를 프롬프트로 조합하여 답변 생성(로컬 LLM 또는 간단한 템플릿 사용)
- 활동: 답변에 근거 필드 추가(예: {"answer": "...", "evidence": [{"doc_id": "D1", "para": 2}]})
- 활동: 근거 없는 질문 판별 로직 구현(검색 점수 임계값 또는 빈 결과 처리)
- 활동: 5개 질문 전체에 대해 결과 수집 및 간단한 평가표 작성(정답성·근거 존재 여부)
- 산출물: 응답 생성 스크립트(파이썬) 및 출력 예시(근거 포함)
- 산출물: 5개 질문에 대한 결과 CSV(질문, 답변, 근거, 분류)
- 산출물: 간단한 평가표(정답성·근거 누락·분류 정확도)
- 완료 기준: 미확인
