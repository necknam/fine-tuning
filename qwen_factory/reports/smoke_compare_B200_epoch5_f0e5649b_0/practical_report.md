# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 가상 규정 3건에서 질문 5건의 근거를 표시하고 근거 없는 질문은 구분하는 최소 RAG 시제품
- 관점: 비용 우선
- 기간: 6주 · 주당 3시간 · 예산 20000원

## 계획

비용 우선 2주 최소 RAG 시제품(근거 표시·분류 중심)

주당 3시간, 총 2주(총 6시간) 안에 최소 동작 RAG 시제품을 구현해 가상 규정 3건에서 질문 5건에 대해 근거를 표시하고, 근거가 없는 질문은 '근거 없음'으로 분류하는 것을 목표로 합니다. 예산 20,000원 내에서 외부 유료 서비스 없이 로컬/무료 도구로 구현하고, Microsoft Learn의 관련 모듈을 학습 자료로 병행합니다. 시간·비용 제약을 고려해 데이터 전처리·임베딩·검색·간단한 생성(템플릿 기반)·평가까지 최소 범위로 축소합니다.

### 1. 데이터 준비 및 임베딩

- 목표: 가상 규정 3건을 구조화하고 임베딩 인덱스를 생성하여 검색 가능 상태로 만든다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 가상 규정 3건(각 500~1,000자)을 작성·정리(메타데이터: 문서ID, 조항명 포함)
- 활동: 문서 분할(섹션/조항 단위) 및 간단한 전처리(불용어 제거, 토큰화) 수행
- 활동: 로컬 임베딩(예: Hugging Face의 작은 임베딩 모델 또는 무료 API)으로 벡터 생성
- 활동: 벡터 인덱스(로컬 FAISS 또는 간단한 numpy 기반 유사도) 생성
- 산출물: 정리된 규정 JSON/CSV(문서ID·조항명·텍스트 포함)
- 산출물: 임베딩 벡터 파일(예: .npy 또는 FAISS 인덱스)
- 산출물: 간단한 검색 스크립트(쿼리 입력 → 상위 K 문서 반환)
- 완료 기준: 검색 스크립트로 각 문서의 핵심 문장을 쿼리했을 때 상위 3개 결과에 해당 문장이 포함되는지 확인(간단한 수동 검증).

### 2. 검색·응답 결합 및 평가

- 목표: 검색 결과를 바탕으로 근거를 표시한 응답을 생성하고, 5개 질문으로 동작을 평가하여 근거 누락·답변 불가 사례를 분류한다.
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 검색 결과(상위 2~3개)를 조합해 간단한 응답 템플릿으로 근거 포함 답변 생성(예: '근거: 문서ID/조항명')
- 활동: 응답에 근거가 없을 경우 '근거 없음'으로 라벨링하는 규칙 구현
- 활동: 5개 질문(근거 있음 3건, 근거 없음 2건)으로 시제품 실행 및 결과 기록
- 활동: 간단한 평가표 작성(정확히 근거 표시 여부, 근거 누락 여부, 답변 불가 여부)
- 산출물: RAG 시제품 스크립트(검색 + 템플릿 기반 응답)
- 산출물: 5개 질문의 실행 결과 로그(입력·검색결과·응답·라벨)
- 산출물: 평가표(각 질문에 대한 근거 표시 성공/실패 및 원인 메모)
- 완료 기준: 5개 질문 중 근거가 있는 3건에 대해 적어도 2건 이상에서 올바른 근거(문서ID/조항명)를 표시하고, 근거가 없는 2건은 모두 '근거 없음'으로 분류되는지 확인.
- 추천 자료: Microsoft Foundry를 사용하여 생성 AI 모델 성능 최적화 · ID MS_df219eb945ff · DB 비용 0.00원 · 이용 상태 미확인
- 자료 출처: https://learn.microsoft.com/ko-kr/training/modules/optimize-generative-ai-model-performance/?WT.mc_id=api_CatalogApi
