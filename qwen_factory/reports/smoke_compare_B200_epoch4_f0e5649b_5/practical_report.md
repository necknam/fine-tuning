# 맞춤형 학습 계획 보고서

## 프로젝트와 조건

- 목표: 비용 한도 안에서 근거 문장을 확인하는 작은 검색 시제품
- 관점: 비용 우선
- 기간: 7주 · 주당 3시간 · 예산 10000원

## 계획

미확인

2주(총 6시간) 동안 비용 우선 관점에서 최소한의 RAG(검색 증강) 시제품을 구현하고, 프롬프트 전략을 적용해 근거 문장 확인 성능을 비교·검증합니다. 예산(10,000원)과 주당 3시간 제약을 반영해 로컬 도구와 무료 학습 자료를 중심으로 진행합니다. 지원금(30,000원)은 승인·지급 시점이 불확실하므로 계획에 포함하지 않았습니다.

### 1. 검색 기반 RAG 프로토타입

- 목표: 문서 기반 검색으로 근거 문장을 찾아 LLM에 증강하는 최소 동작 파이프라인 구현
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 작업 범위 축소: 확인해야 할 근거 문장 유형과 샘플 문서(5~10개) 선정
- 활동: 로컬 검색 인덱스 구성(예: FAISS 또는 간단한 TF-IDF 인덱스) 및 문서 임베딩/인덱싱
- 활동: 검색 결과 상위 k개를 LLM 프롬프트에 증강하는 간단한 파이프라인 작성(검색→프롬프트 조합→LLM 호출)
- 활동: 검색 정확도(정확히 근거 문장 포함 여부)와 응답의 근거 표기 여부로 초기 검증
- 산출물: 간단한 RAG 아키텍처 다이어그램(검색→증강→생성 흐름)
- 산출물: 작업용 샘플 문서 5~10개(텍스트 파일)
- 산출물: 검색 인덱스(로컬)와 검색 쿼리 예시
- 산출물: 간단한 검색-증강 파이프라인 코드(검색 결과와 증강 프롬프트 조합)
- 완료 기준: 미확인

### 2. 프롬프트 전략 적용 및 비교

- 목표: 검색 결과를 효과적으로 LLM에 전달하는 프롬프트 전략을 적용해 응답 품질을 개선하고 비용·응답시간 관점에서 비교
- 기간: 1 · 시간: 미확인시간 · 비용: 미확인원
- 활동: 기본 프롬프트와 고급 프롬프트(컨텍스트 주입, 계층화, 방어적 프롬프트)를 설계
- 활동: 동일한 검색 결과로 여러 프롬프트 전략을 비교 실험(정확도·응답 길이·토큰 비용 추정)
- 활동: 비용·응답시간 관점에서 선택 가능한 프롬프트 템플릿을 문서화
- 산출물: 프롬프트 변형별 비교표(원본 vs 고급 전략)
- 산출물: 최종 선택된 프롬프트 템플릿과 사용 예시
- 산출물: 간단한 평가 리포트(정확도·응답 일관성·비용 추정)
- 완료 기준: 미확인
